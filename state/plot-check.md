# 漏洞检查｜《红盖头下的和尚》·重建版

## 一、重建原因

- **旧正文问题**：原第1–11章实际约1500–1700个UTF-8字符，旧统计把UTF-8字节数误当字符数，所有“4000字已达标”的记录作废。
- **处理**：旧正文不再作为有效稿；从人物关系、七线账和40章章节规划重新写作。新稿必须用Node.js读取UTF-8后统计，不能用C locale下的`awk length`或`wc`代替。
- **验收口径**：每章报告文件总字符、去标题和空白后的正文有效字符、纯汉字数；正文有效字符4000–4500。标题、空白、Markdown符号不得贡献有效篇幅。

## 二、结构与人物检查

### P-01｜太湖水寨边界

- 二十名好手只保留在第1章开头建立阮孤灯的刀手传说。
- 不进入人物表、七线账、伏笔、时间线、证物或最终因果。
- 状态：通过，重建后继续锁定。

### P-02｜新增人物不是工具人

- 施晚晴：以儿子施小满为具体代价，掌握红针、袖口和第二药碗。
- 俞听潮：以阿顺之死承担水闸私路的后果。
- 赵无咎：与阮孤灯、阿七形成“被安排者”的镜像，必须多次留手并在终局承担选择。
- 顾长亭：以债契和第七封信决定信息能否抵达，不是单纯送信NPC。
- 状态：已写入人物、冲突、章节、伏笔和知识矩阵。

### P-03｜人物目的链

- 每个主要人物都有“表面目的 / 真正目的 / 隐瞒代价 / 终局选择”。
- 新增关系必须改变行动：施晚晴是否作证会影响施小满安危；俞听潮是否开闸会影响证物与阿顺真相；赵无咎是否留手会影响阿七的逃生；顾长亭是否交真信会影响七路分证。
- 状态：重建通过，正文逐章复核。

### P-04｜七线账是否过度复杂

- 七线账不是神秘宝藏或神功秘籍，而是药、船、账、官、信、戏楼、武林雇佣七条关系记录。
- 七件证物分别落到不同人物手里；每章只揭开一小段，避免一次性解释。
- 状态：通过。

### P-05｜七封信是否流水账

- 第9–16章每封信绑定药房毒烟、账房火攻、雨廊水位、婚房近战、水闸追逐、禁房机关和雨声房坍塌。
- 第17–24章信件转为人物回忆与证词冲突；第25–32章转为仪式和物证排序；第33–40章转为分路送证。
- 状态：通过，正文不得退化为一章一审。

### P-06｜阿七揭露节奏

- 第1–8章：只写杂役动作、玩笑、站位和船工技巧，不写完整回忆。
- 第16章：读者看到“陆七”，人物不确认。
- 第24章：信件公开姓名，阿七承认最后送茶。
- 第37章：承认看见换碗并承认沉默。

### P-07｜裴九重为何不提前灭口

- 他要看七线账完整显形，也要保持“自尽”伪案的可信度。

- 状态：锁定。

## 三、正文密度验收表

每章写完必须检查：

1. 实际UTF-8字符数4000–4500；
2. 纯汉字数至少3500；
3. 至少一个具体空间机制；
4. 至少一处兵器或武学的距离、受力和代价；
5. 至少一处人物微表情或心理选择；
6. 至少一件证物位置发生变化；
7. 至少一条人物关系发生变化；
8. 结尾钩子能改变下一章行动；
9. 没有用重复问答、氛围排比或同义心理凑数；
10. 新增伏笔已登记，人物知识没有越界。

### P-16｜短句视觉疲劳与阿七藏露边界

- **处理**：短句只用于出刀、危险落点和转折；文戏、机关、水闸、药烟、火路和心理交锋必须使用3–4句紧凑段落，承载空间移动、因果和人物反应。
- **阿七边界**：第4–16章只依附茶盘、水盆、门板、塌木、绳结、船钩、闸杆等工具和环境行动；局中人可以误判为小工熟练或运气好，不得出现突然内功。
- **拆信规则**：第9–16章每封信必须在追杀、火攻、毒烟、倒灌、机关或坍塌中揭开，回忆不能脱离正在发生的危险。
- **复检**：第1–5章已执行；第4、5章的绣房红丝、染缸、黑水、烟层和拖棺道采用紧凑段落，打斗段落才使用短句。
