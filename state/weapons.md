# 天阙 - 兵器谱

> "兵器不杀人，人杀人。但好的兵器，能让杀人变得更容易。"

---

## 二、天兵（传说级）

### 2.1 断水

- **类型：** 剑
- **传说：** 越王勾践佩剑，"断水"意为"一剑断流"
- **实况：** 失传千年，有传言藏于某座越王墓中。裴弘度曾派人寻找
- **小说作用：** 作为"天门遗脉"追寻的上古秘宝之一，推动部分暗线
- **最终下落：** 未被找到（或找到但非真品）

### 2.2 天工

- **类型：** 暗器/机关
- **传说：** 墨家巨子所制，"一发千机，天工开物"
- **实况：** 墨门镇门之宝，公输野手中。非武器，而是一套精密的机关装置，可模拟各种武学招式
- **小说作用：** 公输野用它验证武学理论，后成为沈广农理解"武学底层逻辑"的关键道具

### 2.3 归墟

- **类型：** 刀
- **传说：** 传说铸造于海底，刀身呈暗蓝色，有水波纹
- **实况：** 公孙白的佩刀，但他已封刀三十年。刀在扬州修船铺的角落里生锈
- **小说作用：** 沈广农在扬州找到公孙白时，归墟刀被用来撬船板——天下第一刀，沦为修船工具

## 三、神兵（极品质）

### 3.1 九幽剑

- **类型：** 剑
- **持有者：** 慕容荒
- **铸造：** 传闻为前朝铸剑名师所锻，剑身如秋水，薄如蝉翼
- **特性：** 轻若无物，慕容荒以此剑施展《太一归藏》，剑速天下第一
- **典故：** 慕容荒二十岁时在终南山捡到此剑，此后再未换剑

### 3.2 铁脊枪

- **类型：** 长枪
- **持有者：** 李承洲
- **铸造：** 萧寒山年轻时所用，后传给弟子
- **特性：** 重四十三斤，普通人力不能举。李承洲以此施展《天河倒卷》，一枪改十人方位
- **典故：** 萧寒山说："此枪不杀人，只引路。"

### 3.3 照夜

- **类型：** 剑（残刃）
- **持有者：** 宁红叶
- **铸造：** 不详。宁红叶在长安废墟中捡到的一柄残剑，剑身有裂痕
- **特性：** 不锋利，但极轻。宁红叶以它施展《照夜剑》，"不求胜，只求活"
- **典故：** 宁红叶说："好剑杀人，烂剑活命。我选活命。"

### 3.4 断潮刀

- **类型：** 刀
- **持有者：** 公孙白（已封）
- **铸造：** 公孙白年轻时自锻，刀身刻有"断潮"二字
- **特性：** 刀意"断念"——不是砍断敌人的身体，而是砍断敌人的战意
- **典故：** 公孙白封刀时说："刀在人在，刀封人亡。"

### 3.5 天机算盘

- **类型：** 暗器（算盘形）
- **持有者：** 谢景
- **铸造：** 不详。谢景随身携带的算盘，算珠可射出
- **特性：** 看似算盘，实为暗器。算珠射出速度极快，且可回收
- **典故：** 谢景说："天下事，皆可算。"

### 3.6 洞庭箫

- **类型：** 箫（暗藏剑刃）
- **持有者：** 谢听潮
- **铸造：** 洞庭湖特产的紫竹所制
- **特性：** 看似乐器，实为兵器。箫声可扰敌心神，箫身藏有薄刃
- **典故：** 谢听潮平时以箫声诱鱼，战时以箫声杀人

### 3.7 无名剑

- **类型：** 剑
- **持有者：** 独孤彦
- **铸造：** 独孤彦自锻，无名无款
- **特性：** 出鞘必见血，"一念剑"的物质载体
- **典故：** 独孤彦说："剑不需要名字。需要名字的是人。"

## 五、兵器与武学的关系

本书的兵器不是"越强越好"，而是与持有者的武学理念深度绑定：

| 武学理念 | 典型兵器 | 逻辑 |
|---------|---------|------|
| 剑（道） | 九幽剑、无名剑 | 剑是精神的延伸 |
| 枪（势） | 铁脊枪 | 枪改变战场空间 |
| 刀（断） | 断潮刀 | 刀斩断的是意志 |
| 残刃（活） | 照夜 | 活命不需要好剑 |
| 暗器（算） | 天机算盘、丧门钉 | 暗器是信息不对称的产物 |
| 音（控） | 玉笛、洞庭箫 | 声音是精神攻击的媒介 |

### 核心原则：兵器不是目的

沈广农最终领悟的武学境界"天阙"，其标志之一是：

> **他不再需要兵器。**

不是因为他强到不需要，而是因为他已经看穿了兵器的底层逻辑——**兵器是人的延伸，当人的认知足够高时，万物皆可为兵。**

这与他最终放弃天阙之境形成呼应：**最强大的武器，是放下武器。**
