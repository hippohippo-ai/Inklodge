# 章节规划｜《红盖头下的和尚》·重建版

> 正文硬标准：每章实际 UTF-8 字符 4000–4500；不得用标题、空白行、重复对白凑数。每章至少有一条人物关系推进、一件可触摸的证物变化、一次具体空间或武学冲突和一个改变下一章路线的钩子。

## 卷一：红灯引路（第1–8章）

### 第1章｜月色如水
- **地点 / 人物**：太湖渡口、柳家货船；阮孤灯、明照、柳九娘、陶未明、梅照影、谢三更，后半段阿七。
- **核心事件**：保留月色、黑刀、红盖头和尚和阮孤灯十三岁一刀杀二十名太湖水寨好手的传说；众人因七封信登船。
- **情节密度**：谢三更以管家身份清点客人与行李，陶未明发现邀请信上的官印年份不对；梅照影听出船外有三组不同水声；柳九娘拒绝搜阿七的茶箱，因为茶箱里藏着一枚沈红绡的空白红针。
- **动作**：黑线杀手从船底、桅杆和水面同时袭击，阮孤灯三刀改变近身距离，明照以渡厄掌卸镖，柳九娘用短桨断索，陶未明卡舱门，梅照影以听声辨出真正杀招；阿七用收缆和茶盘救下一封无名信。
- **关系推进**：阮孤灯发现明照耳后旧疤而手抖；阿七第一次用玩笑让明照把茶喝完；谢三更看见阿七看见了不该看的水痕。
- **钩子**：船抵庄门，门内七条黑路同时传来水声，门外药水顺缝流出；无名信上只写“第七个人不要进门”。

### 第2章｜船上第七个人
- **地点 / 人物**：留春山庄庄门、七路水廊；全员、施晚晴、俞听潮、阿七。
- **核心事件**：名单上只有六位客人和明照，阿七不在名单；施晚晴以绣房管事身份迎接，俞听潮修闸时故意不看众人。
- **情节密度**：七道门各有不同水声，陶未明按门钉判断有人刚从内侧锁过；施晚晴发现红盖头边缘少了一针；俞听潮的闸杆上有阿顺留下的三圈绳结。
- **动作**：水下弩、倒灌火油和暗门短刀同时启动；陶未明以铁尺封闸，明照借墙卸力，柳九娘以船钩拉人，阿七用听水步避开塌板并让火油流入空池。
- **关系推进**：施晚晴认出阿七，却故意称他“新来的小工”；俞听潮对阿七的绳结动作多看一眼；赵无咎在暗处第一次看见阿七。
- **钩子**：从空木箱里取出的封蜡竹筒传出沈红绡的声音：“第一封信，不要给最想看的那个人。”七枚短箭钉入门廊。

### 第3章｜红色的请帖
- **地点 / 人物**：七灯小厅、婚房前廊；增加顾长亭（伪装成送信脚夫）。
- **核心事件**：红色请帖宣布七日补婚；明照承认沈红绡是姐姐；顾长亭来取一封被退回的私信。
- **情节密度**：请帖上的红墨遇水变黑，七盏灯按不同顺序熄灭；秦半夏从纸张药味辨出请帖曾在药房；顾长亭看见信封上的旧戏楼印却不承认。
- **动作**：无主影子从灯顶取帖，细针从灯罩落下；阮孤灯以刀鞘护人不出刀，明照用掌风改变针路，阿七故意撞翻茶水让顾长亭逃过一枚毒针。
- **关系推进**：阮孤灯认出明照耳后疤与沈家旧伤相同；顾长亭欠阿七一次救命，却只把他当没名字的杂役。
- **钩子**：请帖最后显出“新娘已经死过一次”；红盖头里有一根针自行断裂，针尖指向绣房。

### 第4章｜绣房里的第二只袖口
- **地点 / 人物**：绣房、婚房；施晚晴成为核心视角。
- **核心事件**：众人调查红盖头缺针，施晚晴声称自己只缝过一件婚衣；却有一只带血袖口在绣架后出现。
- **情节密度**：红丝在雨气中收缩，绣架暗格藏着第二只药碗的碎片；施晚晴的针线不是装饰，而是能绊住手腕的机关；谢三更带护院来收回婚服。
- **动作**：四名护院从绣架、门槛和梁上合围；阮孤灯三刀只断弩弦、袖口和退路，明照以掌力救下施晚晴，阿七用绷线和门闩改变护院重心。
- **关系推进**：施晚晴在众人面前替谢三更撒一次谎，却悄悄把血袖口推给阿七；阿七发现袖口绣纹与赵无咎黑线相同。
- **钩子**：灵堂方向传来沈红绡的笑声，笑声里夹着“不要找棺材，先找替我缝衣服的人”。

### 第5章｜没有棺材的灵堂
- **地点 / 人物**：无棺灵堂、地下拖棺道；秦半夏、陶未明、俞听潮重点出现。
- **核心事件**：陶未明发现棺材被沿地下木轨拖走；第一封信从香灰里露出，指向“替她收药的人”。
- **情节密度**：黑水从七只空碗底上涨，香灰中的纸被药烟熏出双层字；俞听潮发现拖棺道连接旧水闸，承认图纸是自己设计的。
- **动作**：护院用白烟封门，秦半夏以药针救陆秋水，阮孤灯在三寸视野里断掉燃着的红线，阿七把湿布和香灰压在水口；陶未明用铁尺锁住一名护院的肘。
- **关系推进**：俞听潮承认阿顺曾在死亡后夜来过这里；谢三更第一次不再说“沈姑娘只是太累了”，而是抢走半张信。
- **钩子**：秦半夏说沈红绡死前没有喝过她开的原方；黑砂遇水只显一个“迟”字。

### 第6章｜第一个红结
- **地点 / 人物**：药房、药柜暗门；秦半夏、阿七、施晚晴、赵无咎。
- **核心事件**：红盖头第一处针脚指向药房；秦半夏必须在真药碗和假药碗之间做判断，赵无咎第一次正面试探。
- **情节密度**：封息烟贴地流动，药味被风门切成三层；真碗的裂纹向内，假碗裂纹向外；施晚晴的红丝缠住一枚暗针却不敢出声。
- **动作**：赵无咎以黑线绕腕、短刃反刺，阮孤灯在窄门外与他隔三寸对刀；明照以掌力把毒烟推向空柜；阿七用茶盘、水柜和回潮手让真碗漂回。
- **关系推进**：阮孤灯从赵无咎刀路里认出沈红绡教过的救命步；赵无咎故意不杀阿七，却夺走一枚红针。
- **钩子**：药柜内壁写着“碗是真的，药是假的”；第一处红结熄灭，谢三更宣布封锁药房。

### 第7章｜柳九娘的空木匣
- **地点 / 人物**：药房外水廊、空木匣处；柳九娘、俞听潮、顾长亭。
- **核心事件**：柳九娘交出空匣；七道刻痕不是七封信编号，而是七条水路的闸位。
- **情节密度**：蓝火沿药粉走水，匣底暗针受水压弹出；顾长亭认出匣上旧戏楼符号却想偷走；俞听潮从匣底震动听出墙内有空心竹管。
- **动作**：谢三更抢匣，阮孤灯用刀鞘挡手；柳九娘以短桨击落火把，阿七用茶碗改变重心、托盘压水取回湿信；墙内影子以水钩逃走。
- **关系推进**：柳九娘承认曾替沈红绡守过婚房一夜；顾长亭欠柳九娘一笔船钱；阿七第一次主动替一个陌生人藏住证物。
- **钩子**：第二封信写“你不是没看清，是不敢看清”；水线指向雨声房。

### 第8章｜第一盏灯
- **地点 / 人物**：雨廊、庄门、七间客房；全员、赵无咎的七名同伙。
- **核心事件**：七日局正式开始，庄门被铁链封死；外来杀手与庄内护院并非一队。
- **情节密度**：雨廊水位涨到脚踝，红线随水改变方向，七门机关互相传力；梅照影听出左廊三人、右廊四人，施晚晴听见绣房有人哭。
- **动作**：七名杀手与护院混战；阮孤灯断棍不杀，明照护住陶未明，柳九娘以钩拉线，秦半夏救陆秋水，阿七用门闩改变水流救下竹叶留声片。
- **关系推进**：赵无咎在退走前看见沈红绡声音装置保护的是“无名人”；谢三更确认自己不能控制所有杀手。
- **钩子**：门外出现比明照更深的掌印；裴九重尚未现身，但雨廊水面先退了一寸。

## 卷二：七封信（第9–16章）

### 第9章｜药碗里的月光
- **地点 / 人物**：药房、封息烟道；秦半夏、陆秋水、赵无咎、阿七。
- **事件**：第一封信真正开启，要求秦半夏交代药方被改的那一刻；两只药碗在烟中争夺。
- **动作 / 证物**：赵无咎从药柜后夺碗，阿七用碎碗反射灯影辨真假，明照封住药柜门，阮孤灯以湿木板改变刀路；黑砂显“迟”。
- **关系 / 暗线**：秦半夏承认师门供过延迟方；陆秋水替她藏一张药材票，形成互相牵制。
- **钩子**：无头影子在白烟中饮下药，药碗底浮出“第二只手”。

### 第10章｜账房先生
- **地点 / 人物**：账房、东窗火道；陆秋水、陶未明、顾长亭、谢三更。
- **事件**：第二封信打开账房暗柜，陆秋水发现自己的副账被复制；顾长亭来取一页旧信却被两方追杀。
- **动作 / 证物**：火沿油灯架、纸帘和地板下的干沟联动；陶未明铁尺拆门，陆秋水以算盘珠和削笔自保，阿七倒水救出湿账，顾长亭用纸鸢索翻窗。
- **关系 / 暗线**：陆秋水承认阿七曾替他抄页码；谢三更故意让顾长亭活着逃，想追出第七封信。
- **钩子**：湿账浮出三笔同日空账，页脚有沈红绡写给“纸鸢”的圆点。

### 第11章｜盲人听见火
- **地点 / 人物**：雨廊、封水闸；梅照影、俞听潮、赵无咎。
- **事件**：第三封信逼梅照影说出死亡夜声音；廊下水位上涨，火星沿油痕漂来。
- **动作 / 证物**：铁钉鞋刺客利用水下铁钩，梅照影以水滴、呼吸和鞋钉辨位；阿七用木桶截火，俞听潮关闭一半闸门，赵无咎在远处收走鞋钉。
- **关系 / 暗线**：梅照影承认听见三种脚步；俞听潮发现阿顺的闸杆刻痕属于第三个人。
- **钩子**：黑靴主人在水退后出现，谢三更手里纸团展开为“管家听见门”。

### 第12章｜刀客不杀人
- **地点 / 人物**：极窄婚房、红烛、窗廊；阮孤灯、明照、施晚晴、赵无咎。
- **事件**：三名夜行高手抢带血袖口与药碗；赵无咎负责拖住阮孤灯，真正目标是施晚晴手里的红针。
- **动作 / 证物**：红烛翻倒、床柱与衣柜缩小退路；阮孤灯三寸刀只削袖不杀人，明照渡厄掌第一次废人腕骨，施晚晴以缝影针绊住短刃。
- **关系 / 暗线**：阮孤灯从赵无咎口中听见“白砚生”的名字；明照看到姐姐婚衣袖口内绣着半个沈家旧印。
- **钩子**：袖口被夺走一角，药碗却被窗外看不见的人用线钓走。

### 第13章｜女医的手
- **地点 / 人物**：药房后库、染线室；秦半夏、施晚晴、陆秋水、谢三更。
- **事件**：秦半夏检验黑砂，药针盒被调包，三枚救命针变成封穴针；陆秋水中毒倒下。
- **动作 / 证物**：药粉和染线混合成追踪烟；秦半夏以半夏三渡救人，施晚晴用红丝绑住自己的儿子施小满留下的木牌，阿七循药味追进私库。
- **关系 / 暗线**：秦半夏承认老师曾供过无灯楼；谢三更拿施小满做人质，逼施晚晴改口。
- **钩子**：黑砂遇旧药方显出“迟”字下半行：真正的药不在碗里。

### 第14章｜水闸里的第二封信
- **地点 / 人物**：水闸、暗渠、柳家小舟；柳九娘、俞听潮、顾长亭、赵无咎。
- **事件**：第二封信要求柳九娘说出谁进过婚房；水闸突然全开，空匣和顾长亭同时被水卷走。
- **动作 / 证物**：柳九娘用短桨撑闸、船钩换位；俞听潮以闸杆压住回流；赵无咎在水下追顾长亭，阿七用绳结把空匣送向另一条暗渠。
- **关系 / 暗线**：柳九娘承认曾替沈红绡放进一个看不清脸的人；俞听潮确认那人用的是阿顺的私路。
- **钩子**：水里浮出一枚不属于柳家的船钉，顾长亭手里却攥着第七封信的一角。

### 第15章｜和尚犯戒
- **地点 / 人物**：禁房、木鱼机关；明照、陶未明、施晚晴、觉岸。
- **事件**：明照为找姐姐信件进入禁房，木鱼声启动机关；他掀开红盖头一角，露出耳后旧疤，辨出梁上短弩。
- **动作 / 证物**：地板一格格下沉，陶未明被铁锁夹肘；明照以掌力把弩矢导入木鱼，觉岸在门外只截一招不救人，逼明照自行破局。
- **关系 / 暗线**：施晚晴看见明照疤后承认沈红绡曾问过“弟弟还记不记得黑圆印”；阮孤灯的手抖不再只是旧约。
- **钩子**：墙上写“明照不是新郎”，字下压着半枚赵无咎的黑线扣。

### 第16章｜雨声房
- **地点 / 人物**：雨声房、坍塌横梁；阿七、秦半夏、施小满、俞听潮、赵无咎。
- **事件**：阿七凭旧页码找到雨声房，发现账本副本、茶盘和施小满；房中水位逆涨，地板与横梁同时塌陷。
- **动作 / 证物**：阿七用听水步判断空板，用回潮手把梁力送入水柜，以绳结救秦半夏和孩子；赵无咎赶到却故意迟一息，让三人逃过。
- **关系 / 暗线**：旧抄本写出“陆七，送茶后不要回头”；阿七看见自己的名字，第一次意识到沈红绡从未把他当杂役。
- **钩子**：茶盘底传来第二次敲击，里面不是信，而是一枚无灯楼黑印。

## 卷三：新娘的房间（第17–24章）

### 第17章｜沈家姐弟
- **事件**：明照在旧药柜和木鱼声中回忆被送入寺院的那一年；施晚晴补出沈红绡曾保护他的原因。
- **动作**：夜袭者从寺院墙外投火，明照不追杀而以掌力护住旧物；阿七用茶盖辨出火油来自庄内。
- **关系推进**：明照承认自己怕姐姐不是因为死，而是因为姐姐总替他决定。
- **钩子**：第三封信要求他说出沈红绡离家前交给他的黑圆印。

### 第18章｜阮孤灯的旧约
- **事件**：阮孤灯承认沈红绡曾让他杀白砚生；陶未明拿出原始验尸草纸，证明白砚生与沈案不是同一人，却同属无灯楼旧线。
- **动作**：赵无咎来取草纸，阮孤灯与其短刃对刀；两人都在第三寸处停手，赵无咎退走。
- **关系推进**：阮孤灯不再把赵无咎当普通杀手；明照开始怀疑姐姐当年不是把他抛弃，而是在躲某个组织。
- **钩子**：第四封信写“不要问刀客有没有杀我，问他放走了谁”。

### 第19章｜送茶的人
- **事件**：第三封信点名最后送茶的人；众人第一次正式询问阿七，陶未明要求他按时间画茶房路线。
- **动作**：阿七画图时有人从屋顶射针，他故意画错一条路保护施晚晴；顾长亭在屋后看见真实图却没有揭发。
- **关系推进**：陆秋水说阿七当夜不在庄内，谢三更立刻附和，反而暴露两人串供。
- **钩子**：阿七在陶未明的案册上看见第一页已经有一个“七”字，墨迹与沈红绡相同。

### 第20章｜管家的账
- **事件**：陶未明将原始验尸纸与陆秋水账页并排，查出谢三更把死亡时间提前一刻钟；谢三更开始反向审问每个人。
- **动作**：账房门锁变成折页步陷阱，谢三更以袖剑夺纸；陶未明铁尺封腕却被谢三更借桌脚逃走，陆秋水选择救纸而非救自己。
- **关系推进**：陶未明承认自己也改过一行时间，阿七第一次对他产生同情而非戒备。
- **钩子**：谢三更说“时间可以错，死人不会”，门外却传来阿顺敲闸的三声。

### 第21章｜证词册
- **事件**：陶未明拿出空白案册，要求每个人写下当夜所见；施晚晴的孩子被送回，但衣服上有无灯楼黑线。
- **动作**：黑线杀手在落笔时断灯，众人必须在黑暗中保护各自纸页；梅照影用听声给出敌人位置，阿七用墨水反射窗光。
- **关系推进**：陆秋水写下第一句真话，秦半夏却撕掉自己的药方证词；陶未明选择不追问她的师门。
- **钩子**：案册第一页的“七”字下又出现一个小圆点，顾长亭认出是纸鸢暗号。

### 第22章｜说书人的第三个脚步
- **事件**：第四封信逼梅照影讲完死亡夜；她承认听见沈红绡、谢三更之外还有第三种脚步。
- **动作**：说书台下藏着水箱机关，黑衣人以鼓声掩盖脚步；梅照影被迫在水位上涨中靠听声出针，阿七用桌布改变鼓面回音。
- **关系推进**：梅照影承认那个第三脚步的人没有杀意，反而像在门外等谁；她曾把这个人写成鬼故事保护线人。
- **钩子**：她说出争吵内容：“你不能让他回来。”所有人以为“他”是明照，顾长亭却脸色变了。

### 第23章｜明照的木鱼
- **事件**：明照拆开童年木鱼，找到沈红绡留下的红线和黑圆印；觉岸承认收到过半封信。
- **动作**：木鱼内藏的细针启动，明照以掌力引针，阮孤灯以刀鞘接住；觉岸在旁不替他解释。
- **关系推进**：明照得知姐姐送他入寺是为躲无灯楼，而非厌弃他；施晚晴决定不再替沈红绡把所有选择藏起来。
- **钩子**：第五封信写“弟弟，你见到阮孤灯时，不要问他有没有杀我。”

### 第24章｜陆七
- **事件**：第六封信公开点名阿七；阿七承认真名陆七、承认最后送茶，却只说自己看见两只碗，没有说换碗的人。
- **动作**：谢三更命赵无咎当众夺信，赵无咎短刃逼近阿七却在最后一寸改线；阿七用藏灯式消失在众人换位之间，救下施小满。
- **关系推进**：陶未明从“审杂役”变成“保护证人”；阮孤灯第一次主动问阿七是否愿意活着说完。
- **钩子**：信中写“你看见的不是凶手，是我最后一次选择”；红盖头第七针亮起。

## 卷四：冥婚（第25–32章）

### 第25章｜七日第六夜
- **事件**：谢三更按遗嘱布置冥婚，七根红线连向七间房；每人必须站到一处与自己隐瞒有关的门前。
- **动作**：红线一根根收紧，药房碎碗、账房火星、水闸闸杆同时联动；四名护院出手，众人第一次主动分组而非各自逃命。
- **关系推进**：施晚晴带施小满进入绣房，陆秋水选择跟陶未明走，赵无咎在屋檐上切断一根不该断的线。
- **钩子**：第一根红线断裂，秦半夏房中传来碎碗声，门上出现“不是新娘”的掌印。

### 第26章｜盖头下面
- **事件**：明照进入婚房，红盖头被机关强行掀开一角，露出七处针脚地图；沈红绡的留声没有说完。
- **动作**：红针化为细弩，明照借无相步绕过，阮孤灯以刀背挡住；施晚晴用红丝接回第七针。
- **关系推进**：明照知道姐姐不是要他替她成婚，而是要他看见七件被移动的物件；阮孤灯明白第七针是停手暗号。
- **钩子**：地图最后一针指向阿七的茶盘，茶盘却在谢三更手里。

### 第27章｜茶盘底的双圈水渍
- **事件**：阿七夺回当夜茶盘，发现两圈水渍、半片黑砂和一根施晚晴的红线。
- **动作**：谢三更与阿七在厨房狭窄水道交手，阿七不硬挡而让他每次落脚都踩在回流水线上；赵无咎从梁上出手，逼两人暂时联手躲火。
- **关系推进**：阿七确认自己看见过换碗，却仍无法确认沈红绡最后是否故意喝下；施晚晴承认她曾把带血袖口交给沈红绡。
- **钩子**：盘底刻着“不要替我选凶手”，下方还有一行被茶垢盖住的“也不要替我选活法”。

### 第28章｜阮孤灯的手
- **事件**：明照说出沈红绡当年对阮孤灯说过的话，旧约真相揭开；阮孤灯承认自己放走过白砚生。
- **动作**：赵无咎以黑线困住阮孤灯，逼他在杀与不杀之间做选择；阮孤灯削断黑线而不伤人，把刀交给明照。
- **关系推进**：阮孤灯明白手抖不是因为明照像谁，而是因为明照说出了沈红绡的原话；明照开始真正信任阮孤灯。
- **钩子**：阮孤灯第一次把黑刀交给明照保管，门外有人说“刀离手，人才会说真话”。

### 第29章｜第七封信
- **事件**：柳九娘公开藏信；顾长亭从旧戏楼取出第七封信，承认自己曾两边下注。
- **动作**：旧戏楼机关以幕布、纸鸢索和暗火封门；顾长亭边逃边把信拆成七段，阿七用假路标分送。
- **关系推进**：七封信真正目的明确：不是复仇，是让七人各自承认一段事实；柳九娘承认曾替无灯楼送过人。
- **钩子**：第七封信只写给“看见而不说的人”，最后一笔却像裴九重的圆点。

### 第30章｜谢三更的夜
- **事件**：谢三更封锁药房和绣房，烧账、抓施小满、杀俞听潮；四名护院第一次知道自己守的是灭证而非守庄。
- **动作**：阿七带众人走厨房水道，柳九娘以折帆手、秦半夏以药针、陶未明铁尺、施晚晴红丝分别守四个出口；俞听潮以闸杆挡住谢三更的折页步。
- **关系推进**：俞听潮承认阿顺已死，主动把私路图交给阿七；施晚晴为救儿子公开指认谢三更调过药箱。
- **钩子**：谢三更承认调换药碗，却说沈红绡早已把毒喝下；黑暗里有人说“你只看见了第一层”。

### 第31章｜没有新娘的拜堂
- **事件**：明照在空喜堂完成最后一拜，留声竹筒播放沈红绡未完的一句话，裴九重从门外接上。
- **动作**：裴九重只改变众人站位和呼吸，阮孤灯刀停三寸，明照掌失去借力，梅照影听不见脚步；没有人被直接击倒，却没有人能先出手。
- **关系推进**：所有人第一次知道谢三更上面还有人；赵无咎跪下不是臣服，而是无法违抗自己的旧命令。
- **钩子**：裴九重说“谁先出手，谁就是凶手”，七根红线全部指向账房。

### 第32章｜红线尽头
- **事件**：七根红线、七件物证和账房暗门合拢；裴九重解释七线账与反制谱。
- **动作**：账房地板翻转，证物随水道分流；众人各自救一件，裴九重在未全力出手时夺走三件；阿七用藏灯式保住茶盘。
- **关系推进**：谢三更知道自己也只是被利用的中层；沈红绡的真正要求被红盖头第七针揭示：先停手，再承认。
- **钩子**：账页上出现死亡前主动买药的记录，页角有裴九重亲手圆点；他说真正的药不在碗里。

## 卷五：灯灭之后（第33–40章）

### 第33章｜她买的药
- **事件**：秦半夏查出沈红绡主动买过一味延迟药；药柜暗格里还有一张施晚晴未缝完的袖口。
- **动作**：药房余火复燃，秦半夏必须在救师门旧账和保药证之间选择；阿七用茶水冷却药柜，明照护住她。
- **关系推进**：秦半夏承认沈红绡知道药被动过，但不能证明她知道最后一杯的毒性；明照不再要求唯一答案。
- **钩子**：阿七想起沈红绡买药时说“别告诉我弟弟”，却想不起她当时是否在笑。

### 第34章｜每个人的一半
- **事件**：七名受邀者、施晚晴、俞听潮、顾长亭和赵无咎分别补齐自己隐瞒的一半事实；裴九重逐一指出证词漏洞。
- **动作**：裴九重不出重手，只用不同距离让每个人的防御失效；阿七把真话藏进众人的闲话和错页账。
- **关系推进**：陆秋水不再求洗白，施晚晴把儿子交给陶未明保护，赵无咎承认沈红绡曾救过自己。
- **钩子**：谢三更承认调药，却说沈红绡早已喝下真正毒物；裴九重说“真正的药不在碗里”其实指人心。

### 第35章｜官府的结论
- **事件**：陶未明决定带原始验尸纸、七封信和证词册回官府；上司派封水官差封锁渡口。
- **动作**：封水官差与护院在水闸交手，柳九娘和俞听潮护船，陶未明铁尺对旧同僚；顾长亭用纸鸢把副本送出。
- **关系推进**：陶未明公开承认自己改过时间，取得部下信任；谢三更失去“只是管家”的身份。
- **钩子**：最老账房起火，火光中裴九重走出；他对谢三更说“你已经没有解释权了”。

### 第36章｜管家亲自下手
- **事件**：谢三更与阮孤灯交手未完，裴九重进入火场；谢三更用折页步杀向施晚晴，裴九重却先截住他的剑。
- **动作**：裴九重以不见功同时压住阮孤灯、明照、柳九娘、陶未明、梅照影和赵无咎；每个人的优势都被他提前改变落点。阿七只能在烟里救出茶盘和一页湿账。
- **关系推进**：裴九重称呼阿七为“陆七”，公开他寻找的真正目标；赵无咎第一次违令替阿七挡了一线。
- **钩子**：裴九重说“你藏得很好，可惜藏灯不是隐身”，火势封死七条明路。

### 第37章｜最后一个见证者
- **事件**：阿七不与裴九重硬拼，利用七条暗渠、三套错页账和顾长亭的纸鸢路线分散证词。
- **动作**：七路同时出现局部交手：柳九娘守水闸，明照护施小满，阮孤灯牵制赵无咎的旧同伴，陶未明保护证词册，阿七用回潮手把强力送回空井；裴九重赢下每一处，却无法同时追上七路。
- **关系推进**：赵无咎故意把一条错误路线交给无灯楼；俞听潮为开最后一闸受伤；阿七在众人面前承认自己当时看见换碗却选择沉默。
- **钩子**：裴九重第一次真正动怒：“你以为藏起来，就能救人？”

### 第38章｜明照脱下红盖头
- **事件**：明照完成仪式，主动揭下红盖头；最后一针指向沈红绡自己的药柜，证明她曾预留一杯无法判定的药。
- **动作**：裴九重可以杀明照，却被七份已经出庄的证词牵制；他与觉岸隔火相望，二人只交换一招，显示两代高手的差距。
- **关系推进**：明照接受姐姐可能主动选择死亡，也拒绝替她宣判；觉岸承认自己隐瞒半封信并向弟子道歉。
- **钩子**：红盖头内侧出现一句阿七从未见过的字：“不要替我替他原谅。”

### 第39章｜阮孤灯放刀
- **事件**：阮孤灯把黑刀放在山庄门外；封水官差和无灯楼追兵在渡口围住众人。
- **动作**：明照以渡厄掌截住追兵但不取命，柳九娘以七条水路分船，陶未明把证词交给不同人，阿七用玩笑和假页码制造七个出发方向。
- **关系推进**：阮孤灯承认自己仍不知道沈红绡最后想不想活，因此不再替亡者杀人；赵无咎带走一枚黑线扣，选择离开无灯楼而非加入众人。
- **钩子**：裴九重站在远处没有追，只捡起刀鞘，说“下一次，别藏在人群里”。

### 第40章｜我只是送茶的
- **事件**：谢三更的罪证、七封信、原始验尸纸和七份证词分别留存；众人离开留春山庄。
- **情节收束**：官府无法再用单一“自尽”结论覆盖所有证词；沈红绡最后是否主动服药保留两种能自洽的解释；裴九重武力未败、目标未成，仍是江湖阴影。
- **人物收束**：明照脱下红盖头但不急于还俗；阮孤灯把刀留在庄门；施晚晴带施小满离开绣房；俞听潮把闸图交给陶未明；顾长亭用最后一封假信换回自己的债契；赵无咎消失在水路尽头。
- **主角结尾**：阿七在证词末尾写下“陆七”，有人问他是不是最后见过沈红绡的人，他仍答“我只是送茶的”。转身时他对远处的裴九重笑道：“茶钱还没付。”这一次，他没有抹去自己的名字。
