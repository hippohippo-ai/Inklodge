# 阶段 2：人物

【主题】{主题}

## 固定流程

1. 读取：`state/theme.md`、`state/outline.md`
2. 把下面的内容写入 `state/characters.md`，**每个角色一节**：
   - 姓名 / 性别年龄 / 身份职业
   - **性格**：3–5 个关键词 + 一段描述
   - **目的**：他 / 她真正想要什么
   - **秘密**：别人不知道的事
   - **弱点 / 恐惧**
   - **成长弧线**：从 X 变成 Y
   - **标志性行为 / 口头禅**
3. 至少包含：主角、反派、关键配角、盟友、导师（如适用）。
4. 完成后把 `state/progress.md` 的「当前阶段」更新为 `03`。

## 规则

- 人物设定一旦写下，后续**不得随意更改**；如需更改必须走「修订记录」流程并全篇同步。
- 每个角色的「目的」是驱动他行动的唯一依据，写正文时以此为准。
