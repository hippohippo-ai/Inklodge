# 时间线｜《红盖头下的和尚》·重建版

## 一、时间基准

- 沈红绡死亡发生在当前线前三个月；官方结论为自尽。
- 当前故事集中发生在七日局，但第35–40章延伸到离庄与证词送达。
- 太湖水寨二十名好手只属于第一章开篇传说，不进入时间线。

## 四、终局延伸

| 日程 | 事件 | 结果 |
|---|---|---|
| 第8日 | 七人补齐证词，秦半夏确认最后药性存在两种解释 | 谢三更罪责闭合，沈红绡最后选择保留余味 |
| 第9日 | 陶未明带原始验尸纸、证词册和信件准备出庄；封水官差到达 | 官府结论与现场证物冲突公开化 |
| 第10日 | 账房火场，裴九重正面碾压全员 | 武力差距确立，证物开始分路 |
| 第11日 | 阿七、顾长亭、俞听潮、柳九娘等开七条水路 | 裴九重能赢局部，却不能同时追七路 |
| 第12日 | 施晚晴、赵无咎分别承担送证代价；明照脱红盖头 | 无名者不再只是被保护对象，而成为证词出口 |
| 第13日 | 渡口对峙，阮孤灯放刀，明照不杀追兵 | 裴九重选择不追，避免把局变成灭口铁证 |
| 第14日 | 证词分送至官府、寺院、船队和民间说书场 | 谢三更失去解释权，裴九重目的失败但武力未败 |
| 第15–18日 | 众人各自离开或承担后果，赵无咎消失，顾长亭还债 | 新的人情与江湖后果开始形成 |
| 第19–22日 | 阿七写下陆七，裴九重带未完成的黑印离开 | 主谜案闭合，最后药的解释保持两种可能 |

## 五、不可改动的时间边界

- 第24章前，不公开阿七与沈红绡的完整关系和“陆七”姓名。
- 第31章前，不直接让人物说出裴九重姓名；只能通过环境、命令层级和武学痕迹暗示。
- 第32章前，不完整解释七线账、七针地图和反制谱。
- 第40章前，不确定沈红绡最后一杯药究竟是主动选择还是被迫服下。
