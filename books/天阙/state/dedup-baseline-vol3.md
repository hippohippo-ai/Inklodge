## 三、比对阈值（与二卷查重一致）

1. **章内重复**：12字非重叠滑窗，命中≥1即改
2. **跨卷重复（新章 vs 二卷44章）**：14字非重叠滑窗，命中≥1即改——比二卷跨章阈值（12字）严2字，因为跨卷是"隔了20+万字"的重复，读者记忆更浅但更刺眼
3. **冻结短语**：逐字匹配，命中≥1即改（不看长度）
4. **受控呼应**：允许，但须登记章号与上下文

## 四、使用流程（每章）

```
1. 写完一章 → python state/dedup-check.py 45
2. 输出三段：F类命中 / 跨卷滑窗命中 / 章内滑窗命中
3. 全部为0 → 在 chapter-log.md 记一行：ch45 基线比对通过
4. 有命中 → 改写后重跑，通过后才可发布到 public/
```
