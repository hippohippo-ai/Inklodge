# 章节规划｜《天阙》结构修订版

## 第二卷重构（2026-08-28）

第二卷《长安劫》调整为24章，对应正文文件第21—44章。动线固定为：入长安 → 城内失序 → 潼关军报与永兴夜火 → 南门溃逃 → 马嵬坡 → 死人堆 → 渭水难民营 → 各自分路 → 东行洛阳。

### 第21—25章：城内虚火

- **第21章《长安的雨》**：押运公验入城，米价、恶钱、盘查和粮车将沈广农带入西市。
- **第22章《诗会》**：崔玉真以诗稿与具体筹码调动暗线，沈广农为确认脚夫是否被跟踪承担风险。
- **第23章《画舫》**：公孙兰传递范阳与盐运消息；沈广农被迫替受伤船工遮过搜查，形成未结清人情。
- **第24章《黑水盟粮仓》**：账房、偷粮脚夫和沈广农同场，账页被删，证物保持不完整。
- **第25章《截杀密使》**：信使遇截杀，沈广农在密信、药包和追兵之间作出取舍。

### 第26—30章：天崩地裂

- **第26章《潼关血报》**：军报、溃兵、粮车、城门和朝官车队体现长安失序。
- **第27章《永兴夜火》**：黑水盟粮仓起火，火灾破坏地下粮道，余波进入难民营。
- **第28章《夺门狂潮》**：南门踩踏与出城，沈广农失去一件物证，避免道具巧合堆叠。
- **第29章《马嵬惊雷》**：溃兵、卖水老妇、老兵和钩稽使传出马嵬消息；深蓝官服人物不是裴弘度本人。
- **第30章《死人堆》**：沈广农救出宁红叶，断角军功铁牌与照夜剑纹首次形成实物伏笔。

### 第31—36章：泥泞同行

- **第31章《照夜残剑》**：宁红叶处理伤势并救出桑葚、沈念，四人以物资和守夜交换同行。
- **第32章《叛骑截杀》**：孩子哭声暴露路线，队伍在沟渠与倒树间协作，沈广农破形受伤。
- **第33章《过载之痛》**：沈广农耳鸣失眠；宁红叶要求以证物换药，拒绝造成沈念高烧加重。
- **第34章《渭水南岸》**：难民营中井水、车板、差役和伤兵形成资源争夺；桑葚偷饼引发追打。
- **第35章《退役斥候》**：孙驼子以盐换同行，私藏军道图，与宁红叶和沈广农分别发生救人及路线冲突。
- **第36章《军营式秩序》**：裴氏钩稽使按户籍和伤势分粮，沈念被列入无监护男童，队伍面临名册选择。

### 第37—44章：各自歧路

- **第37章《粥棚对坐》**：沈广农与裴弘度第一次正面会面，谈密信、损耗和责任；冷金笺连接顾琰档案。
- **第38章《宁红叶的选择》**：宁红叶带老弱南下剑南，因药粮和孩子分配与沈广农争执，留下照夜剑鞘。
- **第39章《孙驼子的错路》**：错误军道图引队伍入水滩，孙驼子承认来源并留下断后，形成不可逆后果。
- **第40章《崔玉真的车》**：崔玉真以粮和未寄家书换盐账残页，要求沈广农将另一页送往洛阳。
- **第41章《河东风雪》**：李承洲收到迟到军报，段成、赵横、韦敬之和裴校围绕粮道、伤兵和撤防争执。
- **第42章《城墙之酒》**：李承洲弃外围城，段成抗命，谢沉璧开始记录撤离名单；崔玉真家书经中继抵达。
- **第43章《死马铁牌》**：沈广农在东行官道见到死马与缺角铁牌，因追兵逼近未掘尸，证物继续保持未解。
- **第44章《东行洛阳》**：宁红叶向南、孙驼子留在水滩、沈广农向东，第三卷从洛阳敌占区接续。

## 第三卷承接规则

- 正文从第44章沈广农东行洛阳接续，不再重复长安入城。
- 原第二卷鬼市、崔氏17暗桩和沦陷都市交易线暂存为第三卷洛阳备用素材，重写为伪燕粮卡、黑市米价、伪官印和崔氏重点暗桩，不直接复制原段落。
- 沈广农救下的漕工口供须通过黑水盟船只、牙人、信使或流民转手，写明距离、耗时和情报损耗后，才影响李承洲战线。
- 第三卷第一次正面对峙继续保留在洛阳战局后段，不能因卷末信物提前拔刀。

## 全卷返修检查规则

- 每章主角与他人的实质互动原则上达到正文50%。
- 重要配角必须带独立利益、恐惧、秘密或目标，离场留下债务、误会、伤势、证物、承诺或追索。
- 禁止“进场—扫描—取证—警告—离场”的连续副本结构。
- 禁止清单式观察、“第一/第二/第三”汇报、全员哲理腔和正文脚手架。
- 4000—5000字符目标只能通过有效交易、争执、协作、失误、物资压力和行动余波实现。
