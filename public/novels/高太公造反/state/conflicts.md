## 一、主角 vs 系统 / 反派

### C1 高太公 vs 地府官僚系统（阎罗 / 孟婆 / 鬼差）

- **根源**：亡魂被当猪宰；翠兰滞留不轮回；高太公的死期被改。
- **张力**：地府越「照章办事」，高太公越看清规矩本身是错的——从讨公道升级为造反。
- **爆发**：第13章（砸鬼门关牌子，起反心）；第21–22章（鬼门关之战、天庭介入）。
- **解决**：第39章（换了人间，地府失去生死簿，官僚机器失去执掌人命的权力）。
- **落点**：13 / 21 / 22 / 39 ✓

### C2 高太公 vs 天庭（玉帝 / 太白招安 / 二郎神镇压）

- **根源**：天庭是生死簿的幕后靠山；招安想收编他（像收编悟空）。
- **张力**：招安是骗局（翠兰轮回兑现不了）→ 高太公发现自己被当棋局的刀。
- **爆发**：第31章（上天庭、招安）；第34章（混战总爆）。
- **解决**：第38–39章（不夺权——他斩断连接，让天庭再也够不到人间）。
- **落点**：31 / 34 / 38 / 39 ✓

### C3 高太公 vs 唐僧 / 金蝉子（终极反派）

- **根源**：唐僧抹翠兰（度化八戒的代价）、间接害高太公之死（报信人被做手脚）。
- **张力**：全书暗线层层揭开——翠兰的沉默（12）→ 沙僧开口（26）→ 八戒忏悔（28）→ 观音暗示（36）→ 全揭（37）。
- **爆发**：第37章（对质）。
- **解决**：第38–39章（高太公**不报复唐僧个人**——他改的是「人间自决」，不是杀唐僧。这是主题：不夺权、不皈依、不复仇，只斩连接。**但唐僧作死**：他不死于高太公之手，而是死于自己的「慈悲的残忍」——①尘缘之箍随「人间自决」崩断，八戒不再受制于他，他唯一管得住的东西没了；②真相揭穿后西天为保体面弃他（观音放水、如来认账「这人间也该自己走一走了」），他替系统办事，最后被系统扔掉；③高太公问倒他——「你渡人，可你渡的到底是人，还是你的功德？」他一生只渡人，一个都没渡成。不是被杀，是自毁）。
- **落点**：12 / 26 / 28 / 36 / 37 / 38 / 39 ✓

### C4 高太公 vs 佛与道（如来 / 观音 / 老君）—— 人物 vs 环境

- **根源**：慈悲是宏观的，看不见具体的人；佛道之争拿人间当棋盘。
- **张力**：高太公发现连造反都是被利用的（T12：老君借刀、玉帝借势、佛门借机）。
- **爆发**：第32章（天庭勾心斗角）；第36章（上西天，观音「佛不能知道」）。
- **解决**：第38–39章（斩断连接，佛道之争失去争夺对象——人间不再是谁的棋盘）。
- **落点**：32 / 36 / 38 / 39 ✓

## 二、主角 vs 内心

### C5 高太公 认命 vs 不甘

- **根源**：一辈子认命（喂猪、种地、女儿嫁妖），死后不甘。
- **张力**：每一次受辱都把他往「不甘」推一步——地府的猪圈、翠兰的等待、死期被改。
- **爆发**：第13章（砸牌子）；第38章（执笔——最终的选择）。
- **解决**：第38章（他不再认命，也不再执念——写下「人间自决」而非复仇，认命与不甘都放下了）。
- **落点**：13 / 38 ✓

### C6 高太公 怯懦 vs 责任（对翠兰的愧疚）

- **根源**：他早觉翠兰死得蹊跷却没深究（认命里的怯懦）；收了八戒彩礼、默许亲事（觉得自己「卖了女儿」）。
- **张力**：愧疚与翠兰的「别查了」拉扯——他想查，又怕查到是自己间接害的。
- **爆发**：第12章（重逢）；第32章（翠兰真相——他怕的到底是不是自己）。
- **解决**：第38章（为翠兰写下自由轮回，卸下愧疚）。
- **落点**：12 / 32 / 38 ✓

### C7 高太公 恨八戒 vs 怜八戒

- **根源**：八戒间接害死他（报信人）、又因尘缘害了翠兰；但八戒也是受害者（被收编、被锁）。
- **张力**：父婿关系的撕裂与和解——恨是真的，怜也是真的。
- **爆发**：第28章（报信人=八戒）。
- **解决**：第39章（八戒回田里种地，猪回来了——高太公接受了他）。
- **落点**：28 / 39 ✓

## 三、盟友内部矛盾（义军）——山头与叛徒

> **义军不是一家人，是四股山头捏在一起**（各怀算盘，只靠「不下棋的高太公」捏着）：
> - **农人派**（高太公为首）：铁匠鬼/账房鬼/唱戏鬼/跟随的底层亡魂。目标：救女儿、讨公道、**人间自决**。手段：土、账、认死理。
> - **妖派**（牛魔王为首）：被收编又抛弃的妖与旧部。目标：借势**复辟妖界，要当王**。手段：蛮力、妖界规矩。
> - **冤魂派**（白骨精为首）：枉死城冤魂。目标：**血债血偿**（打死我的那根棒子）。手段：怨气、煽动。
> - **鬼差派**（牛头马面/黑白无常）：底层鬼差。目标：不当差、**有朝一日有人掀桌子**。手段：怠工、倒戈、地府地形人情。
> 山头之间有**叛徒**：一缕执念（不是人的内鬼）是明面上的；真正的叛徒在妖派——牛魔王为了「妖界复辟」，把自己二次卖回给天庭（历史重演：他当年被天庭收编时就出卖过老兄弟）。

### C8 农人派(高太公) vs 妖派(牛魔王)——山头：夺权 + 通敌

- **根源**：牛魔王入伙就想当王——他要的是复辟妖界，不是人间自决；妖派跟着他，是奔着当王来的。
- **张力**：义军越大，牛魔王的野心越藏不住；他「出卖过老兄弟」的旧账在发酵——**他当年被天庭收编时卖过兄弟，如今为了「妖界复辟」，又把自己卖回给天庭**（叛徒线，见 C10）。
- **爆发**：第19章（山头摩擦初现，泄密互疑）；第23章（执念被揪出后，妖派被疑却查无实据）；第34章（混战总爆，妖派通敌暴露，山头分裂，义军惨败）。
- **解决**：第39章（天庭二次收编照样是骗局——妖界复辟兑现不了；牛魔王被天庭再卖一次，才认清「俺早不是妖王了」，站到人间这边）。
- **落点**：14 / 19 / 23 / 34 / 39 ✓

### C9 农人派(高太公) vs 冤魂派(白骨精)——山头：救人 vs 复仇

- **根源**：白骨精想报仇（「打死我的那根棒子现在在谁手里」），高太公想救人；冤魂派要的是血债血偿，农人派要的是人间自决。
- **张力**：以暴易暴，就没资格说人间自决。白骨精的怨气是义军的旗帜，也是义军最锋利的刀——刀越利，越容易反伤自己人；妖派通敌后（第34章），她险些带冤魂派血洗，差点让「换了人间」变成另一场屠杀。
- **爆发**：第15章（入伙，旗帜）；第34章（混战总爆，她差点失控）。
- **解决**：第39章（她放下复仇，选择「被看见」——唱戏鬼的戏文记她）。
- **落点**：15 / 34 / 39 ✓

### C10 义军 vs 叛徒（两层：一缕执念 + 妖派通敌）

- **根源**：义军山头林立、各怀算盘，密谋总被泄露。泄密有两层：①**一缕执念**——马面倒卖孟婆汤残渣，执念附身最忠心的鬼卒（地府「遗忘」的残渣，不是人，是「忘不掉」的东西）；②**妖派通敌**——牛魔王与天庭私下交易，太白金星二次招安他：帮天庭按死义军，换「妖界复辟」。这是真叛徒，是人，有名字。
- **张力**：执念先被揪出，义军以为内鬼已除、互信刚恢复——真正的叛徒（牛魔王）却在最要命的时候把义军卖了（第34章）。被「不是人的内鬼」骗过之后，再被「人」背叛，比任何一次都疼。谛听听得出执念（它就在身边），却听不真切牛魔王与天庭隔界的交易——执念是真的，但不是全部。
- **爆发**：第19章（内鬼疑云，山头互疑）；第23章（揪出执念——假的内鬼，真的松一口气）；第34章（妖派通敌暴露，义军惨败）。
- **解决**：第34–39章（牛魔王被天庭二次收编照样是骗局，妖界复辟兑现不了；他认清自己，站到人间这边——叛徒回头，但伤疤留着，山头再也回不到开始）。
- **落点**：19 / 23 / 34 / 39 ✓

### C11 崔珏 vs 阎罗（判官系统内部的账）

- **根源**：崔珏签了翠兰死期造假，阎罗是知情者或装不知情。
- **张力**：崔珏双面身份——帮义军又怕暴露；账还不清。
- **爆发**：第25章（双面立场反转）。
- **解决**：第25章（坦白）+ 第38章（把判官笔交给高太公——写命的权力还给人间）。
- **落点**：25 / 38 ✓

## 四、势力之间（混战）

### C12 天庭 vs 西天（佛道之争）

- **根源**：取经是佛家东扩；老君想压住佛家。
- **张力**：高太公的造反点燃引信——两强积压千年的暗斗被点着。
- **爆发**：第34章（混战总爆）。
- **解决**：第38–39章（换了人间，佛道之争失去争夺对象——人间不再是棋盘）。
- **落点**：34 / 38 / 39 ✓

### C13 天庭 vs 地府（上下级各怀鬼胎）

- **根源**：天庭是生死簿的幕后靠山，地府是中间地带、两强争夺的棋盘。
- **张力**：混战中地府被天庭和西天拉扯。
- **爆发**：第22章（天庭介入地府）；第34章（总爆）。
- **解决**：第39章（地府失去生死簿，官僚机器空转）。
- **落点**：22 / 34 / 39 ✓

### C14 龙王 vs 天庭（龙族被捏着缰绳）

- **根源**：泾河龙王之死（西游记开端）是龙族的旧冤；龙珠被天庭捏着。
- **张力**：龙王观望 → 倒戈——人间的水，归人间。
- **爆发**：第24章（倒戈）；第34章（人间的水归人间）。
- **解决**：第39章（龙族自由，白龙马归海/见证）。
- **落点**：24 / 34 / 39 ✓

### C15 独立势力 vs 天庭/西天（谁都不跪）

- **根源**：菩提隐世、镇元子不拜天不拜佛、地藏王被誓言困住。
- **张力**：混战逼他们站边——中立不下去了。
- **爆发**：第33章（菩提点破棋局）；第34章（总爆）。
- **解决**：第39章（他们站在人间这边——地仙归土、龙族归海、菩提袖手到最后）。
- **落点**：33 / 34 / 39 ✓

### C16 悟空 vs 自己的过去（被招安的造反者）

- **根源**：他反过天，被压五百年，被套箍，成了斗战胜佛——他留住了虎皮，丢了老虎。
- **张力**：他看到高太公走了一条他没走通的路。
- **爆发**：第30章（劝诫）；第33章（选择）。
- **解决**：第33章（他让路/递刀/祝福——他没反成的，高太公反成了；虎皮裙还在他腰上，是他自己的选择）。
- **落点**：30 / 33 ✓

### C17 八戒 vs 自己的罪（尘缘之箍）

- **根源**：他成佛的代价是翠兰的命、永远不能回高老庄；他间接害死老丈人。
- **张力**：赎罪 vs 自保——他一直是吃供品的佛，不敢破戒。
- **爆发**：第28章（报信人=八戒）；第37章（作证）。
- **解决**：第39章（回田里种地——钉耙变回农具，猪回来了，赎罪生还）。
- **落点**：28 / 37 / 39 ✓

### C18 沙僧 vs 自己的沉默（见证者的罪）

- **根源**：他看见了一切（唐僧的所作所为），但不敢说——被一只琉璃盏吓出来的沉默。
- **张力**：沉默的愧疚，越积越重。
- **爆发**：第26章（开口）。
- **解决**：第37章（作证，卸下沉默的罪——沉默者的证词最重）。
- **落点**：26 / 37 ✓

### C19 孟婆 vs 遗忘本身（她也是被遗忘的人）

- **根源**：她是遗忘的化身，也是被遗忘的人——她熬了一辈子汤，忘了自己是谁。
- **张力**：她守着抹除一切的工具，自己也逃不过被抹除。
- **爆发**：第27章（汤的真相）；第36章（她的结局）。
- **解决**：第36章（「你记得你娘叫什么吗」——她自己答不上来；高太公记得。记忆赢了遗忘）。
- **落点**：27 / 36 ✓

### C20 六耳 vs 被抹除的存在

- **根源**：他是被删掉的一页，天庭旧案的受害者。
- **张力**：他要一个「存在过」的证明。
- **爆发**：第29章（登场）；第35章（生死簿真相）。
- **解决**：第39–40章（唱戏鬼的戏文记他——被删掉的人，被唱戏的记住了）。
- **落点**：29 / 35 / 39 / 40 ✓

### C21 高太公 vs 生死簿 / 命运（人物 vs 规则）

- **根源**：他的死期被人改过；翠兰「寿终正寝」是伪造的。
- **张力**：查「谁改的」贯穿全书——阎罗「死期不对」（9）→ 崔珏「改你死期的人你认识」（16）→ 招安兑现不了（31）→ 真相（35）。
- **爆发**：第35章（夺簿见真相）；第38章（执笔）。
- **解决**：第38章（他改写命运——不是改自己的，是改人间的）。
- **落点**：9 / 16 / 31 / 35 / 38 ✓

### C22 高太公 vs 孟婆（记忆 vs 遗忘）

- **根源**：孟婆要他忘，他要记得（记得翠兰、记得冤、记得自己是谁）。
- **张力**：孟婆的威胁「你敢反，我让你连女儿都忘掉」——遗忘是他最怕的武器。
- **爆发**：第17章（底牌）；第27章（汤的真相）。
- **解决**：第36章（孟婆的结局——遗忘的化身被记忆打败）。
- **落点**：17 / 27 / 36 ✓

### C23 高太公 vs 高老庄 / 人间（死后被遗忘）

- **根源**：他死了，人间照常秋收，没人记他——历史不记造反者。
- **张力**：他回高老庄，看见自己的坟和地里的新主人（第34章）。
- **爆发**：第34章（回高老庄）；第40章（土）。
- **解决**：第40章（他守着地——他不需要人间记他，他要人间自由）。
- **落点**：34 / 40 ✓
