# 天阙 - 世界观设定

---

## 一、世界背景

**时代：** 唐玄宗天宝十四载（755年）—— 唐德宗建中元年（779年）
**核心历史事件：** 安史之乱（755-763）→ 藩镇割据（764-）→ 吐蕃入侵（770-）→ 中晚唐新格局（779）

这是一部嵌入真实历史的小说。安史之乱、潼关失守、马嵬坡之变、郭子仪平叛、藩镇割据——所有大事件都是真实发生的。小说的虚构人物在历史的缝隙中行动。

**关键历史逻辑：**
- 北方决定谁能打赢
- 江南决定谁能继续打
- "粮食不够。城要破了。弟弟死了。军饷没了。皇帝跑了。敌军来了。"

## 二、武学体系：八重极境

本书抛弃传统的"内力比拼"，走向"认知与感知的升维"。

### 八重境界

| 层级 | 名称 | 描述 | 对应人物层级 |
|------|------|------|------------|
| 第一层 | **形** | 技巧、力量、速度，普通江湖高手的极限 | 普通江湖人 |
| 第二层 | **意** | 感知自身气机，剑意、刀意初成，一流高手 | 一流高手 |
| 第三层 | **势** | 借助环境，风势、水势、军势。开始脱离纯粹的肉搏 | 准一流 |
| 第四层 | **域** | 建立感知领域。五丈之内，落叶、水滴、心跳皆入感知，无法被偷袭 | 高手 |
| 第五层 | **神照** | 本书宗师境。以意识统御身体，关闭痛觉，降低心跳，进入绝对理智或无我状态 | 宗师门槛 |
| 第六层 | **天人** | 大宗师。借天地之势，在特定环境下战力翻倍。**天人受环境制约，并非无敌** | 十二宗师级 |
| 第七层 | **破界** | 绝顶高手。打破"武学常识"，改变战斗逻辑。剑不再是刺人的，而是改变敌人选择的筹码 | 独孤彦级 |
| 第八层 | **天阙** | 天下仅三人触及。一人如国，一念如军。看穿武道与天下大势的底层同构性，达到"全知"，随后走向"放下" | 沈广农最终境界 |

### 核心武学功法

| 功法 | 修炼者 | 等级 | 特点 |
|------|--------|------|------|
| 《太一归藏》 | 慕容荒 | 天人/破界 | 归纳万变，永远比敌人早半步 |
| 《天河倒卷》 | 李承洲 | 军阵武学 | 一枪改变战场十个人的位置 |
| 《照夜剑》 | 宁红叶 | 破界理念／天人境 | 不求胜，只求活，改变战斗逻辑；用剑鞘、马势、尸体作为武器 |
| 《照神经》 | 顾琰 | 观察秘法 | 通过微表情与肌肉动作读取敌人潜意识 |
| 《坐忘经》 | 澹台孤鹤 | 道极 | 消除自身存在感，代表"无" |
| 《金刚无住》 | 明空老人 | 佛极 | 绝不杀人，借力化力，代表"空" |
| 《断潮刀》 | 公孙白 | 刀极 | 绝招"断念"（打消敌方战意） |
| 《听潮诀》 | 谢听潮 | 水极 | 在水面上无敌天人，离水则弱 |
| 《太音九转》 | 虞凤池 | 音极 | 声音造成极端心理控制与感知扰动 |
| 《一苇渡江》 | 陆沉舟 | 极速 | 不比快，只比"永远在最短路径上" |
| 《万军枪》 | 萧寒山 | 兵极 | 与军阵合一，离军则弱 |
| 《天机算盘》 | 谢景 | 算极 | 一切靠计算 |
| 《无量身》 | 鸠摩摩诃 | 身极 | 断绝痛觉与情感的绝对肉体控制 |
| 《一念剑》 | 独孤彦 | 破界 | 出剑前决定，出剑后绝不改 |

### 武学核心原则

1. **天人受环境制约**：雨中剑客无敌，离雨则弱。这不是无限升级。
2. **破界是改变规则**：不是更强，而是让敌人的武学常识失效。
3. **每次突破必须伴随认知突破**：不是打坐就能升级，而是"想通了"才能突破。
4. **沈广农的无名武学**：从"看见以后再动"起步，最终演化为"看穿天下因果"的无名之境。

## 三、四层立体势力图谱

势力间并非非黑即白，而是围绕各自的生存逻辑运转。

### 第一层：天下大势（国运争夺）

| 势力 | 代表人物 | 核心诉求 |
|------|---------|---------|
| 大唐朝廷 | 郭子仪、李光弼 | 极力恢复中央集权 |
| 河北藩镇 | 史思明及后继者 | 为保军权拥兵自重 |
| 回纥/吐蕃 | — | 外部施压者，促使唐廷与藩镇后期不得不妥协 |
| 江南财阀 | 顾氏 | 控制钱粮盐铁。"北方决定谁能打赢，江南决定谁能继续打" |

### 第二层：江湖显宗（武林表象）

| 势力 | 特点 |
|------|------|
| 太白剑宗 | 天下剑客圣地，内部因"是否入世"分裂 |
| 烂柯寺 | 佛门圣地，面临"止杀"与"救人必杀"的教义冲突 |
| 墨门 | 机关、战船、冶炼的垄断者（首领公输野），不争霸，但各方拉拢 |

### 第三层：幽暗深渊（幕后操盘者）

| 势力 | 领导者 | 特点 |
|------|--------|------|
| 观天台 | 顾琰（核心）→ 分裂 | 存在300年的情报分析机构，宗旨"记录规律、利用规律"，分化为观、衡、执、藏、天五脉 |
| 黑水盟 | 谢景 | 最大的地下商业网络，控制战争黑市，不杀人只赚钱 |
| 夜行司 | — | 皇权直属杀手，处理不能写进史书的肮脏事 |
| 白衣楼 | 白玉京（代号） | 顶级刺客组织，只接"改变历史节点"的单子 |

### 第四层：极境隐士（文明守墓人）

| 势力 | 特点 |
|------|------|
| 天门遗脉 | 掌握古代历法、心理、数学的最高组织（裴弘度所属） |
| 终南"无名社" | 澹台孤鹤等七名老怪物，不干涉天下，只负责在有人试图妄用"天阙"时出手抹杀 |
| "无名"网络 | 一群曾经接触过天阙的普通人/高人，平时互不相识，危局时却会做出共同选择 |

## 四、榜单体系

> 详见 `rankings.md`（完整榜单）

### 《天下宗师录》
- 问的是：**"你有多高？"**
- 十二席，不是排名，而是武林共识
- 入选条件：武学跨过普通层级 + 至少三名顶尖高手确认 + 江湖各势力承认 + 足够长的江湖履历

### 黑榜
- 问的是：**"你有多危险？"**
- 十人，有明确排名
- 评价维度：武功 × 情报 × 势力 × 性格 × 不可预测性 × 历史影响
- 每三年重新排一次（是剧情工具）
- **779年黑榜取消**——沈广农最终明白：把人按危险程度排序，本身就是试图掌控人

> **"宗师录论武，黑榜论杀，裴弘度论天下。"**

### 八凶
- 问的是：**"你有多要命？"**
- 八人，不是组织，彼此互相厮杀
- 武林正道无法容忍的人

## 五、核心机构：观天台

- 存在300年的情报分析机构
- 宗旨："记录规律、利用规律"
- 五脉分化：观、衡、执、藏、天
- 并未制造安史之乱，但提前准备了"乱世吃人模型"来收割天下
- 顾琰从小被培养在其中，最终叛逃
- 沈广农从小就被列入"筛选名单"
- 宁红叶是"绝对理智实验"的失败品

---

## 六、核心机构：天门/天衡

- 天门不是仙术，而是武、医、兵、算的集合
- 裴弘度继承天门计划，意图建立"天衡体系"
- 天衡 = 一套即便皇帝昏庸也能自动运转的制度
- 核心理念：制度胜过圣君
- 最终结局：部分设计被保留（限制军权、财政制衡、权力监督、信息公开），部分被摧毁（由系统决定什么是正确）

沈广农在卷一获得残卷："天宝十四载起，十四年止"。他以为是预言，其实这是上一代天阙者留下的"十四步救世/灭世棋谱"。
