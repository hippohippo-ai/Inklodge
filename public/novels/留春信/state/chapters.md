# 章节规划｜《留春信》·重建版

> 正文硬标准：每章实际 UTF-8 字符 4000–4500；不得用标题、空白行、重复对白凑数。每章至少有一条人物关系推进、一件可触摸的证物变化、一次具体空间或武学冲突和一个改变下一章路线的钩子。

## 卷一：红灯引路（第1–8章）

### 第1章｜月色如水
- **地点 / 人物**：太湖渡口、柳家货船；阮孤灯、明照、柳九娘、陶未明、梅照影、谢三更，后半段阿七。
- **核心事件**：保留月色、黑刀、红盖头和尚和阮孤灯十三岁一刀杀二十名太湖水寨好手的传说；众人因七封信登船。
- **情节密度**：谢三更以管家身份清点客人与行李，陶未明发现邀请信上的官印年份不对；梅照影听出船外有三组不同水声；柳九娘拒绝搜阿七的茶箱，因为茶箱里藏着一枚沈红绡的空白红针。
- **动作**：黑线杀手从船底、桅杆和水面同时袭击，阮孤灯三刀改变近身距离，明照以渡厄掌卸镖，柳九娘用短桨断索，陶未明卡舱门，梅照影以听声辨出真正杀招；阿七用收缆和茶盘救下一封无名信。
- **关系推进**：阮孤灯发现明照耳后旧疤而手抖；阿七第一次用玩笑让明照把茶喝完；谢三更看见阿七看见了不该看的水痕。
- **钩子**：船抵庄门，门内七条黑路同时传来水声，门外药水顺缝流出；无名信上只写“第七个人不要进门”。

### 第2章｜船上第七个人
- **地点 / 人物**：留春山庄庄门、七路水廊；全员、施晚晴、俞听潮、阿七。
- **核心事件**：七张请帖对应六位普通宾客和一名引魂替身明照；阿七没有请帖，借柳家船上杂役身份入庄。施晚晴以绣房管事身份迎接，俞听潮修闸时故意不看众人。
- **情节密度**：七道门各有不同水声，陶未明按门钉判断有人刚从内侧锁过；施晚晴发现红盖头边缘少了一针；俞听潮的闸杆上有阿顺留下的三圈绳结。
- **动作**：水下弩、倒灌火油和暗门短刀同时启动；陶未明以铁尺封闸，明照借墙卸力，柳九娘以船钩拉人，阿七只凭听水和脚下受力避开塌板，并让火油流入空池；他不能单靠臂力翻越障碍，必要时由同伴借绳、船钩和断桨接应。
- **关系推进**：施晚晴认出阿七，却故意称他“新来的小工”；俞听潮对阿七的绳结动作多看一眼；赵无咎在暗处第一次看见阿七。
- **钩子**：从空木箱里取出的封蜡簧匣奏出沈红绡的暗号：“第一封信，不要给最想看的那个人。”七枚短箭钉入门廊。

### 第3章｜红色的请帖
- **地点 / 人物**：七灯小厅、婚房前廊；增加顾长亭（伪装成送信脚夫）。
- **核心事件**：红色请帖宣布七日补婚；明照承认沈红绡是姐姐；顾长亭来取一封被退回的私信。
- **情节密度**：请帖上的红墨遇水变黑，七盏灯按不同顺序熄灭；秦半夏从纸张药味辨出请帖曾在药房；顾长亭看见信封上的旧戏楼印却不承认。
- **动作**：无主影子从灯顶取帖，细针从灯罩落下；阮孤灯以刀鞘护人不出刀，明照用掌风改变针路，阿七故意撞翻茶水让顾长亭逃过一枚毒针。
- **关系推进**：阮孤灯认出明照耳后疤与沈家旧伤相同；顾长亭欠阿七一次救命，却只把他当没名字的杂役。
- **钩子**：请帖最后显出“新娘已经死过一次”；红盖头里有一根针自行断裂，针尖指向绣房。

### 第4章｜绣房里的第二只袖口
- **地点 / 人物**：绣房、婚房；施晚晴成为核心视角。
- **核心事件**：众人调查红盖头缺针，施晚晴声称自己只缝过一件婚衣；却有一只带血袖口在绣架后出现。
- **情节密度**：红丝在雨气中收缩，绣架暗格藏着第二只药碗的碎片；施晚晴的针线不是装饰，而是能绊住手腕的机关；谢三更带护院来收回婚服。
- **动作**：四名护院从绣架、门槛和梁上合围；阮孤灯三刀只断弩弦、袖口和退路，明照以掌力救下施晚晴，阿七用绷线和门闩改变护院重心。
- **关系推进**：施晚晴在众人面前替谢三更撒一次谎，却悄悄把血袖口推给阿七；阿七发现袖口绣纹与赵无咎黑线相同。
- **钩子**：灵堂方向传来沈红绡的笑声，笑声里夹着“不要找棺材，先找替我缝衣服的人”。

### 第5章｜没有棺材的灵堂
- **地点 / 人物**：无棺灵堂、地下拖棺道；秦半夏、陶未明、俞听潮重点出现。
- **核心事件**：陶未明发现棺材被沿地下木轨拖走；第一封信从香灰里露出，指向“替她收药的人”。
- **情节密度**：黑水从七只空碗底上涨，香灰中的纸被药烟熏出双层字；俞听潮发现拖棺道连接旧水闸，承认图纸是自己设计的。
- **动作**：护院用白烟封门，秦半夏以药针救陆秋水，阮孤灯在三寸视野里断掉燃着的红线，阿七把湿布和香灰压在水口；陶未明用铁尺锁住一名护院的肘。
- **关系推进**：俞听潮承认阿顺曾在死亡后夜来过这里；谢三更第一次不再说“沈姑娘只是太累了”，而是抢走半张信。
- **钩子**：秦半夏说沈红绡死前没有喝过她开的原方；黑砂遇水只显一个“迟”字。

### 第6章｜第一个红结
- **地点 / 人物**：药房、药柜暗门；秦半夏、阿七、施晚晴、赵无咎。
- **核心事件**：红盖头第一处针脚指向药房；秦半夏必须在真药碗和假药碗之间做判断，赵无咎第一次正面试探。
- **情节密度**：封息烟贴地流动，药味被风门切成三层；真碗的裂纹向内，假碗裂纹向外；施晚晴的红丝缠住一枚暗针却不敢出声。
- **动作**：赵无咎以黑线绕腕、短刃反刺，阮孤灯在窄门外与他隔三寸对刀；明照以掌力把毒烟推向空柜；阿七用茶盘、水柜和回潮手让真碗漂回。
- **关系推进**：阮孤灯从赵无咎刀路里认出沈红绡教过的救命步；赵无咎故意不杀阿七，却夺走一枚红针。
- **钩子**：药柜内壁写着“碗是真的，药是假的”；第一处红结熄灭，谢三更宣布封锁药房。

### 第7章｜柳九娘的空木匣
- **地点 / 人物**：药房外水廊、空木匣处；柳九娘、俞听潮、顾长亭。
- **核心事件**：柳九娘交出空匣；七道刻痕不是七封信编号，而是七条水路的闸位。
- **情节密度**：蓝火沿药粉走水，匣底暗针受水压弹出；顾长亭认出匣上旧戏楼符号却想偷走；俞听潮从匣底震动听出墙内有空心竹管。
- **动作**：谢三更抢匣，阮孤灯用刀鞘挡手；柳九娘以短桨击落火把，阿七用茶碗改变重心、托盘压水取回湿信；墙内影子以水钩逃走。
- **关系推进**：柳九娘承认曾替沈红绡守过婚房一夜；顾长亭欠柳九娘一笔船钱；阿七第一次主动替一个陌生人藏住证物。
- **钩子**：第二封信写“你不是没看清，是不敢看清”；水线指向雨声房。

### 第8章｜第一盏灯
- **地点 / 人物**：雨廊、庄门、七间客房；全员、赵无咎的七名同伙。
- **核心事件**：七日局正式开始，庄门被铁链封死；外来杀手与庄内护院并非一队。
- **情节密度**：雨廊水位涨到脚踝，红线随水改变方向，七门机关互相传力；梅照影听出左廊三人、右廊四人，施晚晴听见绣房有人哭。
- **动作**：七名杀手与护院混战；阮孤灯断棍不杀，明照护住陶未明，柳九娘以钩拉线，秦半夏救陆秋水，阿七用门闩改变水流救下簧匣。
- **关系推进**：赵无咎在退走前看见沈红绡声音装置保护的是“无名人”；谢三更确认自己不能控制所有杀手。
- **钩子**：门外出现比明照更深的掌印；裴九重尚未现身，但雨廊水面先退了一寸。

## 卷二：七封信（第9–16章）

> **空间体感差异化**：第9章药房主打窒息与视线剥夺（封息烟、不能呼吸、盲摸辨位）；第10章账房主打高温与时间竞速（纸遇火即燃，几十秒抢页码，不算盘不谈情）；第12章极窄婚房主打零距离幽闭与情绪崩溃（机关被洪水泡发卡死停不下来，施晚晴看水漫过儿子的带血小鞋而崩溃）；第14章水道水闸主打流体动能与载具拖拽（颠簸小舟、湍流暗礁、绞盘铁索，无人能站立对刀）。
> **熵增定律（本卷总纲）**：前面的机关越精巧，后面越破碎；前面的人越体面，后面越狼狈；前面阿七越是从容，后面越要让凡人肉身的极限显现。灾变必须脱离所有人的控制，包括反派。①机关熵增：第12章之后婚房/禁房/雨声房的机关一律因水压火烤而卡死失控（墙板收拢一半楔死、铜环锈住、暗门被断梁砸变形），禁止精巧机关运转。②空间破碎：第10章账房烧塌横梁砸穿墙壁，人物从破洞直接滚进绣房/婚房，不走完整“进房—出门—再进房”动线。③反派熵增：赵无咎第12、13章不出现（黑线在水火中施展不开），他只作为灾变求生者在断梁砸下时与阮孤灯短暂背靠背求生，背靠背那场戏落地 F-14（沈红绡教过刀理）；谢三更第13、14章长袍烧烂满脸泥水、兵器换成断木铁钩骨针，从优雅管家变成疯狗；裴九重卷二正文只允许第9章试探与第16章总结开口，中间章节一律不出声，存在感靠环境（某条安全水路被人用铁水浇死、风门卡死方向、红线改向方式）。④阿七代价递进：第10章茶盘烧掉一半、头发燎焦呼吸道灼伤（此后干咳体力下降）；第12章握发烫残木垫门掌心严重烫伤；第13章用残破木板引流手臂割开长口子；第16章骨裂脱臼是左手烫伤＋割伤累积肌肉痉挛、摸暗闸慢半拍被铁齿咬住，不是突然算错。⑤证物变体：静态“遇水显字”仅允许一次，改为物理痕迹（第9章药碗相击听声、第10章铁珠算盘磨损、第11章听声不读字）。
> **链式灾害必须跨章累积，禁止单间清场复位**：第9章药房毒烟不散；第10章账房起火后，火热气流把毒烟倒吸进通风道，第11章雨廊众人同时面对“上层火烟、下层毒雾”夹击；第10章烧塌的地板损坏地底水管，第14章水闸全开时洪水顺裂缝冲入，第15–16章禁房承重柱被冲歪，雨声房成为全庄水网主枢纽断裂点。
> **破案方式**：秘密靠利益交换、保命本能和实物证据当场戳穿，禁止挤牙膏式认罪。施晚晴开口是因为谢三更拿出施小满带血的鞋，明照抢下鞋保证孩子安全，她才扔出带血袖口；陆秋水不认改账，直到陶未明以铁珠算盘第三颗档位的磨损指出“你算的是双份银子”。某些信件打开后是沈红绡生前故意留下的挑拨信（例如“今夜进门者为柳九娘”），必须由陶未明现场勘验去伪存真，团队不无条件互信。
> **节奏下坠滑梯**：第9–10章局部危机闷烧（自保有余、证物争夺）；第11–13章中度失控（团队内讧分流、退路被堵、人质危机）；第14–15章系统瘫痪（阿顺尸体、水闸全开、明照掀盖头、承重崩溃）；第16章全面崩盘（阿七伤势累积至极限、证物碾碎、雨声房主枢纽爆裂、全员被洪水冲出山庄）。

### 第9章｜药碗里的月光
- **地点 / 人物**：药房、封息烟道；秦半夏、陆秋水、赵无咎、阿七。
- **事件**：第一封信真正开启，要求秦半夏交代药方被改的那一刻；两只药碗在烟中争夺。裴九重本卷第一次也是唯一一次试探性开口（隔雾一句，角色不取名）。
- **动作 / 证物**：赵无咎从药柜后夺碗，阿七用碎碗反射灯影辨真假，明照封住药柜门，阮孤灯以湿木板改变刀路；黑砂显“迟”。
- **关系 / 暗线**：秦半夏承认师门供过延迟方；陆秋水替她藏一张药材票，形成互相牵制。
- **钩子**：无头影子在白烟中饮下药，药碗底浮出“第二只手”。

### 第10章｜账房先生
- **地点 / 人物**：账房、东窗火道、被烟倒灌的雨廊；陆秋水、陶未明、顾长亭、谢三更，后续全员被迫分流。
- **事件**：第二封信打开暗柜，陆秋水发现副账被复制；顾长亭来取旧信。火沿油灯架、纸帘和地板干沟蔓延，浓烟穿过通风缝倒灌雨廊；烧塌的横梁砸穿墙壁，人物从破洞直接滚入绣房方向，账房和庄内水网同时失控。阿七的茶盘被烧掉一半，他为救账本头发被燎焦、呼吸道灼伤，本卷此后持续干咳、体力下降。
- **分组 / 博弈**：阮孤灯、明照、施晚晴在雨廊硬挡火线和追兵；陶未明、陆秋水、谢三更留在账房，陆秋水故意把一包药渣踢进火里灭证，谢三更借此逼他交出副账；阿七、梅照影、顾长亭沿后窗摸索出路，各自隐瞒一段路线。
- **高手 / 证物**：陶未明只凭谢三更把“东窗”说成“西窗”和鞋底的干泥，反推他提前走过外廊；他用铁尺打断门轴，硬拆出逃生口；又从火堆里抢出半截铁珠算盘，指出第三颗档位磨损得不对，陆秋水手里整套账“算的是双份银子”，铁证之下陆秋水才松口。顾长亭带走湿账一角，浓烟把其余页码熏黑，火势遗留到第11章雨廊。
- **钩子**：湿账浮出三笔同日空账，页脚有沈红绡给“纸鸢”的圆点；雨廊尽头的水位开始上涨，火星顺油膜漂向下一组人。

### 第11章｜盲人听见火
- **地点 / 人物**：雨廊、封水闸；梅照影、俞听潮、铁钉鞋刺客（水下），赵无咎只在水下远处收走鞋钉、不露面搏斗。
- **事件**：第三封信逼梅照影说出死亡夜声音；护院已经死在火里，不排队打护院；廊下水位上涨，火星沿油痕漂来；账房余火把药房毒烟倒吸入通风道，雨廊上层是火烟、下层是毒雾，众人只能伏低换气、边跑边呛。
- **动作 / 证物**：铁钉鞋刺客利用水下铁钩，梅照影以水滴、呼吸和鞋钉辨位；阿七用木桶截火、干咳着递水，俞听潮关闭一半闸门。
- **关系 / 暗线**：梅照影承认听见三种脚步；俞听潮发现阿顺的闸杆刻痕属于第三个人。
- **钩子**：黑靴主人不出声地在雨廊尽头出现，存在感全靠风门卡死方向与红线改向方式；谢三更手里纸团展开为“管家听见门”。

### 第12章｜刀客不杀人
- **地点 / 人物**：极窄婚房、红烛、窗廊；阮孤灯、明照、施晚晴、谢三更（无赵无咎）。
- **事件**：婚房的机关被洪水泡发、卡死停不下来——墙板收拢一半楔死，床柱和衣柜向内挤压，退路被家具吞掉；谢三更趁乱夺带血袖口与红针，明照渡厄掌第一次废人腕骨，施晚晴看水漫过儿子的带血小鞋而情绪崩溃，主动砸开暗格交出带血袖口，阮孤灯刀锋在极窄空间里只削袖不杀人。
- **动作 / 证物**：阿七手握第10章烧剩的发烫残木去垫门，掌心严重烫伤；刀光贴着床柱走，明照掌力把卡死的墙板引向地面。
- **关系 / 暗线**：明照看到姐姐婚衣袖口内绣着半个沈家旧印；施晚晴崩溃后第一次完整说出“袖口换过”。
- **钩子**：袖口被夺走一角，药碗却被窗外看不见的人用线钓走；卡死的墙板只剩一道缝，退回的路被水封死。

### 第13章｜女医的手
- **地点 / 人物**：药房后库、染线室；秦半夏、施晚晴、陆秋水、谢三更（无赵无咎）。
- **事件**：秦半夏检验黑砂，药针盒被调包，三枚救命针变成封穴针；陆秋水中毒倒下。秦半夏为分辨毒性以身试毒，右手短暂瘫痪，只能左手施针；谢三更长袍烧烂、满脸泥水，兵器换成断木和铁钩，从优雅管家变成疯狗。
- **动作 / 证物**：药粉和染线混合成追踪烟；施晚晴用红丝绑住儿子留下的木牌，阿七用第10章烧剩的残破木板引流、手臂被割开长口子，循药味追进私库。
- **关系 / 暗线**：秦半夏承认老师曾供过无灯楼；谢三更拿出施小满带血的小鞋逼施晚晴改口，明照抢下鞋子、承诺孩子安全，施晚晴才在崩溃中承认袖口是她换的。
- **钩子**：黑砂遇旧药方显出“迟”字下半行：真正的药不在碗里。

### 第14章｜水闸里的第二封信
- **地点 / 人物**：水闸、暗渠、柳家小舟、被洪流撞开的禁房承重墙；全员在水势中被拆成三组。
- **事件**：第二封信要求柳九娘说出谁进过婚房；水闸突然全开，洪流穿过庄内暗沟和账房烧塌后破损的地底水管，冲垮禁房一侧承重墙；空匣、顾长亭和几件证物各自漂向不同出口。小舟在急流里打转，无人能站立对刀。另有一只木盒打开后是沈红绡生前故意留下的挑拨信，信里写“今夜进门者为柳九娘”，众人立刻拔刀相向，靠陶未明验纸浆、验墨痕才辨出是旧信伪证，团队信任第一次被当面撕开。
- **分组 / 博弈**：阮孤灯、明照、施晚晴负责在狭窄闸口挡住追兵，施晚晴却偷偷把陆秋水的假账塞进陶未明的公文袋，引开谢三更；陶未明、陆秋水、谢三更在被水浸的账袋旁互相拿捏，陆秋水承诺交一页真账换身契；阿七、梅照影、顾长亭摸向芦苇外水道，各自不说自己真正要找的物件。
- **高手 / 证物**：柳九娘凭船帮经验调动两艘废船，俞听潮从地底震动听出活闸位置，徒手砸开闸盖，洪流才分出一条可走的水口；柳九娘短桨折断后，阿七用绑在腰上的绳子把自己当人肉锚点拉住船尾，不能替所有人改水路。
- **关系 / 后果**：禁房墙裂延续到第15–16章；空匣保住，湿账被水撕掉一页；赵无咎在水下救出顾长亭，却把第六封信的一角交给看不见的第三人。
- **钩子**：水流冲出一枚不属于柳家的船钉，远处禁房木鱼被洪声撞响，整座庄子的水位开始同步上涨。

### 第15章｜和尚犯戒
- **地点 / 人物**：洪水冲裂的禁房、外廊、庄西逃生坡；明照、陶未明、施晚晴、觉岸、阮孤灯、阿七、赵无咎（灾变求生者，断梁砸下时与阮孤灯短暂背靠背）。
- **事件**：洪流冲垮禁房承重墙，机关杆不是运转而是被承重断裂带着崩解。明照为找姐姐信件掀开红盖头，露出耳后旧疤；禁房已不是独立关卡，而是整座庄子失衡的中心，梁柱在头顶一根根砸下。
- **分组 / 博弈**：阮孤灯、明照、施晚晴在墙内硬挡铁网和追兵；陶未明、陆秋水、谢三更在外廊争夺湿账与公文袋，谢三更主动把一名护院推入水沟灭口；阿七、梅照影、顾长亭沿断墙寻找通往雨声房的旧路，顾长亭故意给阿七一条假方向以保住自己手里的信。
- **高手 / 证物**：明照独自以渡厄掌托住铁网并救出顾青禾；阮孤灯为救明照，一刀劈向正在合拢的铁机关墙，刀刃卡在生铁柱上崩出一个豁口（名刀受损，江湖旧规矩被暴力撕裂）；断梁砸下的一瞬他与赵无咎背靠背求生，黑线缠住梁端泄力，F-14 沈红绡教过刀理在此自然落地；陶未明只凭谢三更袖口的黑泥判断他从水闸来过，反手锁住其退路。
- **关系 / 暗线**：觉岸被迫承认半封信；施晚晴承认红针不是婚饰而是停手记号；阿七在断墙后看见木牌背面字迹被水泡糊，没有露出姓名，茶盘底的黑印被洪水卷向雨声房。
- **钩子**：木鱼声不再来自禁房，而从庄外地下传来；雨声房的横梁开始连续断裂。

### 第16章｜雨声房外
- **时间 / 地点 / 人物**：第4日黎明；雨声房、被砸穿的地下主暗渠、庄西废闸、废弃旧码头；全员在洪水中分流。
- **事件**：雨声房不是一间房的坍塌，而是整个庄子水网的主枢纽断裂。地下主暗渠被横梁砸穿，灵堂黑水、账房余火和水闸洪流汇成一股，墙、路和证物一起向庄外溃散。
- **分组 / 博弈**：A组阮孤灯、明照、施晚晴负责硬挡落梁并护施小满；B组陶未明、陆秋水、谢三更在冲毁的账道里争夺剩余页码，谢三更主动撕掉一页真账；C组阿七、梅照影、顾长亭寻找活闸，顾长亭隐瞒自己已拿到一角黑印。
- **高手 / 失手**：俞听潮凭耳朵听出地底三丈的活闸，徒手砸开闸盖；阮孤灯为救明照，直接劈断合拢的铁墙与承重石柱；明照托住落梁把施小满送过断口。阿七的左手从第10章烫伤、第12章烫伤、第13章割伤一路累积，摸暗闸时肌肉痉挛慢了半拍，加上裴九重提前动过的反扣暗线，铁齿反咬他的手臂，湿账副页和黑砂药碗同时被碾碎，秦半夏为拖他离开肩部受伤。
- **关系 / 后果**：阿七失去最能证明换碗的两件物证，手臂重伤，第一次无法靠小聪明救全所有人；俞听潮命令他以后只听现场水声，不准凭旧记忆下注。赵无咎在废闸截断追兵，却把一枚黑印交给裴九重的信使。裴九重作为旁观者做卷二的唯一一次总结收网（隔水说一句，不露面、不取名）。
- **钩子**：众人被洪水冲到庄外不同地貌：阮孤灯、明照、施晚晴落入芦苇荡，陶未明和陆秋水漂到旧码头，阿七、梅照影、顾长亭被冲向废戏楼；天亮后，官府告示把他们全部列为水匪同党。

## 卷三：出庄之后（第17–24章）

> 本卷从第16章黎明开始扩张到庄外。每章的主要空间、天气和社会压力不同；人物不再按房间轮流吐证词，而是在路上、船上、台上和公门中争夺谁有资格讲述沈红绡之死。
> **Boss 存在感阶梯（本卷硬验收之一）**：第17章仍只出现“门外的人/黑靴/命令”，人物不知道名字；**第18～20章必须正式把“裴九重”和“无灯楼”的名字推到台前**——旧戏楼旧案卷与顾长亭债契点名，县衙假封水令/伪验单上的暗印点名，县令见了条子不敢接状纸；第21～24章全员在明确知道对手名字的情况下逃亡、拆分证词和收网。名字先于真身（第31章）出现是硬规定，严禁把名字憋到第31章。

### 第17章｜芦苇荡里的荒庙
- **时间 / 地点 / 人物**：第4日上午；庄外芦苇荡、荒庙和废渡船；明照、施晚晴、施小满、秦半夏。
- **事件**：A组被洪水冲入芦苇荡，施小满发热，施晚晴必须在带孩子逃生和回头找证物之间选择；无灯楼死士沿芦苇水痕追来，荒庙成为短暂遮蔽而非安全房间。
- **动作 / 破局**：明照独自护住三人，渡厄掌把死士逼入泥滩；最后一名死士挟持施小满，明照为救孩子第一次杀生，掌力落下后在血泊中失神，秦半夏强行把他拉出庙门。施晚晴主动把一枚假红针塞进死士衣中，引开第二队追兵。
- **关系 / 代价**：明照破戒，施晚晴不再把“保护”当成替孩子决定一切；秦半夏发现自己手里的真正药碗已经碎了，只能改救活人。
- **钩子**：荒庙墙上留着沈红绡的水墨圆点，指向废戏楼；远处传来阮孤灯与赵无咎交刀的声音。

### 第18章｜旧戏楼的两把刀
- **时间 / 地点 / 人物**：第4日下午至入夜；外围旧戏楼、塌台、风急的湖岸；阮孤灯、赵无咎、梅照影、顾长亭。
- **事件**：阮孤灯循交刀声截住赵无咎，顾长亭带着原始验尸草纸残角躲在幕幕后。裴九重的信使放火烧台，逼两名刀客在火与风中决出谁能带走证物。
- **动作 / 破局**：阮孤灯不等赵无咎退入暗处，直接一刀斩断合拢的铁幕和承重木柱，刀势霸道地劈开逃路；赵无咎以黑线缠住刀柄，二人以命搏刀。旧约在刀光中自然露出：阮孤灯当年放走的人正是赵无咎要找的白砚生。
- **关系 / 代价**：阮孤灯没有杀赵无咎，却被黑线割伤手腕；顾长亭救出草纸但烧掉戏单，梅照影从台下鼓皮听出裴九重已经把假验单送往县衙。
- **Boss 名字点名（第一处）**：顾长亭被烧的债契角上印着“无灯楼”三个字和一枚圆印，旧戏楼后间翻出的旧案卷里有一份十三年前的修渠公文，落款“裴九重”笔迹与债契上催债批注完全一致。梅照影顺口说出她曾听说书场讲过“听讼修渠起家的裴九重”这个名字——人物第一次读到/听到全名，确认谢三更背后有具体的人和字号，而不是一个无名影子。阮孤灯不用这个名字报复，只是把名字和人一一对上了。
- **钩子**：旧戏楼外响起官差号角，谢三更带着封水文书抵达，所有出路同时被官府和无灯楼堵住。

### 第19章｜渡厄寺外潮
- **时间 / 地点 / 人物**：第5日清晨；渡厄寺外的潮滩、晒经石和渡口，不进入寺内密室；明照、觉岸、秦半夏、施小满。
- **事件**：觉岸交出半封信，却要求明照先承认自己愿意听见姐姐的坏消息。无灯楼杀手借涨潮冲上潮滩，目标是半封信和施小满。
- **动作 / 破局**：明照独自以渡厄掌把三名杀手的冲势引入潮沟，再用寺外石柱和潮水卸力，明确完成一次不依赖阿七的战斗；秦半夏在岸边判断潮毒，救下被划伤的施小满。
- **关系 / 代价**：明照不再接受觉岸替他删信；觉岸承认沈红绡曾把明照托给寺院，是为了让裴九重找不到“弟弟”而非为了隐瞒真相。**老人第一次在明照面前把“裴九重”三字说出口，并说明他当年正是在县衙听讼时见过这个名字落在一份渠工账上**——名字由上一章的纸面证据变成活人的证词，明照知道姐姐一直在躲的是谁。
- **钩子**：半封信提到“第五日午后，县衙会收到一份假的尸格”。

### 第20章｜县衙的两道门
- **时间 / 地点 / 人物**：第5日午后；县衙外街、验尸房、档案库与水门；陶未明、陆秋水、顾长亭、谢三更。
- **事件**：谢三更让官府把证人分押两处，准备借转押灭口；陶未明必须在听从上峰和保护一群通缉犯之间做选择，陆秋水则拿自己的两套页码向两边下注。
- **动作 / 破局**：陶未明凭交接时辰、口误和书吏袖口泥痕拆穿伪验单，铁尺当众封住领队手腕；陆秋水主动把真副账交给县令，却把一页假账留给谢三更，顾长亭从水门送出副本。
- **Boss 名字点名（第二处·制度碾压）**：拆穿的伪验单与假封水令压在案角的暗印花纹，和旧戏楼债契上的圆印是同一枚；县令见到谢三更带来的“无灯楼条子”后不敢接陆秋水的状纸，让陶未明第一次当众说出“裴九重”三个字——不是江湖传闻，而是官盐、封水和见证人全被同一只手的条款压住。谁签的名、印泥新旧、条子递进二堂的过程都写实，让“无灯楼控制官府版本”成为可验证的事实而非旁白。
- **关系 / 代价**：陶未明失去捕头腰牌，成为保护证人的逃犯；谢三更第一次在公开场合失去解释权，却从陆秋水的假账中反推出阿七仍活着。
- **钩子**：县衙门口贴出新告示，沈红绡案暂停公开审理；城外暴雨将至，所有船只不得离港。

### 第21章｜集市上的背叛
- **时间 / 地点 / 人物**：第5日黄昏；城南集市、茶棚、纸马摊；阿七、陆秋水、顾长亭、施晚晴。
- **事件**：顾长亭要把七条线的抄件交给不同传信人，裴九重用假信和赏银让人群互相指认。阿七肩伤未愈，误认两名信使，关键副本落入追兵手中。
- **动作 / 破局**：阿七拒绝用藏灯式遮掩错误，主动站到街心承认判断错了；陆秋水用账房编号追回真正信使，施晚晴主动把假账塞进陶未明的包引开谢三更，顾长亭当众烧掉假信，自己暴露在悬赏下。
- **关系 / 代价**：阿七失去“总能看准”的保护层，陶未明把错误写进案册；陆秋水和施晚晴第一次主动互相利用又互相补偿。
- **钩子**：假信灰里留下裴九重圆点，城外雨声压过集市锣鼓，所有人被逼向雨夜渡口。

### 第22章｜湖上葬灯
- **时间 / 地点 / 人物**：第5日深夜；城外湖面、七艘葬灯船、废浮桥和被风推散的芦苇；柳九娘、梅照影、阮孤灯、明照、施晚晴、阿七、顾长亭。
- **事件**：集市失手后，众人借一支为溺亡船工送灯的船队出城。裴九重没有派人封死一条水路，而是让三艘火船混进葬灯队，官差从岸上发布“水匪不得渡湖”的假令；七艘船一旦挤在同一条水道，火油便会顺风连烧。
- **分组 / 博弈**：柳九娘和梅照影在船队外圈辨风向、听橹声，必须决定舍哪一艘空船；阮孤灯、明照、施晚晴在中船护住施小满与烧焦鞋钉，明照负责把被火逼下水的人托回船沿；阿七、顾长亭和陆秋水在后船分开三份副本，顾长亭想把真页带走，陆秋水却要用它换回身契。
- **高手 / 证物**：梅照影凭七盏葬灯在风中的高低变化听出真正的火船，柳九娘当机立断割掉满载纸灯的缆绳，以七船错位避开火线；这是她第一次为保人主动牺牲一船货。阮孤灯在船头斩断燃烧的长篙，明照从翻船者手里夺回烧焦鞋钉，二人各自完成破局，阿七没有替他们改水。
- **关系 / 代价**：柳九娘的船队损失一艘，船帮从此不能再假装置身事外；陆秋水把一页真账塞进葬灯纸骨，暂时瞒过顾长亭，三组人重新汇合时彼此都少了一件东西。
- **钩子**：火船沉没前撞上废浮桥，桥上的七盏白灯同时转向北岸；风雪桥的封水官差已经等在那里，裴九重的命令改成了“让他们自己带着证物上岸”。

### 第23章｜风雪桥
- **时间 / 地点 / 人物**：第6日黎明至上午；湖口风雪桥、雨雾里的栈道、两岸芦苇堤；阮孤灯、明照、陶未明、阿七、陆秋水、谢三更。
- **事件**：葬灯船被迫靠桥，寒雨转成暴雨，湖雾漫上桥面，桥板被雨水泡得发滑。封水官差拿着真假交替的公文封住两岸；谢三更趁三组人信息不全，指认阿七为换碗凶手，并声称湿账是他伪造的。
- **分组 / 独立破局**：阮孤灯守南桥，借桥索和断桩挡住无灯楼追兵，直接斩断正在倾斜的桥臂，给伤员留出退路；明照守北桥，面对挟持施小满的护院，以渡厄掌卸开对方的刀并把人送到桥腹，拒绝让孩子成为诱饵；陶未明在桥心凭官差口令中的错字、印泥未干和靴底青苔拆穿假令，铁尺锁住旧同僚。
- **阿七 / 代价**：阿七只负责把伤员拖过桥，手臂伤口重新裂开；他没有机会补救第21章丢失的副本，只能眼看一页湿账被雨水泡烂。陆秋水承认自己藏过真页，施晚晴也承认调包过账页，两个选择让谢三更暂时失去互相栽赃的筹码。
- **关系 / 钩子**：陶未明正式失去官身，却把原始验尸草纸交给七名过桥的陌生船夫分别传抄；雨幕外的悬赏画像终于补上阿七的脸，暂写“最后见证者：阿七”。七桥渡口在桥后封锁，众人只能向那里退。

### 第24章｜七桥渡口
- **时间 / 地点 / 人物**：第6日午后至入夜；暴雨渡口、七座桥、船市和官道分岔；全员、谢三更、赵无咎、裴九重的公开命令。
- **事件**：所有人退无可退，被围在渡口废船和断桥之间。第六封信公开点名阿七，谢三更当众把换碗罪名推给他；裴九重通过悬赏、假公文和收买船帮同时收网。
- **动作 / 破局**：阮孤灯、明照、陶未明分别守住三条登岸线；明照护住孩子，陶未明公开宣读原始草纸，阮孤灯截断谢三更的追杀。阿七为了给明照和施小满争活路，亲自站到船头，摘下杂役帽和旧腰牌，使用沈红绡教过的藏灯手段，把五封真函和两份信引交给七个互不相识的渡口人。
- **Boss 名字点名（第三处·公开传播）**：此刻名字已不是秘密，榜文、船帮口信和雨里的悬赏都写明“无灯楼裴九重——伪造官文、包庇谢三更、悬赏追杀证人之罪”；陶未明当众把假封水令对着围观船夫宣读，指出暗印与旧戏楼债契同源。裴九重第一次以“被众人指着名字喊”的方式存在于公开舆论中，为第31章真身登场铺好台阶。
- **关系 / 代价**：赵无咎最后改线放走一名信使；陶未明从审问者变为保护证人的逃犯；阮孤灯第一次问阿七是否愿意活着把话说完；阿七认脸不认名，肩伤和沉默公开，姓名留到第37章。
- **钩子**：红盖头第七针亮起，裴九重在雨幕外说：“从今日起，我不必替你们守住一座庄。”第25章转入主动组织证词与冥婚仪式，空间和叙事都不再回到房间巡回。

## 卷四：冥婚（第25–32章）

### 第25章｜七日正日
- **事件**：七封信散出后，官府水师封死太湖八百里出水口，海捕文书、船帮封口和无灯楼追兵把众人从外圈逼回留春山庄；庄子东侧低洼区和主暗渠已经毁坏，西侧高台残院仍有可用的门窗、抽屉和机关。庄底暗渠总枢纽与最后一份真账备份是唯一还能把证词送出去的出口。七日正日的油蜡、红线与水闸回流将在当夜销毁账证，他们杀回庄子是抢总闸、取备份，不是重新巡房。
- **动作**：红线一根根收紧，药房碎碗、账房火星、水闸闸杆同时联动；四名护院出手，众人第一次主动分组而非各自逃命。
- **关系推进**：施晚晴带施小满进入绣房，陆秋水选择跟陶未明走，赵无咎在屋檐上切断一根不该断的线。
- **钩子**：第一根红线断裂，秦半夏房中传来碎碗声，门上出现“不是新娘”的掌印。

### 第26章｜盖头下面
- **事件**：明照进入婚房，红盖头被受潮机关牵开一角，露出七处针脚地图；沈红绡的簧音没有奏完。
- **动作**：洪水和泥沙使机关只剩一枚红针迟滞弹出，另几枚卡在针槽、落入泥沙或滑落，阮孤灯以刀背挡住残针；施晚晴用红丝接回第七针。
- **关系推进**：明照知道姐姐不是要他替她成婚，而是要他看见七件被移动的物件；阮孤灯明白第七针是停手暗号。
- **钩子**：地图最后一针指向阿七的茶盘，茶盘却在谢三更手里。

### 第27章｜茶盘底的双圈水渍
- **事件**：阿七夺回当夜茶盘，发现两圈水渍、半片黑砂和一根施晚晴的红线。
- **动作**：谢三更与阿七在厨房狭窄水道交手，阿七不硬挡而让他每次落脚都踩在回流水线上；赵无咎从梁上出手，逼两人暂时联手躲火。
- **关系推进**：阿七确认自己看见过换碗，却仍无法确认沈红绡最后是否故意喝下；施晚晴承认她曾把带血袖口交给沈红绡。
- **钩子**：盘底刻着“不要替我选凶手”，下方还有一行被茶垢盖住的“也不要替我选活法”。

### 第28章｜阮孤灯的手
- **事件**：明照说出沈红绡当年对阮孤灯说过的话，旧约真相揭开；阮孤灯承认自己放走过白砚生。
- **动作**：赵无咎以黑线困住阮孤灯，逼他在杀与不杀之间做选择；阮孤灯削断黑线而不伤人，把刀交给明照。
- **关系推进**：阮孤灯明白手抖不是因为明照像谁，而是因为明照说出了沈红绡的原话；明照开始真正信任阮孤灯。
- **钩子**：阮孤灯第一次把黑刀交给明照保管，门外有人说“刀离手，人才会说真话”。

### 第29章｜第六封信
- **事件**：第八日拂晓，水师仍封着湖口；顾长亭带阿七从残渠赶到庄外旧戏楼，取出藏着的第六封总密折抄件。
- **动作**：旧戏楼机关以幕布、纸鸢索和暗火封门；顾长亭边逃边把抄件拆成七段，阿七在戏楼外的市集完成唯一一次市井分发。
- **关系推进**：七封信真正目的明确：不是复仇，是让七人各自承认一段事实；柳九娘承认曾替无灯楼送过人。
- **钩子**：第六封信只写给“看见而不说的人”，最后一笔却像裴九重的圆点。

### 第30章｜谢三更的夜
- **事件**：谢三更封锁药房和绣房，烧账、抓施小满、杀俞听潮；四名护院第一次知道自己守的是灭证而非守庄。
- **动作**：阿七带众人走厨房水道，柳九娘以折帆手、秦半夏以药针、陶未明铁尺、施晚晴红丝分别守四个出口；俞听潮以闸杆挡住谢三更的折页步。
- **关系推进**：俞听潮承认阿顺已死，主动把私路图交给阿七；施晚晴为救儿子公开指认谢三更调过药箱。
- **钩子**：谢三更承认调换药碗，却说沈红绡早已把毒喝下；黑暗里有人说“你只看见了第一层”。

### 第31章｜没有新娘的拜堂
- **事件**：第七日白天顾长亭与阿七从旧戏楼取信、分送抄件，入暮在北边水湾与众人合流；正夜回庄后，谢三更点燃喜堂与老账房之间的油蜡引线，俞听潮开应急小闸，火水冲散补婚队伍，众人在残渠与高台间周旋两日，直到第九日明照才在空喜堂完成最后一拜，簧匣奏出沈红绡未完的一句暗号，裴九重从门外接上。
- **动作**：裴九重只改变众人站位和呼吸，阮孤灯刀停三寸，明照掌失去借力，梅照影听不见脚步；没有人被直接击倒，却没有人能先出手。
- **关系推进**：所有人第一次知道谢三更上面还有人；赵无咎跪下不是臣服，而是无法违抗自己的旧命令。
- **钩子**：裴九重说“谁先出手，谁就是凶手”，七根红线全部指向账房。

### 第32章｜她买的药
- **事件**：秦半夏查出沈红绡主动买过一味延迟药；药柜暗格里还有一张施晚晴未缝完的袖口。
- **动作**：药房余火复燃，秦半夏必须在救师门旧账和保药证之间选择；阿七用茶水冷却药柜，明照护住她。
- **关系推进**：秦半夏承认沈红绡知道药被动过，但不能证明她知道最后一杯的毒性；同时确认裴九重先换药引、谢三更后换药碗，明照不再把两次动作混成一个疑问。
- **钩子**：阿七想起沈红绡买药时说“别告诉我弟弟”，却想不起她当时是否在笑。

## 卷五：灯灭之后（第33–40章）

### 第33章｜红线尽头
- **事件**：七根红线、七处门位、七件物证和账房暗门合拢；裴九重解释七线账与反制谱。门位属于庄子的空间机关，外圈请帖名册与内圈物证承接人不按姓名一一对应。
- **动作**：账房地板翻转，证物随水道分流；众人各自救一件，裴九重在未全力出手时夺走三件；阿七用藏灯式保住茶盘。
- **关系推进**：谢三更知道自己也只是被利用的中层；沈红绡的真正要求被红盖头第七针揭示：先停手，再承认。
- **钩子**：账页上出现死亡前主动买药的记录，页角有裴九重亲手圆点；他说真正的药不在碗里。

### 第34章｜每个人的一半
- **事件**：七名受邀者、施晚晴、俞听潮、顾长亭和赵无咎分别补齐自己隐瞒的一半事实；裴九重逐一指出证词漏洞。
- **动作**：裴九重不出重手，只用不同距离让每个人的防御失效；阿七把真话藏进众人的闲话和错页账。
- **关系推进**：陆秋水不再求洗白，施晚晴把儿子交给陶未明保护，赵无咎承认沈红绡曾救过自己。
- **钩子**：谢三更承认调药，却说沈红绡早已喝下真正毒物；众人厘清他只换了碗与痕迹，裴九重七日前已把药引变成甘遂，真正未决的只剩沈红绡当夜如何咽下。

### 第35章｜管家亲自下手
- **事件**：谢三更与阮孤灯交手未完，裴九重进入火场；谢三更用折页步杀向施晚晴，裴九重却先截住他的剑。
- **动作**：裴九重以不见功同时压住阮孤灯、明照、柳九娘、陶未明、梅照影和赵无咎；每个人的优势都被他提前改变落点。阿七只能在烟里救出茶盘和一页湿账。
- **关系推进**：裴九重仍以“阿七”称呼，公开他寻找的真正目标；赵无咎第一次违令替阿七挡了一线。
- **钩子**：裴九重说“你藏得很好，可惜藏灯不是隐身”，火势封死七条明路。

### 第36章｜官府的结论
- **事件**：陶未明决定带原始验尸纸、七封信和证词册回官府；上司派封水官差封锁渡口。
- **动作**：封水官差与护院在水闸交手，柳九娘和俞听潮护船，陶未明铁尺对旧同僚；顾长亭用纸鸢把副本送出。
- **关系推进**：陶未明公开承认自己改过时间，取得部下信任；谢三更失去“只是管家”的身份。
- **钩子**：最老账房起火，火光中裴九重走出；他对谢三更说“你已经没有解释权了”。

### 第37章｜最后一个见证者
- **事件**：阿七不与裴九重硬拼，利用七条暗渠、三套错页账和顾长亭的纸鸢路线分散证词；赵无咎预埋的断楔使渠水倒卷，按察司快马也在官道逼近。
- **动作**：七路同时出现局部交手：柳九娘守水闸，明照护施小满，阮孤灯牵制赵无咎的旧同伴，陶未明保护证词册，阿七用回潮手把强力送回空井；裴九重赢下每一处，却因官面暴露与堤脚塌陷无法同时追上七路。
- **关系推进**：赵无咎故意把一条错误路线交给无灯楼；俞听潮为开最后一闸受伤；阿七在众人面前承认自己当时看见换碗却选择沉默。
- **钩子**：裴九重第一次真正动怒：“你以为藏起来，就能救人？”

### 第38章｜明照脱下红盖头
- **事件**：明照完成仪式，主动揭下红盖头；最后一针指向沈红绡留下的药案，补齐甘草被换成甘遂、两只药碗先后调换的因果。
- **动作**：裴九重可以杀明照，却被七份已经出庄的证词牵制；他与觉岸隔火相望，二人只交换一招，显示两代高手的差距。
- **关系推进**：明照接受姐姐可能主动选择死亡，也拒绝替她宣判；觉岸承认自己隐瞒半封信并向弟子道歉。
- **钩子**：红盖头内侧出现一句阿七从未见过的字：“不要替我替他原谅。”

### 第39章｜阮孤灯放刀
- **事件**：阮孤灯把黑刀放在山庄门外；封水官差和无灯楼追兵在渡口围住众人。
- **动作**：明照以渡厄掌截住追兵但不取命，柳九娘以七条水路分船，陶未明把证词交给不同人，阿七用玩笑和假页码制造七个出发方向。
- **关系推进**：阮孤灯承认自己仍不知道沈红绡最后想不想活，因此不再替亡者杀人；赵无咎带走一枚黑线扣，选择离开无灯楼而非加入众人。
- **钩子**：裴九重站在远处没有追，只捡起刀鞘，说“下一次，别藏在人群里”。

### 第40章｜我只是送茶的
- **事件**：谢三更的罪证、七封信、原始验尸纸和七份证词分别留存；众人离开留春山庄。
- **情节收束**：官府无法再用单一“自尽”结论覆盖所有证词；药性与两次调换的先后已经明确，只留下沈红绡当夜主动端碗或被逼喝完的意志疑点；裴九重武力未败、目标未成，仍是江湖阴影。
- **人物收束**：明照脱下红盖头但不急于还俗；阮孤灯把刀留在庄门；施晚晴带施小满离开绣房；俞听潮把闸图交给陶未明；顾长亭用最后一封假信换回自己的债契；赵无咎消失在水路尽头。
- **主角结尾**：阿七在证词末尾写下“陆七”，有人问他是不是最后见过沈红绡的人，他仍答“我只是送茶的”。转身时他对远处的裴九重笑道：“茶钱还没付。”这一次，他没有抹去自己的名字。
