# 《天阙》有效扩写审计

## 目标

将第1—44章逐步补足至约4000—5000汉字正文，优先补充有效戏剧内容，不以重复景物、心理解释或同义改写填充。

## 每章扩写必须至少新增两项

- 多方同时在场且目标冲突；
- 物资、伤势、路程或天气造成的实际阻力；
- 配角主动选择并留下后果；
- 证物、情报或误会发生不可逆变化；
- 让上一场行动在本章产生延迟后果。

## 禁止的“伪扩写”

- 连续重复同一处泥、水、风、火、尸体或饥饿描写；
- 用主角反复观察环境代替事件；
- 让配角轮流出现讲解背景；
- 用哲理独白、金句和章节总结拉长篇幅；
- 为凑字数新增没有后续影响的路人、道具或战斗。

## 分批计划

- 第一批：第3—10章，补强半面、席横、顾琰、严平的利益纠缠和盐仓后果。
- 第二批：第11—20章，补强第一卷中后段的军报传播、伤兵、段成与李承洲双线。
- 第三批：第21—32章，补强长安失序、潼关军报、火灾、出城与流亡队伍。
- 第四批：第33—44章，补强难民营、钩稽使、分路、河东线和洛阳承接。

每批结束后重新统计字数，并人工检查重复、脚手架、清单式观察和对白声线。
