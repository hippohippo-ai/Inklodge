# 《天阙》结构修订版：第二卷空间与节奏重构

**修订日期：** 2026-08-28
**修订范围：** 第二卷《长安劫》、第三卷《洛阳龙蛇》及总章节计数

## 重构原则

1. 第二卷采用单向动线：入长安 → 城内失序 → 潼关军报与长安大火 → 南门溃逃 → 马嵬坡 → 死人堆 → 渭水难民营 → 各自分路 → 沈广农东行洛阳。
2. 不再让沈广农在长安沦陷后反复进出长安；沦陷后的鬼市、暗桩清洗和敌占区谍战平移至第三卷洛阳。
3. 第二卷扩为24章，给潼关、长安火灾、夺门、马嵬坡和死人堆保留独立叙事空间。
4. 第二卷终点为沈广农东行洛阳，第三卷从洛阳接续，保证物理路线和伏笔传递连续。
5. 李承洲线不再压缩为第二卷末两章，改为与沈广农线交替推进；军报、家书和粮道构成中继。

## 总体计数修正

- 第一卷：20章（第1—20章）
- 第二卷：24章（第21—44章）
- 第三卷起：原有章节编号整体顺延4章；原第二卷第33—35章的鬼市、暗桩内容改为第三卷洛阳线备用素材，不直接沿用原编号。
- 第十四卷仍为终卷，章节总数按各卷实际章节重新统计；不得继续使用“268章”这一旧估算，待第三卷至终卷逐卷核定后更新最终总数。

## 第二卷《长安劫》（756年）· 年命「强」

**24章；主题：帝国如何在日常生活中死去。**
**核心动线：长安城内 → 南门 → 马嵬驿 → 尸堆官道 → 渭水难民营 → 洛阳方向。**

### 第一段：城内的虚火（第21—25章）

- **第21章《长安的雨》**：沈广农凭押运公验入长安，伤势、恶钱、米价和坊门盘查落地；他随粮车进入西市脚夫圈，发现城内已出现提前转运家财的车队。
- **第22章《诗会》**：崔玉真借诗稿折痕、桌脚铜片和茶盏位置传递家族转移命令；她需要沈广农替她确认一名送粮脚夫是否被跟踪，第一次以具体筹码而非格言与他交涉。
- **第23章《画舫》**：公孙兰在曲江池剑器舞中传出范阳与盐运消息；沈广农被迫替她把一名受伤的船工藏过搜查，换得盐引残片，公孙兰留下未结清的人情与误会。
- **第24章《黑水盟粮仓》**：沈广农、黑水盟账房和一名准备偷粮的脚夫同处旧宅；粮仓、官印、盐引和账房损耗同时暴露，账房为自保删掉一页账，沈广农带走的证物因此不完整。
- **第25章《截杀密使》**：范阳军报与裴弘度的截盐密信在巷中争夺；沈广农救不了信使，只能在追兵和巡街差役之间选择带走密信还是救信使遗留的药包，密信进入下一段动线。

### 第二段：天崩地裂（第26—30章）

- **第26章《潼关血报》**：六月初，潼关失守的军报传入长安。溃兵、粮车、城门和朝官车队在同一空间互相冲撞，米价与逃亡秩序同步失控。
- **第27章《永兴夜火》**：黑水盟粮仓被提前点燃。沈广农被困在粮仓与逃出的难民之间，必须在救一名被梁木压住的账房和抢回密信之间做选择；火灾破坏地下粮道，余波延续到难民营。
- **第28章《夺门狂潮》**：南门关闭与重新开启造成踩踏。沈广农护着押运公验和密信随人流出城，粮车、家眷、金吾卫和逃兵互相遮挡；他在混乱中失去一件物证，避免携带过多道具的巧合感。
- **第29章《马嵬惊雷》**：沈广农沿官道抵达马嵬驿，通过溃兵、卖水老妇、老兵和差役听见杨国忠死、贵妃缢、皇帝西逃的碎片；深蓝官服来客只作为巡检钩稽使收集军马遗物，不出现裴弘度本尊。
- **第30章《死人堆》**：沈广农在尸堆中听见呼救，救出宁红叶；死马鞍下的断角铁牌和照夜残剑同时出现，宁红叶尚未成为同行者，只先提出交换水和布的条件。

### 第三段：泥泞同行（第31—36章）

- **第31章《照夜残剑》**：宁红叶处理自己的断臂伤，发现桑葚与沈念；沈广农因持有公验和密信成为队伍风险源，四人以分粮和守夜交换同行。
- **第32章《叛骑截杀》**：叛军斥候逼近，沈广农、宁红叶、桑葚和沈念在沟渠、翻车和倒树间协作；孩子的哭声提前暴露路线，沈广农第一次实战破形但受伤。
- **第33章《过载之痛》**：突围后的耳鸣、发热和失眠迫使队伍停在涵洞；宁红叶要求沈广农放弃一部分证物换药，沈广农拒绝后导致沈念夜间高烧加重，关系出现裂缝。
- **第34章《渭水南岸》**：队伍进入难民营，车板、井水、差役、伤兵和粮价构成生存冲突；桑葚为沈念偷来半块发霉饼，引发失主追打，孩子第一次主动制造后果。
- **第35章《退役斥候》**：临时同行者孙驼子登场。他为换盐加入队伍，教众人辨水和躲抓壮丁，却私藏一张军道图；他与宁红叶争救一名断腿妇人，与沈广农争是否绕路。
- **第36章《军营式秩序》**：裴氏钩稽使接管难民营，按户籍和伤势分粮。沈广农、宁红叶和孙驼子各自隐瞒身份；沈念被列入“无监护男童”，队伍必须在名册和逃亡之间选择。

### 第四段：各自歧路（第37—44章）

- **第37章《粥棚对坐》**：沈广农与裴弘度第一次真正会面，但地点是临时行署的粥棚后屋，裴弘度只谈密信、损耗和责任；冷金笺与顾琰档案的材质连接首次出现，裴弘度不说警句。
- **第38章《宁红叶的选择》**：宁红叶决定带老弱沿南线去剑南。沈广农要追查密信和盐运，双方因药、粮和孩子的分配争执；宁红叶留下照夜剑鞘作夹板，并带走一半药材。
- **第39章《孙驼子的错路》**：孙驼子为避官道带队进入旧河滩，地图判断错误，队伍遭水患和流民抢粮；他承认军道图来自逃兵，主动留下引开追兵，腿伤造成不可逆后果。
- **第40章《崔玉真的车》**：崔玉真从西撤车队中脱身，以半袋粮和一封未寄出的家书换回沈广农手中的一页盐账；她不提供完整答案，只要求他将另一页送往洛阳。
- **第41章《河东风雪》**：镜头转至李承洲。潼关失守的迟到军报抵达河东，段成、赵横、韦敬之和裴校围绕粮道、伤兵与撤防争执；李承洲第一次把伤兵列入可牺牲的军粮表。
- **第42章《城墙之酒》**：李承洲下令放弃一座外围城，段成当面抗命；谢沉璧开始记录撤离名单。崔玉真家书经黑水盟信使抵达，李承洲只留下收粮条件。
- **第43章《死马铁牌》**：沈广农在东行官道发现死马和缺角铁牌，无法确认持有者身份；他听见河东军的口音，却因追兵逼近没有掘尸，铁牌作为未解证物继续携带。
- **第44章《东行洛阳》**：沈广农与宁红叶队伍在三岔路短暂分离。宁红叶向南，孙驼子留在水滩，沈广农向东；他携残缺盐账、裴弘度密信和断角铁牌进入洛阳方向，第三卷从敌占区的鬼市与伪官网络接续。

## 第三卷《洛阳龙蛇》（757年）· 年命「胜」：重排说明

第三卷开头承接第二卷第44章，不再从“沈广农突然进洛阳”开始。原第二卷第33—35章的鬼市、暗桩、崔氏清洗和沦陷都市交易线转入本卷，作为第3—10章的备用素材，须重写为洛阳敌占区情境。

### 第三卷备用线（待扩写，不直接作为正文）

- 鬼市交易：地点改为洛阳南市残垣与伪燕粮卡交易点；沈广农带残缺盐账进入，粮价、军粮券和伪官印成为主要冲突。
- 崔氏暗桩：不再是一次性“17人报告”；选两名重点人物展开，一个为保家人主动背叛，一个为保账页制造假尸体，其他名单只作为背景压力。
- 黑水盟：从长安粮仓撤出的账房与洛阳伪官争夺盐运线路，沈广农被迫与其共同穿过搜粮队。
- 李承洲：通过军报延迟和黑水盟情报中继，得知一条被沈广农救下的漕工口供，第一次受到沈广农行动的间接影响；必须明确路程、耗时、转手人和情报损耗。
- 第三卷第一次正面碰撞不提前；沈广农与李承洲的首次正面对峙继续保留在洛阳战局后段。

## 不得恢复的旧结构

- 沈广农在长安沦陷后反复进城、出城、回鬼市；
- 第26—29章用数段消息直接跳过潼关、长安火灾和马嵬坡；
- 鬼市、17暗桩和崔氏交易继续塞进第二卷尾段；
- 以完整“河东·李”铜牌在多个地点重复提示双雄；
- 裴弘度本人亲临破庙、驿站和难民营反复讲道理。
