# 主题确认

- **书名**：红盖头下的和尚
- **题材**：古典江湖 / 动作武侠 / 庄园谜案
- **基调**：冷峻、寂寞、诡谲，间有黑色幽默与江湖讥诮；杀意藏在静处，真相藏在每个人不肯说完的话里。
- **视角**：第三人称限知为主，前期采用群像限知；开篇跟随黑刀刀客与现场人物，不进入真正主角的完整内心。阿七延迟出场，先作为不起眼的杂役存在。
- **目标规模**：40 章；每章实际 UTF-8 字符 4000–4500，正文纯汉字通常 3500 以上，以高信息密度、情节推进和悬念为先，禁止靠重复对白或氛围排比撑篇幅。旧正文作废，重新从人物、关系和大纲开始规划。
- **一句话核心故事**：沈红绡死后三个月，七封要求补办婚礼的信把一群各自藏着半个秘密的人召回留春山庄；盖红盖头的和尚、三寸黑刀、七条暗渠和四名被牵连的无名者，最终把故意藏成杂役的陆七推到能碾压所有人的不见先生面前，争夺的不是谁能打赢，而是谁还能保住说真话的资格。
- **开篇钩子**：杀过太湖水寨二十名好手的黑刀第一次发抖，因为他看见了红盖头下的年轻和尚；但那二十人的传说只负责证明刀手厉害，真正的谜案从留春山庄才开始。
- **核心谜团**：沈红绡究竟如何死亡；七封信为何分别写给这六人和明照；和尚为何戴红盖头；阮孤灯为何认出明照身上的某个细节；阿七为何不敢说出自己是最后的见证者；山庄中谁用武功护住了这场假自尽；裴九重为什么要亲自逼出一个不起眼的杂役。
- **结局方向**：开放式偏苍凉；沈红绡死亡真相、七封信的目的、阮孤灯手抖的原因和阿七的选择必须闭合，江湖后果保留余味。

> 本次重建明确：太湖水寨二十名好手只属于开篇战绩，不进入后续故事因果；新增施晚晴、俞听潮、赵无咎、顾长亭和施小满，使药、船、账、官、私信、戏楼与武林雇佣七条关系线互相咬合。每章以实际 UTF-8 字符 4000–4500 为篇幅区间，靠完整事件链、空间动作、兵器距离、环境演变、人物关系和心理博弈增加密度，不靠回音壁对白注水。排版也要有呼吸：打斗用短句制造刀口冲击，机关、文戏和心理交锋用3–4句紧凑段落展开，防止40章连续一句一段造成视觉疲劳。
