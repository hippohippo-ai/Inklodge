# 阶段 4：章节规划

【主题】{主题}

## 固定流程

1. 读取：`state/theme.md`、`state/outline.md`、`state/characters.md`、`state/conflicts.md`
2. 把下面的内容写入 `state/chapters.md`，**每章一节**：
   - 章节号 + 暂定标题
   - **核心事件**（一句话）
   - **出场人物**
   - **时间 / 地点**
   - **本章推进了什么**（主线 / 支线 / 伏笔）
   - **本章钩子**（结尾悬念，一句话）
3. 完成后把 `state/progress.md` 的「当前阶段」更新为 `05`，并写入总章节数。

## 规则

- 章节号与 `state/progress.md` 的总章节数必须一致。
- 每章至少有一个「钩子」或推进点，禁止水章。
- 章节规划确定后，写正文按此执行；个别章节允许微调，但总章节数和主线不变。
