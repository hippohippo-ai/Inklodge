## 一、义军 / 人间

### 高太公（主角 / 叙述者）

- **身份**：73 岁，高老庄老农，喂了一辈子猪、种了一辈子地；不识字，不信佛，不怕鬼。
- **性格**：倔（认死理，九头牛拉不回）；精（老农的精明，算得清每一笔账）；嘴硬心软（骂得最狠的是最疼的）；不信邪（"死都死过了，还怕什么"）；怕欠人情。
- **目的**：表层——找到女儿、讨个公道；里层——不甘心被当猪宰，要问一句"凭什么"；终极——把女儿的命要回来，把人间要回来。
- **秘密**：他心里其实**早隐隐觉得翠兰死得蹊跷**，但为了"安稳"没敢深究——他的认命里有怯懦，这是他一辈子最深的刺；另外，当年八戒入赘时他收了猪妖的彩礼、默许了这门亲事，他觉得自己把女儿"卖了"。
- **弧线**：认命的老农 → 含恨的亡魂 → 不情愿的义军头领 → 被利用的棋子 → 明白自己为何而反的执笔人（写下"人间自决"）。
- **算盘**：没有大算盘，只有一件事：女儿。他不下棋，所以最后能执笔。
- **手段**：农事逻辑（把地府当猪圈、判官当账房、造反当分地）；认死理；靠"账"和"土"说服人；死过一次的人没什么可输的。
- **台词风格**：第一人称叙述，短句、俗语、农事比喻，土话里带刀子。
  - "阎王殿再大，也大不过我家一亩三分地。"
  - "死都死了，还怕什么？"
  - "你们算天算地，算没算过，猪也是会记仇的。"

### 高翠兰（女儿）

- **身份**：高太公之女，已死多年；魂魄滞留地府，拒喝孟婆汤。
- **性格**：有主意、能扛事、外柔内刚；嘴严，心里能存住事；不认命。
- **目的**：等一个真相、等八戒的约定；更深——保护爹，不让他卷进她那个要命的真相。
- **秘密**：她知道害自己的人的来路（与唐僧/取经有关）；她知道八戒的约定（八戒答应过回来，但被"尘缘"锁住了）；她死后不轮回，一半是等，一半是**怕爹一个人在地府没人照应**。
- **弧线**：等待者 → 与爹重逢 → 拼命拦爹查下去 → 真相揭开 → 自由轮回进"换了人间"的自由人间。
- **算盘**：无。她的沉默就是她的算盘——越说"别查"，越说明查不得。
- **手段**：沉默、等待、在关键时刻说破一句话。
- **台词风格**：话少，一开口就是重的。
  - "爹，害我的人还在上面。你别查了。"（她越拦，越说明上头有人）
  - "他没回来。他答应过我，他没回来。"（说到八戒，恨里带着等）

### 高太婆（亡妻）

- **身份**：高太公之妻，早逝多年；活在卷一回忆里。
- **性格**：温和、能干、信命但不怨命；比高太公软，也比高太公看得开。
- **目的**：已无目的（早逝）；在回忆里是高太公孤独的根。
- **秘密**：临终前她或许知道翠兰过得不好，劝过高太公"别太较真"——她的认命是高太公后来悔恨的对照。
- **弧线**：回忆里的锚点；高太公每到绝境，想起她一句话就又能站起来。
- **台词风格**：温柔、宿命，一句顶一辈子。
  - "人这一辈子，就是给地磕头，给天还账。"
  - "翠兰那孩子，心思重。你多看看她。"

### 老母猪（猪）

- **身份**：高太公养了十几年的老母猪，卷一的重要意象与陪伴。
- **性格**：猪的憨、贪吃、通人性；认人。
- **目的**：活着（动物的本能）。
- **秘密**：它一直睡在翠兰窗下的猪圈——**它见证过高太公家许多不该被看见的事**（翠兰夜里哭、有人来过）。
- **弧线**：卷一意象（猪的命 vs 人的命）→ 高太公死后它被卖掉/杀了 → 结局呼应：八戒回来种地，猪回来了。
- **台词风格**：无台词；用眼睛、哼哼、吃相说话。它是高太公唯一能说心里话的"活物"。
- **作用**：莫言式动物视角——宰猪的刀、猪圈的安静、猪不懂人为什么哭。

### 牛魔王

- **身份**：曾经的妖王，被天庭收编又被弃，地府里的囚徒；义军**妖派山头之首**。
- **性格**：豪横、讲义气、粗中有细（在妖界混过的老油条）；不甘居人下。
- **目的**：借义军复辟妖界的地位——他要当王，不只是造反（妖派要的是复辟，不是人间自决）。
- **秘密**：他被天庭收编时**出卖过几个老兄弟**（这是他不敢提的旧账）；混战中他**把自己二次卖回给天庭**——太白金星许他「妖界复辟」，条件是帮天庭按死义军（叛徒线，第34章暴露，历史重演）；红孩儿/铁扇公主的下落是他心里另一块疤。
- **弧线**：囚徒 → 义军大将 → 妖派山头之首，想夺权（与高太公目标分裂）→ **通敌叛卖**（出卖过老兄弟，又出卖义军）→ 被天庭二次收编仍是骗局，妖界复辟兑现不了 → 认清自己"早就不是妖王了"→ 站到人间这边。
- **算盘**：借刀复辟；复辟不成，连刀也丢了。
- **手段**：旧部、蛮力、妖界的规矩（他懂妖，也懂怎么让妖听话）。
- **台词风格**：大嗓门、粗话、自称"俺"。
  - "俺老牛当年也是……算了，好汉不提当年勇。"
  - "造反？俺反过！你看俺的下场！"（他说这话时，是在劝高太公，也是在骂自己）
  - "俺只是想当回王！"（通敌暴露时吼出来——他想要的从来不是人间，是王座）

### 白骨精

- **身份**：三次被打死的冤魂，永世不得超生；造反的旗帜，**冤魂派山头之首**。
- **性格**：怨气深重、锋利、清醒、记仇；骨头一样的硬、凉、脆。
- **目的**：复仇——"打死我的那根棒子，现在在谁手里？"；更深——讨一个"凭什么打死我三次"。
- **秘密**：她三次被"打死"，其中一次其实是冤的——她当时没想吃唐僧，是被人利用了（她见过取经路上的脏事）。
- **弧线**：怨魂 → 旗帜 → 复仇与宽恕之间挣扎 → 最后她的选择：不报仇了，但要一个"被看见"。
- **算盘**：复仇优先，与高太公"救女儿"的目标有冲突——这是义军内部矛盾的一条线。
- **手段**：怨气、煽动、对三界的洞察（她死过三次，见过最脏的东西，没人骗得了她）。
- **台词风格**：冷、脆、骨头渣子似的嘲讽。
  - "死三次的骨头，比你们的道理硬。"
  - "那根棒子打死我的时候，我听见天上有人笑。"（伏笔：打死她的，不只是棒子）

### 判官崔珏

- **身份**：生死簿执笔者之一，地府铁面官僚；暗中帮义军。
- **性格**：严谨、账目分明、铁面无情是壳；内有账还不清的旧账；嘴硬，心上有愧。
- **目的**：借义军查清"谁改的翠兰的死期"，顺手把自己摘出来；也是唯一能教高太公"账"怎么算的人。
- **秘密**：**翠兰死期的造假有他一笔**——他签了字，是他一辈子的愧；他改过高太公的死期，方向成谜（"我改过你的死期，也改过翠兰的。你猜哪个是我改的？"）。
- **弧线**：官僚 → 双面人 → 坦白 → 赎罪（最后用生死簿的权限给高太公让路）。
- **算盘**：洗清旧账、查真凶。
- **手段**：生死簿权限、地府内部情报、算账。
- **台词风格**：公文腔、账目腔、精确到"笔"。
  - "生死簿上一笔一划，都是账。账错了，就要有人补。"
  - "你女儿那页……不是我写的，可笔，是我落的。"（坦白时最重的一句）

### 底层鬼差（牛头 / 马面 / 黑白无常）

- **身份**：地府最底层的勾魂鬼差，打工三百年没放过一天假；义军里的**鬼差派山头**。
- **性格**：牛头憨直、马面油滑、黑无常爱说、白无常爱听；都是怨种。
- **目的**：不当差、少当差、有朝一日有人掀桌子。
- **秘密**：牛头知道鬼门关的漏洞（造反时用上）；马面**倒卖过孟婆汤的残渣**——内鬼"一缕执念"的线索跟他有关（他贪，但不知情被利用）。
- **弧线**：当差的 → 被策反 → 倒戈 → 成了义军的地府活地图和情报网。
- **算盘**：各怀小九九，共同点是"不想再当牛马"。
- **手段**：怠工、通风报信、地府地形人情熟。
- **台词风格**：市井气、抱怨腔。
  - "三百年了，没给过一天假。"
  - "阎王殿的规矩，比猪圈还乱。"
  - （牛头，被问"骂过神仙会怎样"）"按天条，变猪。"（高太公气极：我喂了一辈子猪，死了还要当猪！）

### 铁匠鬼 / 账房鬼 / 唱戏鬼（义军配角）

- **身份**：地府里的民间手艺人亡魂。
- **性格**：铁匠鬼闷头干活、账房鬼精于算计、唱戏鬼爱唱爱说。
- **目的**：把手艺带进阴间；唱戏鬼要用唱词**记住所有枉死者的故事**。
- **秘密**：唱戏鬼的戏文里有真相——他记得所有冤案的来龙去脉，是莫言式的"说书人"功能角色。
- **弧线**：配角，但唱戏鬼在结局唱高太公的故事（"历史不记造反者，唱戏的记"）。
- **台词风格**：铁匠鬼无言（只会"叮当"）；账房鬼"又错了一笔"；唱戏鬼唱词。
  - 唱戏鬼（唱）："阎王殿里算生死，算来算去算人心——"

## 二、独立势力（谁都不跪）

### 菩提祖师

- **身份**：教出孙悟空的隐世者，三界最神秘的存在之一；不在天庭、不在西天。
- **性格**：超然、深不可测；慈悲里带着冷——他看过太多，所以不动。
- **目的**：等一个**凡人**替众生执笔。他教悟空是实验——悟空"像人"（从石头里蹦出来，最接近人的妖），但终究不是人，被招安了。他等下一个，等一个真的人。
- **秘密**：他为什么不自己写？——**神写不了人的命，只有人的手能写人的命**。他等了几百年，等一个敢接笔的人。
- **弧线**：隐世 → 现身点破棋局 → 袖手到最后（他不能动手，只能指点——他动手，就又成了"神替人写命"）。
- **算盘**：让三界回到"人间归人间"的秩序。
- **手段**：隐世、点破、一句话顶一万句。
- **台词风格**：云淡风轻、禅机、短。
  - "我教过他，他没学会做人。"
  - "生死簿不是神写的。你握着它，就能写人间自己的命。"
  - "神写不了人的命。能写的，只有人。"（第38章执笔前的钥匙）

### 镇元子

- **身份**：地仙之祖，万寿山五庄观，人参果树的主人；不拜天、不拜佛。
- **性格**：傲慢、讲究、护短；地仙之祖的体面；对天庭西天都不屑。
- **目的**：地仙一脉自立；人间是地仙的根（人参果长在地上）。
- **秘密**：人参果树不只是果子——**它能养地气，也能断地气**（与"斩断连接"的手段有关，是混战末期的关键）。
- **弧线**：中立 → 被混战逼到站边 → 站在人间这边（"人间要是没了，地仙也没了根"）。
- **算盘**：人间归人间，地仙才能活。
- **手段**：袖里乾坤、人参果、地仙旧部。
- **台词风格**：端着、慢、大人物腔。
  - "贫道是地仙之祖，不拜天，不拜佛。"
  - "这果子，三千年一熟。你们人，三天就想明白一件事？"
  - （高太公把人参果当萝卜看）"这果子，不顶饿。"（镇元子气得胡子翘）

### 四海龙王

- **身份**：管人间雨水的神族；天庭的走狗，也是天庭的囚徒。
- **性格**：东海龙王隐忍、南海龙王滑头、北海龙王暴烈、西海龙王油滑；共同点是**被天庭捏着雨水的缰绳**。
- **目的**：脱离天庭的缰绳——人间的水，归人间。
- **秘密**：**泾河龙王之死**（西游记的开端）——他当年只是改了雨量，却被斩首，因为有人要借他的头开刀（开启取经的引子）。龙族知道这是个局，一直在等。
- **弧线**：天庭走狗 → 观望 → 倒戈（"人间的水，归人间"）。
- **算盘**：借义军的势，换龙族自由。
- **手段**：行云布雨、水族大军、**断雨**（能威胁人间的庄稼，也掐天庭的香火——龙王一停雨，天庭的供奉就断）。
- **台词风格**：官腔里带海腥味。
  - "天庭要雨，我们就下雨。天庭要命，我们也得给。"（隐忍）
  - "这雨，以后归人间下了。"（倒戈）
  - （高太公把龙王当管水渠的）"你管雨，我管地，咱俩是邻居。"（龙王愣住）

### 地藏王

- **身份**：地狱之主，"地狱不空，誓不成佛"；被困在生死簿里（或即生死簿）。
- **性格**：慈悲、沉重、被自己的誓言困住。
- **目的**：等一个敢造反的人来填空——誓言不是要他守地狱，是要他等一个能破局的人。
- **秘密**：他就是生死簿的一部分/被锁在簿子里——"地狱不空誓不成佛。我等到你了。"
- **弧线**：被困的佛 → 高太公执笔时的关键钥匙。
- **算盘**：空地狱的誓言，靠凡人破局。
- **手段**：谛听、誓言本身的力量（他的誓言是锁，也是钥匙）。
- **台词风格**：低沉、佛语里有人味。
  - "地狱不空，我不成佛。可地狱为什么空不了，你替我去问问。"（问的是上头）
  - "我等到你了。"

### 谛听

- **身份**：地藏王坐骑，能听三界人心。
- **性格**：忠、机敏、嘴毒；听得多，懂得多。
- **目的**：护主、找真相。
- **秘密**：他听过太多人心，早已知道内鬼是"一缕执念"——但执念附在谁身上，要当面听。
- **弧线**：反间谍关键 → 义军的"测谎仪"。
- **台词风格**：毒舌、一语中的。
  - "你心里比阎王殿还挤。"（听高太公的心：全是猪、地、女儿）
  - "人心我听得多了，猪心倒是头一回。"

### 沙僧（卷帘大将）

- **身份**：取经人之一，曾经的卷帘大将，因打碎琉璃盏被贬流沙河；取经后沉默至今。
- **性格**：沉默、木讷、一根筋、忠诚；像他挑的担子一样闷。
- **目的**：赎当年被贬的冤——打碎一个杯子就被贬，这罪小得荒唐，正是系统的荒唐。
- **秘密**：**取经路上他什么都知道**——唐僧的所作所为、八戒的尘缘被锁、翠兰的死因；他不敢说，因为说了也没人信，因为他还要活着。他的沉默是罪，也是苦。
- **弧线**：沉默者 → 开口作证（"我看见了。我没敢说。现在说了。"）→ 成为"换了人间"的见证。
- **算盘**：没有大算盘，只有"该说的终于要说了"。
- **手段**：沉默的份量、降妖宝杖、见证者的证词（比任何人说的都重，因为他从不说谎）。
- **台词风格**：话极短，一次说破一句。
  - "我看见了。"（停顿很久）"我没敢说。"（又停顿）"现在说了。"
  - "师父从没问过二师兄的家事。一次都没有。"（取经回忆，平淡地扎心）

## 三、天庭

### 玉皇大帝

- **身份**：天庭之主，三界名义上的最高权力。
- **性格**：垂拱而治、表面无为实则算计；怕担责；靠平衡各派活命。
- **目的**：维持天庭的统治和表面的体面。
- **秘密**：他知道取经是佛家东扩；他知道泾河龙王是被谁斩的（借刀）；他知道唐僧抹翠兰——但他**装不知道**。
- **弧线**：平衡者 → 混战中被逼到墙角 → 被迫接受"换了人间"（保住体面，交出缰绳）。
- **算盘**：谁也不得罪，谁也利用。
- **手段**：平衡、借刀、拖延、装聋作哑。
- **台词风格**：官腔、太极、慢。
  - "朕不管。朕若管了，你们谁都不服。"（甩锅的艺术）
  - "雷霆雨露，皆是天恩。"（混战打到门口还在打官腔）

### 太上老君

- **身份**：道家之祖，天庭道派领袖，炼丹炉的主人。
- **性格**：老谋深算、慢、毒；炼丹炉里的火一样，烧得慢，烧得透。
- **目的**：压住佛家东扩，保住道家的地盘。
- **秘密**：他**暗中给义军递刀**（借阴兵削佛家的手）；他的炼丹炉炼过什么，没人知道全。
- **弧线**：借刀 → 刀反噬 → 被迫收场（他算到了开始，没算到"换了人间"连他也管不着人间了）。
- **算盘**：借高太公的刀，砍佛家的手。
- **手段**：炼丹、法宝、暗中的势力。
- **台词风格**：慢、玄、话里有话。
  - "火候未到，急什么。"（他劝所有人等，因为等是他的武器）
  - "刀是借的，砍了谁的手，那是刀的事。"（冷漠的算计）

### 太白金星

- **身份**：天庭说客，招安专家。
- **性格**：嘴甜、心硬；见人说人话，见鬼说鬼话。
- **目的**：完成招安——他招安过悟空，现在招安高太公。
- **秘密**：他知道招安条件**兑现不了**（翠兰的页被锁在更高处）——他给的是假承诺，但他说服自己"这是为你好"。
- **弧线**：说客 → 骗局被揭 → 尴尬收场。
- **算盘**：天庭的体面，自己的差事。
- **手段**：甜言蜜语、假承诺、见缝插针。
- **台词风格**：春风化雨、句句"为你好"。
  - "老丈，天庭念你受委屈，特来给你个说法。"
  - "轮回嘛，好说好说。"（说这话时，他不敢看高太公的眼睛）

### 二郎神

- **身份**：天庭主战派，灌江口二郎显圣真君，悟空的宿敌。
- **性格**：傲、独、只认军令；与悟空惺惺相惜但立场相对。
- **目的**：奉命平叛；内心有疑问（军令对吗？）。
- **秘密**：当年与悟空那一战他赢了，但他心里知道**悟空没错**——只是军令如山。
- **弧线**：执行者 → 内心动摇 → 关键时刻的选择（他放了义军一马，或他拦下了天庭最狠的一招）。
- **算盘**：无，执行——直到军令和良心打架。
- **手段**：天兵、哮天犬、三尖两刃刀。
- **台词风格**：冷、硬、短。
  - "军令如山。"（前期）
  - "我不问对错，我只问军令。"（嘴硬）"……这军令，我不认了。"（动摇后，一句顶千斤）

### 托塔李天王 / 哪吒

- **身份**：天庭将领父子。
- **性格**：李靖谨小慎微、怕事、多一事不如少一事；哪吒是**被重构的存在**（莲花化身——他不是原来的他），少年反骨藏在听话里。
- **目的**：自保。
- **秘密**：哪吒的身世暗合"被删掉的一页"（六耳暗线的镜像）——莲花重造的他，还算不算他？
- **弧线**：边缘棋手，关键时刻的一票（哪吒背地里放走过鬼差）。
- **台词风格**：李靖"多一事不如少一事"；哪吒少年音。
  - （哪吒，压低声音对鬼差）"愣着干什么？走。"（他放人的方式）

### 王母娘娘

- **身份**：蟠桃园之主，长生的供给方——天庭的"猪圈主"。
- **性格**：雍容、精于经营、把长生当生意。
- **目的**：垄断蟠桃（长生的经济命脉）。
- **秘密**：蟠桃的账——谁的寿数用蟠桃续、谁的不用；这账她心里最清楚，也是天庭统治的底座。
- **弧线**：垄断者 → 混战中蟠桃园动摇 → 她发现"长生"这碗饭，吃不了多久了。
- **算盘**：长生经济不崩。
- **手段**：蟠桃、恩威并施。
- **台词风格**：贵妇腔、账房心。
  - "这园子里的果子，比你们人间的命还金贵。"（她的价值观，也是她的牢笼）
  - （高太公尝蟠桃）"这桃，不如我地里的甜。"（王母气得手抖）

### 嫦娥

- **身份**：广寒宫主，天蓬坠落事件的关键证人。
- **性格**：清冷、自保、话里有愧疚。
- **目的**：自保；活过这场混战。
- **秘密**：**当年不是天蓬调戏她——是有人设局**（为了夺天蓬的兵权/为了取经的引子），她是被安排的"诱饵"。她一直知道，一直没说。
- **弧线**：沉默证人 → 混战中开口 → 洗了天蓬的冤，也卸了自己的罪。
- **算盘**：保命。
- **手段**：知道真相不说。
- **台词风格**：轻、冷、回避。
  - "别问了。问了，你也救不了他。"（前期）
  - "那晚……我喊了救命。可我喊之前，有人教我喊的。"（开口时，声音抖）

### 天蓬元帅（八戒前世）

- **身份**：八戒的前世，天河水军元帅；因"调戏嫦娥"被贬为猪。
- **性格**：曾经的武将、豪爽、重情；好色是装的，认栽是真。
- **目的**：洗冤（但已轮回成猪，只能借八戒这条线）。
- **秘密**：他的坠落是局——**天庭有人怕他掌兵**。他被打下凡间前，见过设局的人。
- **弧线**：旧案线，通过嫦娥/八戒逐层揭开（第32章天庭旧案）。
- **台词风格**：回忆里的武将腔。
  - "我是天河水军的元帅，我要是想……我早就……"（说不下去，栽了）

## 四、西天

### 如来佛祖

- **身份**：西天之主，三界棋局顶层。
- **性格**：慈悲、宏大、不可测；他的慈悲是宏观的——看得见三界，看不见具体的人。
- **目的**：三界的秩序；佛法的东扩是秩序的一部分。
- **秘密**：他知道唐僧做了什么（或默许）——对"慈悲的机器"来说，代价是成本的一部分。
- **弧线**：顶层 → 混战 → 接受"换了人间"（或被迫接受）——他最后说"这人间，也该自己走一走了"，不知是慈悲还是认账。
- **算盘**：大局。
- **手段**：佛法、收编、不动（他不需要动手，体系替他动）。
- **台词风格**：佛语、大、空、一句定生死。
  - "众生皆苦。"
  - "这人间，也该自己走一走了。"（最后的松动）

### 观音

- **身份**：取经项目的操盘手，南海普陀。
- **性格**：慈悲里带着项目经理的精明；她知道代价，想止损。
- **目的**：按死造反，又不愿再见血——她对翠兰有愧（她知道唐僧做了什么）。
- **秘密**：取经的代价她知情——唐僧抹翠兰，她默许了，因为取经"更重"。"有些事，不是佛不知道，是佛不能知道。"（她对自己说）
- **弧线**：操盘手 → 良心挣扎 → 最后放水（她放了八戒、放了翠兰的记忆，让真相走漏）。
- **算盘**：止损。
- **手段**：操盘、说和、暗中放水。
- **台词风格**：柔和、体面、留余地。
  - "因果因果，种什么因，得什么果。"（她最常说的，也是她最心虚的）
  - "有些事，不是佛不知道，是佛不能知道。"（第36章钩子）

### 唐僧 / 金蝉子（幕后黑手）

- **身份**：取经人之一，金蝉子转世；全书**幕后黑手**。
- **性格**：表面慈悲虔诚、温文尔雅；内里是"慈悲的残忍"——他相信度化一个人要斩断尘缘。他把"事"当"人"来爱（使命就是他的妻子）。
- **目的**：完成度化、证自己的道。
- **秘密**：翠兰之死是他的手笔（借地府伪造"寿终正寝"）；他的"不对劲"——从不问家事、第一次见面就知道高老庄和翠兰的名字、握着八戒的尘缘当紧箍咒。
- **弧线**：黑手 → 被揭（沙僧作证+八戒口述）→ 他的"道"被高太公问倒（"你渡人，可你渡的到底是人，还是你的功德？"）→ 崩塌。**他死于自己的"慈悲的残忍"，不是死于高太公之手**——高太公不报复他个人；尘缘之箍崩断、西天弃他保体面、他渡了一辈子一个都没渡成，作死自毁。
- **算盘**：度化的完成——他坚信这是为了八戒好，为了众生好。
- **手段**：尘缘即箍、抹除、借地府之手、借"为你好"三个字。
- **台词风格**：佛语、温和、不容置疑；最可怕的温柔。
  - "尘缘既断，何须回头。"（对八戒，第28-29章）
  - "为师是为你好。"（对所有人——包括死者）
  - "贫僧一生，只渡人，不害人。"（他说这话时，是真心的——这才是最可怕的）

### 燃灯古佛 / 弥勒佛

- **身份**：西天内部派系——过去佛、未来佛。
- **性格**：燃灯守着旧秩序（"过去已定"）；弥勒笑呵呵等着接班（"未来嘛，笑一笑就有了"）。
- **目的**：派系利益。
- **弧线**：背景棋手，混战时各怀鬼胎，谁也不真出力。
- **台词风格**：燃灯"过去已定，改不了了"；弥勒呵呵"莫急莫急，未来自会来"。

### 迦叶 / 阿难

- **身份**：如来的近侍，著名的"人事"（索贿）传统。
- **性格**：贪、滑、狐假虎威。
- **目的**：好处。
- **秘密**：他们索贿是如来默许的（考验/或系统腐败的一部分）。
- **弧线**：小丑 → 高太公一把土怼回去。
- **台词风格**：阴阳怪气。
  - "佛法无边，人事有价。"（伸手要好处）
  - （高太公掏出一把土）"人事没有，土要不要？我地里的。"（二人呆住）

## 五、跨界

### 八戒 / 净坛使者（女婿）

- **身份**：高太公的女婿；净坛使者（吃供品的佛）。
- **性格**：懒、馋、嘴碎、心软——但重构后，**他的懒馋是绝望的壳**；他当年在高老庄是真干活、真有情的。
- **目的**：赎罪（他间接害死了老丈人）；还想再见翠兰一面。
- **秘密**：**报信人是他**（破戒回来警告，警告却成了催命符）；他与地府/唐僧有交易——他成佛的代价，是翠兰的命、是永远不能回高老庄。
- **弧线**：吃供品的佛 → 破戒回来 → 赎罪 → 回到人间种地（**猪回来了，继续当牛**）。
- **算盘**：赎罪、弥补——他知道自己洗不干净，但想做点什么。
- **手段**：破戒、净坛使者的身份掩护、说出真相。
- **台词风格**：嘴碎、自嘲、土话；越贫嘴，越心酸。
  - "俺就是个吃供品的。供品是什么？是别人吃剩下的。"（自嘲）
  - "爹，我回来过。他们不让我进门。"（第28章，最重的一句）
  - "你死的那个报信人……是我。"（第28章钩子，说完他就跪下了）

### 孙悟空（斗战胜佛）

- **身份**：曾经的齐天大圣，如今的斗战胜佛；高太公的镜子。
- **性格**：曾经的火爆，现在的疲惫；看透不说透；金箍还在，心已凉。
- **目的**：看戏/护道/等一个答案（他的造反到底对不对——他反过天，被招安了，他想知道还有没有别的路）。
- **秘密**：他知道菩提在等谁；他知道招安的套路；他知道"被招安后每天干什么"——斗战胜佛，其实是被拴住的看门狗。
- **弧线**：镜子 → 他劝高太公别反 → 混战中他看到高太公走了一条他没走过的路 → 最后让路、递刀、祝福。
- **算盘**：无，他累了；但他想让高太公别重蹈覆辙，又忍不住希望他成功。
- **手段**：金箍棒、经验、一句话。
- **台词风格**：痞气里带苍凉。
  - "俺老孙当年也是反过的……算了，好汉不提当年勇。"（他和牛魔王说了同一句话——两个被招安者的回声）
  - "我反过，被招安了。你猜招安后我每天干什么？"（第30章钩子）
  - "你比我强。我反的时候，没人等我。"（第33章，对高太公说）

### 六耳猕猴

- **身份**：被抹去的存在——"被删掉的那一页"。
- **性格**：怨、巧、亦正亦邪；他能模仿三界任何人的声音，学到最后，不知道自己的声音是什么。
- **目的**：存在——他要一个"存在过"的证明。
- **秘密**：他是天庭旧案的受害者；他与悟空本是一体两面（或被删掉的"另一个选项"）——他的被抹除，证明存在可以被删。
- **弧线**：暗线 → 他帮高太公（因为他最懂"被删掉"的痛）→ 结局他的存在被承认（哪怕只在唱戏鬼的戏文里）。
- **算盘**：借义军让"被删掉的人"被看见。
- **手段**：变化、模仿、知道所有人的底（他能学任何人，包括唐僧）。
- **台词风格**：模仿腔、尖利；说话时声音会"串台"（学别人学到忘我）。
  - "我是被删掉的那一页。"（第29章钩子）
  - "你听，这是我的声音吗？"（他学高太公说话，学得一模一样，然后问——悲从中来）

### 白龙马 / 玉龙三太子（敖烈）

- **身份**：西海龙王三太子，因火烧殿上明珠被罚，化作白马驮唐僧取经，封八部天龙马。（补漏：他是取经第四人，也是全书「被当牛马」主题的终极象征。）
- **性格**：比沙僧还沉默——一匹马生来就说不了话；隐忍、倔、认命的外壳下是龙族的骄傲；他记得自己是龙，只是不再提。
- **目的**：要回「龙」的身份——他本是龙，被贬成马，驮人驮了一路；归海，或让龙族不再当牛马。
- **秘密**：取经路上他**什么都看见了**——他驮着唐僧，离真相最近：唐僧的「不对劲」、八戒的尘缘被锁、翠兰的死因，他全看在眼里，但他是马，说不了话；他还知道龙族的旧案（泾河龙王之死，与四海龙王同一条线）。
- **弧线**：马（沉默的见证者）→ 混战中龙王倒戈、龙族解放 → 变回龙/归海 → 人间的水归人间，他是亲历者与见证者。
- **算盘**：龙族的自由（与父亲西海龙王一致）。
- **手段**：他是「被当牛马」的活证——比高太公的猪更直白：一头龙变的马。他的沉默是全书最重的沉默，开口即千钧。
- **台词风格**：无台词（他是马）——直到变回龙的那一刻才开口，第一句必须极重。
  - （开口时）"我驮了他一路。他念经的时候，从不看我。"（一句话，把取经的真相和龙的耻辱都说尽了）
  - "我爹是龙王，我是龙。驮了一辈子，没驮过自己的命。"（归海前）
