# 《天阙》第四卷《河北三镇》卷纲

**时间范围：** 757年春—758年冬
**正文承接：** 第三卷第68章《北仓的灯灭了》
**卷主题：** 名字如何被借走，活人如何把账重新拿回来。
**核心问题：** 当一个死人的名字在军籍、盐账和征兵册上继续活动，追查的究竟是一个人，还是一套允许死人替活人承担罪责的制度？
**篇幅建议：** 24章，正文第69—92章；单章4000—5000字。

> **正典边界：** 李承恩已于第一卷第19章北哨执勤时冻亡。第四卷不得复活李承恩、不得安排其正面行动；“李承恩”只能通过军牌、旧军籍、遗物、证人和被借用的签押出现。第四卷追查的是“借名者”，不是死者本人。

---

## 一、卷首状态

第三卷末，北仓被焚，记名册分散到民间，沈广农、宁红叶、桑葚南折，准备寻找孙驼子所在的桥；韩魁向东追查含嘉仓旧案中仍活着的第三名抄账人；李承洲在陕郡收到淮字号漕工口供，在军道图上圈出洛阳东市；裴弘度在火场外现身，以“招募”代替追杀。

第四卷开篇不回长安，不重复北仓火灾，不重新解释第三卷账线。故事从南行队伍抵达标红渡口开始，并让三条线分别进入河北、河东与江淮。

### 三条主线

1. **名字线：** 沈广农查“李承恩”签押为何在死后继续出现，发现借名者并非单独冒名，而是利用死者军籍、空缺军功和转运权限形成了一条替身链。
2. **桥与军道线：** 孙驼子被困在标红渡口，军道图其实记录了被人为改造的桥、闸、粮卡和撤军路线；救出孙驼子同时意味着暴露一处河北军粮转运节点。
3. **军政线：** 李承洲从河东向东推进，必须在“救粮”“收兵”“保住军队”之间选择；他与沈广农仍不立即相见，先通过军报、军籍和被改动的地图互相判断。

## 二、24章主要情节节拍（含结构类型防重复标注）

> **结构纪律（本卷硬约束）：** 每章必须标注下列一种结构类型；相邻两章不得同型；同一节拍区内四种类型至少各用一次。禁止"到一处→见一人→取一物→做一事"的单一调查节奏：每章要么以行动/后果开场（追、救、撤、爆炸余波），要么让线索与代价同生（拿到线索的同一刻必须失去一样东西）。

### 第一段·过桥（69—74）：死人名下的活粮

- **第69章《桥头》〔行动·突围〕：** 开场即追击——沈广农一行在桑葚画中的桥被桥头粮卡拦下，李承恩旧军牌在守卡人手里被当众核验。孙驼子不在桥上，他在桥下暗渠替一队逃民守住退路；"站桥"是诱饵。本章主线是逃（暗渠、水门、被烧掉一角的图），不是查：证明死者名字仍在运转的方式，是它差一点把队伍送进卡子。
- **第70章《驼背的人》〔对峙·抉择〕：** 孙驼子归队，但拒绝南下。冲突是面对面的：他摊开被削去图例的军道图残角，逼沈广农在"继续追账"与"先救桥下十七名逃民"之间立刻选一边。旧伤与三十七船沉船案在此以证人身份登场（孙驼子本人），不是作为新线索——他当年看见的不是路线，是"谁有权改桥"。
- **第71章《旧牌新名》〔查证·反被查〕：** 结构反转：沈广农本以为在查牌，实际牌在查他。桥头账房拿出一块军籍有矛盾的旧军牌，沈广农追的是"谁在死亡日期后用了这牌"，但他每核对一处，队伍的行踪就暴露一处（妇孺、周七、少年被逐一点名）。章末救出周七的弟弟不成，只追回半截真相——证据是别人的饵。
- **第72章《河北的粮车》〔追踪·陷阱成形〕：** 追车辙北上，四站"过桥钱"。本章不是四段式收钱流水账，而是一次性揭露：五站走完才拼出"每一站都是给追的人看的"——旧纸新装的伪册、缺角木盒、拴绳孩童全是铺好的路。章末没有新线索，只有确认：真册子在前方车辙上，队伍被算进了别人的局。
- **第73章《空营》〔数账·数人〕：** 冲突不是找线索，是数——营册三百七十六人，营地只有九十七副铺席；架上三百七十六块无名木牌，一块不缺。沈广农第一次确认借名者在成批制造身份，但他数的同时必须决定：把多出来的二百七十九块牌带走（证据）还是留下（让私运队继续以为营地已封）——带走即暴露，留下即纵容。章末选留下，代价是周八（周七之弟）被车拉走的方向从此断了线。
- **第74章《桥下第二道水》〔失败·反转〕：** 孙驼子带众人从桥下旧水道进粮站，预期找到复制军籍凭证的模具，结果模具缺角、作废、而且被人抢先一步搬空——真正的模具已经在更北的盐窖里开始量产。本章是第一次实质失败：计划落空、退路被水涨断、队伍被迫绕行暴露行踪。卷首悬念从"谁借名"推进到"谁能复制"，方式是打脸，不是揭秘。

### 第二段·三镇（75—80）：藩镇不是一座城

- **第75章《营州来客》〔审问·双面〕：** 不是"来客谈路权"，是沈广农审一个主动送上门的使者。使者不承认自己是叛军，只反复说"我们不想死"。沈广农从鞋底泥色判断其来自营州，但审问后半程反转：使者是李怀仙派来钓鱼的——他早知道军道图北端是河北诸镇，此行是来确认沈广农一行知道多少。章末沈广农没有拆穿，顺着使者演下去，把假信任当成通行证。
- **第76章《北门》〔抉择·代价〕：** 众人进入军镇外围，张孝忠的政治影子放难民换粮，条件是全登记。宁红叶发现登记册上出现多个李承恩的后续签押——但当场不能点破（点了，整队难民都走不了）。本章核心是一道选择题：保证据（带走登记册的抄页）还是保人（把抄页还给册子，让难民先过关）。宁红叶与孙驼子第一次正面分歧，沈广农被迫站一边。
- **第77章《没有脸的兵》〔行动·夜逃〕：** 被强征的少年杂役队夜里逃亡，宁红叶带人接应。动作主线：夜、火、追兵、破鞋、失散的队伍。军牌缺口角度之秘是逃亡途中拼出来的（沈广农把散落在地上的牌按缺口排成一段被删去的路线），不是坐着推演。章末救回一半人，另一半被堵回营——第一次救不干净。
- **第78章《假命簿》〔查证·死者复活〕：** 段九的旧算法再次出现，但段九本人已死。本章冲突不在算式，在"谁在替死人继续拨算盘"——韩魁赶到，确认有人抄走了段九的"更序"方法。结构：韩魁与沈广农各查各的，两条线在章末对撞，撞出一枚段九生前从未用过的私章。章末不是新线索，是旧仇人诈尸——死者还会写字。
- **第79章《韩魁问第三人》〔对质·留活口〕：** 韩魁找到含嘉仓旧案第三名抄账人，不是审出线索，而是审出"借名入册"的权限归属。抄账人交出从未入卷的印章，但韩魁必须当场决定杀与不杀。他第一次把拳头放下，让证人活着——这是韩魁个人弧光的转折章，不是信息章。
- **第80章《三镇之间》〔军议·三难〕：** 李承洲在河东收到军报，判断三镇互相借粮、借兵、借名。韦敬之建议切断粮道，谢沉璧指出会先饿死被册遗漏的人。本章不是"收报—判断"流水线，是三人三案、一案一死的军议：切断粮道（饿死册外人）、不切（叛军吃饱）、只核军籍（两线同时拖慢）。李承洲选第三条，代价是时间——他比谁都清楚，慢就是让给借名者的时间。

### 第三段·借名者（81—86）：活人替死人签押

- **第81章《军籍库》〔潜入·三处对不上〕：** 沈广农潜入旧军籍库，发现李承恩档案分三处：死亡册、军功册、转运册。三册互相引用，却没有一册承认死后权限被注销。本章冲突是账目互搏：他必须同时抄三册（分头行动），每抄一册就多一分暴露的风险，抄完才发现三册的"引用"是循环论证——每一册都指向另一册，没有一册指向活人。
- **第82章《承恩二字》〔证人·反向钓鱼〕：** 找到负责誊录的老妇，本以为是找证人，结果老妇是借名者的诱饵——她说"李承恩不是一个人，是一种可以暂时不用问出处的旧名"，同时把沈广农一行的落脚点透露给了追兵。本章是证人戏的反转：证人给了答案，答案本身就是局。章末沈广农必须决定：信老妇（带她走）还是弃老妇（她可能还在为借名者传话）。
- **第83章《照夜过北》〔行动·代价〕：** 宁红叶主视角动作章：照夜剑鞘裂开救出押运妇孺，发现伪军队里有人只是借军籍逃过征发。她反对把所有借名者当敌人，与沈广农的"账要算清"正面冲突。本章没有新线索，只有旧债：剑鞘裂、妇孺安置、队伍因救人而暴露在雪地里——救人的代价当场兑现。
- **第84章《墨圈》〔军线·守原件〕：** 李承洲收到军籍核验报告，报告上有与洛阳东市相似的墨圈。谢沉璧判断圈是提醒后来的读者，李承洲下令保留原件不许重抄。本章冲突是军令 vs 史官：重抄（军令，干净）还是保留（违令，但保真）。章末李承洲选择保留，代价是他在军中的把柄多了一条。
- **第85章《桥梁账》〔拼图·时间差〕：** 孙驼子把军道图补完整：桥、闸、粮站、军籍库被虚线连在一起。借名者真正借的是桥梁和粮站之间的时间差——粮已走、账未到，死人名填补空档。本章是技术揭底章，但结构上必须对抗"拼图流水账"：孙驼子一边补图一边老病发作，补到一半倒下，图只补完三分之二，缺口留给了下一卷——拼图不是胜利，是倒计时。
- **第86章《借名者》〔对坐·失手〕：** 沈广农与借名者隔案相对，只看见一只戴旧皮手套的手。对方承认借用李承恩的名字，但否认创造这套制度："我只是拿了一个没人再要的名字。"对方留下半页名单，转身引爆粮库外的火药。本章不是揭秘章，是失手章：沈广农本拟活捉，结果对方一句话就让他慢了半拍——名单到手，火药在背后炸响，追了三卷的人从指缝里跑了。

### 第四段·各自的账（87—92）：不让死人再替活人受罪

- **第87章《河东来使》〔擦肩·止损〕：** 火药余波未散，李承洲派来的使者在废驿站与沈广农擦肩而过。双方只交换军籍抄件和桥图，没有正面相见。本章冲突不是信息交换，是交换的代价：使者被追兵盯上，沈广农必须选择保使者（放弃半页名单）还是保名单（牺牲使者）。他保了使者——这是他第一次把"人"排在"账"前面。
- **第88章《李承洲的弟弟》〔军线·直面〕：** 李承洲从谢沉璧处重看李承恩死亡记录。谢沉璧指出所有后来的"李承恩"都避开死亡地点，说明借名者知道死者的真实经历却从未见过其家人。李承洲决定公开一部分弟弟的军籍，让死者不再只是可挪用的空栏。本章冲突是哥哥的身份：他既是将军也是弟弟，公开军籍＝把私情摆上军案。章末他把弟弟的名字写进公开名册，笔没有抖——但写完那只手在案下握了很久。
- **第89章《三镇火线》〔抉择·两头〕：** 藩镇因粮道断裂起小冲突。沈广农一行必须选：救被扣押的册员，还是护送一车药材过桥。宁红叶坚持先救人，孙驼子用旧水道两头换位，沈广农把两件事合并完成——但军道图因此暴露，孙驼子的旧伤在换位中断裂。本章是三线并进的行动章：救人、护药、保图，三件事只能保住两件半。
- **第90章《归名》〔揭底·不洗白〕：** 借名者身份揭开：被除名的低级文吏，家人曾因一笔错误军籍被强征而死。他最初借名是为了让一批逃兵、孤儿、伤兵获得粮与路；后来被更大的势力接管，借名变成牟利工具。本章结构是庭审式对质：沈广农不是接受忏悔，是逐条对账——你救过谁、你害过谁、哪一笔是救、哪一笔是卖，一条条摆出来。动机不洗白罪责。
- **第91章《不替你签》〔决断·归位〕：** 沈广农拒绝用李承恩的旧牌替众人过最后一道关。他把牌交给李承洲的使者，要求把死者的死亡日期、北哨地点和真实军籍一并写回册中。孙驼子把军道图缺角补上，但不补借名者最后逃向何处。本章没有谈判余地：沈广农的决断让队伍失去最后的通行证，代价是全员绕行三百里——但这是全卷第一次"按死人的规矩还死人的名"。
- **第92章《名在纸上》〔收束·开放〕：** 卷末：河东军籍库公开注销李承恩死后所有签押，使用过该名字的人被分成"被迫借名"和"借名牟利"两类，未完全解决的罪责留到后卷。四线并行收尾：沈广农一行向北，韩魁带证人向东，李承洲率军入河北边线，裴弘度在天衡的账上添了一行字。远处营火连成一线，军道图不再指向一个归宿，而指向下一场更大的战争——卷末不解决制度，只解决这一卷的名字。

## 三、人物关系与冲突矩阵

| 人物 | 与沈广农 | 与李承洲 | 本卷变化 |
|---|---|---|---|
| 沈广农 | 核心视角；从查账转向替人归名 | 通过军报、使者和地图互相判断，不在本卷前半正面相见 | 学会区分“理解动机”与“免除责任” |
| 宁红叶 | 同行者、现实制衡者 | 认可其救人底线，但警惕军队把人重新数字化 | 从护送队医者转为临时组织者 |
| 桑葚 | 画信与观察者 | 她的图帮助李承洲线确认桥路 | 从记录别人变成能独立传递路线情报 |
| 孙驼子 | 军道图师傅、桥线核心 | 旧军道曾服务河东军，掌握军队改路证据 | 从“被确认存活”到主动揭示改道真相 |
| 李承洲 | 未立即相见；共同追查死人军籍 | 自己弟弟的名字被借用，个人心结进入军政选择 | 从“核军报”转向公开军籍、保护死者名誉 |
| 谢沉璧 | 记录者与事实校验者 | 强迫李承洲看具体名字，不允许只看战损数字 | 建立“原件不可重抄”的史官原则 |
| 韩魁 | 证据共同持有人，阶段性同行 | 与河东军无直接信任 | 从复仇者变成保护证人的人 |
| 借名者 | 主要对手，动机复杂 | 借用李承恩名号，间接触及李承洲 | 从制度受害者变成制度共犯，最终身份揭开 |
| 裴弘度 | 远程布局者，不在卷首现身 | 通过天衡制度影响军籍与粮道 | 从招募者变成潜在制度幕后方，不提前揭底 |
| 李怀仙、张孝忠 | 河北地方权力节点 | 与河东军形成现实博弈 | 展示藩镇“求活”与割据的灰度 |

## 四、核心伏笔与回收安排

| 线索 | 本卷推进 | 卷末状态 |
|---|---|---|
| 李承恩旧军牌 | 证明死后被使用、被复制、被分配 | 死亡事实公开，借名链部分揭开 |
| 盐账 | 通过粮站、盐窖、桥梁时间差继续追踪 | 证明盐粮账与军籍账共用同一转运空档 |
| 孙驼子军道图 | 从残角补成桥闸粮站图 | 图不再是路线，而是制度施工图 |
| 断角铁牌 | 作为死者凭证交回河东军籍库 | 不再作为通关工具，成为证物 |

## 五、写作与连续性硬约束

1. 李承恩不复活，不正面出场，不写其死后亲自行动。
2. 第四卷不回长安；长安只作为旧军籍来源和历史背景。
3. 张巡、许远只作江淮战局背景，不提前正面出场。
4. 李承洲与沈广农的正面相见至少延后到第87章之后，且不得用巧合制造长谈。
5. 藩镇人物以军政现实为主，不写成江湖门派。
6. 借名者动机可以复杂，但不能因“曾经救人”而免除其参与牟利、伪造和牺牲他人的责任。
7. 每章必须有一个具体器物或空间锚点：桥、军牌、营册、空营、军籍匣、旧水道、断裂剑鞘等。
8. 第七袋、第七盏灯等第三卷核心回环只作低频暗引，不再作为第四卷主意象。
9. 第四卷新核心意象为“缺角归位”（低频约束）：军牌缺角、图纸缺角、姓名缺角，最终对应“名在纸上”。“缺角/缺口”意象全卷仅限链首（69）、模具转折（74）、归位（91—92）四处落位，其余章节禁用该词，改用各章自身器物锚点（伪册、铺席、木牌、墨圈、残印）。
10. 使用 `state/dedup-check.py` 时，第三卷冻结短语仍需避免原样复现；如需回收，必须登记为第四卷受控呼应。

11. **结构防重复纪律（本卷最重要约束）：** 每章必须标注结构类型（见第二节括号标注），相邻章不同型；同一节拍区内四种类型至少各用一次。禁止"到一处→见一人→取一物→做一事"的单一调查节奏。
12. 每个新地点必须同时承担至少三项功能：提供冲突、产生代价、推进证据——只提供线索的地点不得保留。
13. 每章必须发生至少一次实质损失或失败（丢人、丢证、暴露、受伤、误判），禁止"顺利拿到线索并全身而退"。
14. 李承洲军线章节（80/84/88）不得同为"收报→判断"结构：80是军议三难、84是守原件对抗、88是直面死者家属——三章三种开法。
