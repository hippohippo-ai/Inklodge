# 人物设定｜《红盖头下的和尚》

> 太湖水寨二十名好手只作为阮孤灯开篇战绩，不设人物、不设名单、不设后续关系。以下人物均属于留春山庄主线。

## 1. 阮孤灯｜黑刀客

- **性别年龄 / 身份**：男，33 岁；受雇护送明照的江湖刀客。
- **性格**：冷、准、寡言、守约；感情越深，话越少。
- **目的**：把明照安全送到留春山庄，确认沈红绡死前为何又提到自己。
- **秘密**：多年前沈红绡曾请他杀一个人，他没有出刀，却替她藏下了一个秘密；他以为沈红绡死后这个秘密已经结束。
- **弱点 / 恐惧**：害怕自己不是在守约，而是在逃避回答沈红绡当年的问题。
- **成长弧线**：从用沉默保护自己，到承认沉默也会成为帮凶；最终把刀放下，但不宣称自己被原谅。
- **武学**：黑刀“沉月”，只练近身三寸；第一刀试距离，第二刀断退路，第三刀才取命。出刀极少，出刀后局势必变。
- **标志性行为 / 口头禅**：说话前看对方的手；常说“刀只管落下，不管理由”。

## 2. 明照｜红盖头下的年轻和尚

- **性别年龄 / 身份**：男，19 岁；渡厄寺小沙弥，沈红绡失散多年的弟弟。
- **性格**：温和、迟钝似的聪明、守戒又好奇；对死人比对亲人更有耐心。
- **目的**：完成沈红绡遗嘱中的仪式，弄清姐姐为何在死后三个月召他回去。
- **秘密**：他幼年被沈红绡送入寺院，记得姐姐的一句没说完的话，却忘了她为何急着送走自己。
- **弱点 / 恐惧**：害怕自己只是姐姐用来完成最后一局的工具；不敢在信仰和亲情之间做选择。
- **成长弧线**：从替亡姐戴红盖头，到脱下红盖头，以自己的身份面对姐姐的死。
- **武学**：渡厄掌与无相步；掌力以卸力、截脉、借势为主，戒杀，不主动取人性命，但被逼到绝处时能废掉对手的腕与膝。
- **标志性行为 / 口头禅**：遇险先问“这算不算犯戒”；把红盖头折得过分整齐。

## 3. 阿七（真名：陆七）｜船上杂役 / 隐藏主角

- **性别年龄 / 身份**：男，22 岁；柳家船上的端茶、搬箱、收缆杂役，曾在留春山庄做抄账童子。
- **性格**：表面安静，骨子里潇洒、聪明、爱开玩笑、重情又有分寸；不抢风头，却能让最难相处的人愿意听他说完。
- **目的**：起初只想拿到船钱；后来必须决定是否承认自己是沈红绡死前最后见到的人。
- **秘密**：沈红绡死前曾让他抄一页账；她还教过他一种把脚步、气息和意图藏进杂音里的小技巧，却没有告诉他这就是“藏灯式”。他看见谢三更的人把药碗换过，却因为害怕被赶走、被灭口而沉默。
- **弱点 / 恐惧**：害怕自己的魅力和能力给身边人带来危险；习惯把“我不知道”当成护身符，却最不能忍受有人利用无名者的沉默。
- **主角气质**：他会把最危险的话说得像玩笑，把最重的承诺说得像随口一提；不主动炫耀，但在朋友受伤时从不退后。
- **成长弧线**：从用不起眼保护自己，到在所有人面前写下自己的名字并承担证词后果。
- **武学**：听水步、回潮手，以及不完整的“藏灯式”。前者让他在船板、湿石和狭窄廊道上保持重心；后者借绳、桨、门板和水柜反震来卸力；藏灯式能把自己的气息、意图和存在感藏到对手判断之外，但不能硬拼内力。
- **江湖技艺**：会品茶、认酒、记路、拆谎，能在三句话里让陌生人把秘密说出一半；喜欢把功劳让给别人，把危险留给自己。
- **标志性行为 / 口头禅**：看账页边角、茶渍和鞋底；常说“我只是送茶的”。
- **出场纪律**：第 1 章后半段、在五名重要人物之后出现；前 8 章不写完整内心，不点明与沈红绡的关系。

## 4. 沈红绡｜留春山庄主人，已故

- **性别年龄 / 身份**：女，死亡时 31 岁；山庄主人、药材与丝绸商人的女儿。
- **性格**：聪明、锋利、爱开玩笑、绝不轻易求人；能把遗嘱写成谜语。
- **目的**：活着时想查清家中账目被吞的真相；临死前想让看见真相的人承认自己看见过。
- **秘密**：她察觉药被替换，故意把七封信写成七日证词局；她可能主动服药，也可能被逼入无法逃脱的局。
- **弱点 / 恐惧**：不相信任何人能在压力下保持诚实，因此把所有人都设计进局。
- **作用**：通过信件、房间、物件和他人的记忆存在；不以鬼魂、假死或幕后活人回归。

## 5. 谢三更｜留春山庄管家 / 中层执行者

- **性别年龄 / 身份**：男，49 岁；沈家三代管家。
- **性格**：谦和、耐心、极会替别人收拾残局；从不在第一时间反驳。
- **目的**：掩盖自己吞没沈家产业、控制药材账，并逼沈红绡交出药材与丝绸生意的印信；沈红绡死后，他奉裴九重的明令收回七封信、维持“自尽”结论。裴九重没有告诉他寻找阿七的真正原因。
- **秘密**：他制造了沈红绡自尽的表象，调换药碗和死亡记录，又借公开举行冥婚的名义把七名收信人集中到山庄。信分散在不同人手里，他既不能提前确定谁持有哪一段，也不敢在官府视线下逐一灭口；他以为自己在操盘，实际上只是裴九重允许他看见的那一层。
- **弱点 / 恐惧**：无法忍受有人掌握不在他账本上的细节；相信所有人最终都会为活命撒谎。
- **成长弧线**：无救赎弧线；从不动声色的管家变成不得不亲自杀人的罪犯。
- **标志性行为 / 口头禅**：替人添茶、替人解释；常说“沈姑娘只是太累了”。

## 6. 柳九娘｜船主

- **性别年龄 / 身份**：女，38 岁；柳家船队掌柜，沈红绡生前的生意伙伴。
- **性格**：泼辣、精明、重承诺，但先算钱再谈情。
- **目的**：把明照和客人送到山庄，取回沈红绡托她保管的一只空木匣。
- **秘密**：她在沈红绡死前收过一封信，却没有交给官府；她担心自己的船队被谢三更控制。她仍然带阿七上船，是因为收信后答应过把人和空木匣送到山庄，且她相信在水上自己至少能护住这群人一程。
- **弱点 / 恐惧**：无法承认自己曾为了保住船队选择沉默。
- **武学**：短桨、船钩和折腰借势，熟悉船战而非正面比武；能在水上打赢不会走水路的高手。
- **成长弧线**：从只想平安交货，到主动公开自己藏下的信。

## 7. 陶未明｜水案捕头

- **性别年龄 / 身份**：男，41 岁；负责沈红绡死亡案的经办捕头。
- **性格**：谨慎、现实、有底线但常被官身牵住。
- **目的**：确认山庄内没有新的命案，带回能经得起官府审问的证据；他不是来替官府草草结案，而是要确认那份自尽卷宗是否站得住。
- **秘密**：他知道沈红绡的验尸记录有一处被改过，却不敢承认是上司授意；因此只要出现新的伤亡，他就必须把所有人和证物带回去，而不是继续替山庄维持体面。
- **弱点 / 恐惧**：怕失去官身后无法保护家人。
- **武学**：铁尺“八问”，以封腕、压肘、锁喉和逼退为主，擅长在门框、桌角等窄地控场，不以杀人为先。
- **成长弧线**：从守住卷宗，到承认卷宗本身可能是伪证。

## 8. 梅照影｜盲眼说书人

- **性别年龄 / 身份**：女，29 岁；沈红绡生前请来讲故事的人。
- **性格**：诙谐、敏锐、虚实相间；最会把真话说成笑话。
- **目的**：完成沈红绡临死前请她转述的一段故事；她把这当作欠一个将她从困顿中救出的朋友的人情，而不是一份普通说书差事。
- **秘密**：她能从声音和气味判断沈红绡死前房间里有两个人；她曾故意把这个判断说成一段荒唐故事，以保住自己和线人的性命。
- **弱点 / 恐惧**：害怕自己也用“故事”逃过了作证责任。
- **武学**：听声辨位，折扇藏三枚短针；眼盲后靠脚步、呼吸和衣料摩擦判断距离，近战时比明眼人更难预判。
- **成长弧线**：从传播传闻，到在最后一封信前说出准确证词。

## 9. 陆秋水｜山庄账房先生

- **性别年龄 / 身份**：男，36 岁；沈家账房，七名受邀者之一。
- **性格**：文弱、爱干净、胆小，擅长把脏账写得漂亮。
- **目的**：保住自己偷改过的账页，不让沈红绡死前发现；他来山庄是因为沈红绡的信已经暗示账页有副本，而谢三更又许诺会替他挡下罪责。
- **秘密**：他并非杀人者，但替谢三更抹去了三笔药材支出；一旦七封信公开，他既可能成为污点证人，也可能被谢三更灭口，所以他先选择保住自己。

## 10. 秦半夏｜女医

- **性别年龄 / 身份**：女，34 岁；曾为沈红绡看病，七名受邀者之一。
- **性格**：冷静、刻薄、真正有医者底线。
- **目的**：证明自己没有伪造沈红绡的药方，并查清是谁利用她的医术制造了自尽结论。
- **秘密**：她认出死者服下的不是原方，却因害怕牵连老师而没有立刻揭穿；她留在山庄不是为了替任何人报仇，而是为了在证据面前保住医者的名字。
- **武学**：药针“半夏三渡”，针尖可麻腕、封穴、止血；她只在救人或自保时使用。

## 11. 觉岸｜渡厄寺主持

- **性别年龄 / 身份**：男，63 岁；明照师父。
- **性格**：慈悲、严厉、知道得多却不替弟子选择。
- **目的**：让明照亲自走完沈红绡留下的仪式；他把这看作弟子面对亲缘和死亡的一次选择，不把答案直接塞给他。
- **秘密**：他知道沈红绡的死不是简单自尽，却不知道谢三更已经控制山庄；他允许明照戴红盖头，是因为最后是否接受这场安排必须由明照自己决定。

## 12. 裴九重（江湖称“不见先生”）｜最终 Boss

- **性别年龄 / 身份**：男，58 岁；无灯楼主人，当世最强的武人之一，谢三更真正的上家。
- **性格**：温和、宽厚、有礼，甚至像个愿意听人说话的长者；但他把所有人的命和选择都视为可整理的棋谱。
- **目的**：收回沈红绡分散在七名证人手里的信件、账页和证词，把她安排的“谁都只说一部分”改造成“只有他有资格解释全部”。他还要确认沈红绡是否把看穿自己的人和那一线藏灯技巧交给了某个不起眼的人；所谓“反制谱”不是一本武功秘籍，而是裴九重对这套分散证词布局的称呼。
- **秘密**：他早已看穿谢三更的山庄局，却故意让局继续，因为七封信只有在七人聚齐、证词逐步公开后才会暴露完整的证物路线；提前杀人会毁掉他想收回的线索，也会把自尽伪案变成无可掩饰的灭口案。他只命谢三更维持局面，不曾告诉谢三更自己真正要找的是阿七。
- **武学**：不见功。不是单纯快或重，而是能在对手出招前改变距离、呼吸和受力方向；能同时压制阮孤灯的刀、明照的掌、梅照影的听声和阿七的借力。正面交手中，所有主要人物联手也只能保命。
- **战斗规则**：首次全力出手必须明确碾压，不允许主角突然升级反杀；他可以折断兵器、封住经脉、夺走场地，却暂不杀死主要人物，因为他要他们活着见证自己的胜利。
- **弱点 / 代价**：他必须亲自控制所有叙事出口，不能容忍无法归档的证词；他也不能随意杀光证人，否则官府和江湖会得到一个比“自尽”更简单、更可信的灭口结论。阿七的真正反击不是伤他，而是让七封信、证词册和目击者沿七条不同水路同时离开他的控制。
- **结局状态**：武力上未败，目标上失败；去向保留开放性，成为后续江湖仍然存在的阴影。
