# 人物设定｜《红盖头下的和尚》·重建版

> 本版从人物与关系重新规划。太湖水寨二十名好手仍只负责衬托阮孤灯开篇战绩，不属于任何人物关系或后续暗线。

## 一、核心人物

### 1. 阿七（真名：陆七）｜故意不起眼的主角

- **身份**：22岁，柳家船上的端茶、搬箱、收缆杂役；幼年曾在留春山庄茶房和账房做抄写童子。
- **表面性格**：安静、手脚麻利、爱说便宜话；谁都能使唤他。
- **真实性格**：聪明、风趣、潇洒、重情，知道什么时候该退一步，也知道什么时候退一步就是害人。他不争名声，却不肯把弱者交给强者处置。
- **初始目的**：拿到船钱，平安离开山庄，不让任何人想起自己曾在那里做过抄账童子。
- **核心秘密**：沈红绡死前最后一夜让他抄过一页账；他亲眼看见有人换过药碗，却因谢三更拿他的身契和旧案威胁而沉默。他不是没有勇气，而是把活下去误当成唯一的正义。
- **能力来源**：沈红绡曾在茶房以水声、碗声和脚步声教过他一段藏灯式；船上劳作又让他练出听水步、回潮手、绳结和借板平衡。这些是低微、实用、不能硬拼内力的本领。
- **主角气质**：把最危险的话说得像玩笑，把最重的承诺说得像随口一提；会把功劳让给显眼的人，却会在无人看见处替陌生人挡一刀。
- **弱点**：害怕自己的名字给别人带来危险；一旦有人因他的沉默受伤，他会用玩笑掩盖愧疚，直到不得不站到灯下。
- **弧线**：从“没人问我，所以我不用回答”，走到“既然我看见了，就该让别人知道我看见了”。
- **关系**：沈红绡是教他识字和藏灯的人；施晚晴知道他曾抄账；赵无咎把他视作另一个被江湖吞掉的孩子；陶未明最终逼他承担正式证词；裴九重要找的是他身上那段未完整的藏灯式。
- **口头禅**：我只是送茶的。

### 2. 阮孤灯｜黑刀客

- **身份**：33岁，受雇护送明照的江湖刀客。
- **性格**：冷、准、守约、寡言；感情越深，话越少。
- **目的**：护送明照，弄清沈红绡为何死后三个月仍要召回自己；不替死者擅自杀人。
- **秘密**：沈红绡七年前请他杀裴九重身边一个叛徒“白砚生”，他没有出刀，只把人送走；白砚生后来死于无灯楼追杀。沈红绡因此欠他一句解释，他也欠沈红绡一个回答。
- **武学**：黑刀“沉月”，只练三寸近身；第一刀试距，第二刀断退路，第三刀才取命。对赵无咎的黑线短刃、裴九重的不见功形成逐级克制关系。
- **弧线**：从相信刀能替人结束问题，到承认有些问题必须由活人自己回答。
- **关系**：与陶未明互相不信任却尊重底线；与明照从护送者变成并肩者；对施晚晴有旧识；对赵无咎的刀路有似曾相识的疑虑。

### 3. 明照｜红盖头下的年轻和尚

- **身份**：19岁，渡厄寺小沙弥，沈红绡失散多年的弟弟。
- **性格**：温和、好奇、守戒，偶尔以迟钝掩饰看得太清楚；对死人比对亲人更有耐心。
- **目的**：完成姐姐留下的仪式，弄清她为何把自己送入寺院又在死后召回。
- **秘密**：幼年离家前，他曾在沈家药柜后看见一枚黑色圆印；他忘了圆印的主人，却记得姐姐说“不要让那个人知道你还活着”。
- **武学**：渡厄掌、无相步；引导来力、卸开关节、截断杀势，戒杀但不戒护人。每次废人腕骨或膝骨都会留下心理代价。
- **弧线**：从替姐姐完成一场安排好的仪式，到以自己的身份接受或拒绝姐姐的最后选择。
- **关系**：阮孤灯是护送者；觉岸是师父；阿七是最先把他当普通人说笑的人；施晚晴在他耳后看见沈家旧疤后开始动摇。

### 4. 沈红绡｜留春山庄主人，已故

- **身份**：死亡时31岁，药材、丝绸与水运商人的继承人。
- **性格**：锋利、聪明、爱试探、绝不轻易求人；擅长把遗嘱写成谜语。
- **生前目标**：查清沈家药材账、船运和官府卷宗被谁串在一起；找出无灯楼在江南的“七线账”。
- **死前目标**：让每个看见过真相的人承认自己看见过，而不是替他们指定一个凶手。
- **秘密**：她发现谢三更只是执行者，真正控制账、药、船路和官差的是裴九重；她知道自己未必能活过那夜，因此将证物、路线和证词拆给不同的人。
- **弧线 / 作用**：不复活、不化鬼，只以信件、物件和别人不完整的记忆继续逼活人选择。她可能主动服药，也可能被逼到只能主动选择最后一口药，结局保留两种解释。

### 5. 谢三更｜管家 / 中层执行者

- **身份**：49岁，沈家三代管家，掌握山庄药、账、门和仆役。
- **真实目的**：吞掉沈家产业，替裴九重回收七线账和七封信，维持“自尽”结论。
- **性格**：谦和、耐心、极会替别人解释，从不先发怒。
- **秘密**：他调换药碗、提前死亡时间、转移棺材，并借自己的亲信控制施晚晴和俞听潮；但裴九重没有告诉他阿七才是最关键的人。
- **武学**：表面不会武，实际会“折页步”和袖中短剑；每次出手先改变站位，再让别人替他承担伤势。
- **弧线**：从替人收拾残局，到亲自成为必须被记录的罪犯。
- **关系**：压着陆秋水的旧账，威胁秦半夏师门，控制施晚晴的儿子，利用俞听潮的旧债；与赵无咎保持命令关系却互不信任。

## 二、七名受邀者与山庄关系

### 6. 柳九娘｜船主

- **身份**：38岁，柳家船队掌柜，沈红绡生前的生意伙伴。
- **目的**：护住船队，履行把明照、客人和空木匣送到山庄的承诺。
- **秘密**：沈红绡死前把一条不能走的水路写给她；她曾为保船队把一名无灯楼信使送过水，却不知道那人后来害死了沈红绡。
- **武学**：短桨、船钩、折腰借势；水上强，陆地窄地仍能用门框和水盆借力。
- **弧线**：从先算钱、后谈情，到主动公开会让船队受损的证据。
- **关键关系**：与俞听潮有旧师徒债；与阿七是雇主和被雇者；与沈红绡互相利用又互相信任。

### 7. 陶未明｜水案捕头

- **身份**：41岁，沈红绡死亡案经办捕头。
- **目的**：确认旧卷宗是否被改，带回能经得起官府审问的证物和活口。
- **秘密**：他曾因上司命令改过一行验尸时间，后来一直保留原始草纸；若公开，自己也会丢官。
- **武学**：铁尺“八问”，卡门、封腕、锁肘、逼退，擅长控场而非追杀。
- **弧线**：从保护卷宗到承认卷宗必须被推翻。
- **关键关系**：与梅照影互相嫌对方不够诚实；与俞听潮曾共同办过水案；对阿七先是审问、后是保护。

### 8. 梅照影｜盲眼说书人

- **身份**：29岁，沈红绡生前请来讲故事的人。
- **目的**：完成朋友托付的故事，同时保住一个仍在无灯楼手里的线人。
- **秘密**：她听见死亡夜有三种脚步，不是两种；她故意把第三种脚步藏进一个荒唐故事里。
- **武学**：听声辨位、折扇藏针；可以听水滴、衣料、鞋钉和呼吸判断距离，但遇到裴九重刻意改变呼吸时会失去优势。
- **弧线**：从用故事保护自己和别人，到承认故事也能成为遮掩。
- **关键关系**：施晚晴替她修过眼前白布；赵无咎曾在她说书场听过自己的身世；她与裴九重有一次隔帘对话，却没看清人。

### 9. 陆秋水｜账房先生

- **身份**：36岁，沈家账房，改账者而非杀人者。
- **目的**：保住自己改过的三笔小账和性命。
- **秘密**：他曾把一份副账交给沈红绡，又把另一份交给无灯楼，想两边下注；副账页码因此出现两套顺序。
- **武学 / 技艺**：削笔、算盘珠、铁算盘暗扣；不是高手，但能用账房狭窄空间自保。
- **弧线**：从用漂亮字掩盖污点，到在证词上留下难看的真名。
- **关键关系**：受谢三更控制；与阿七有旧师徒关系，曾教他认页码；害怕陶未明，也依赖陶未明保护他活着。

### 10. 秦半夏｜女医

- **身份**：34岁，沈家旧医，药方证人。
- **目的**：证明药方被利用，保住医者名誉，并救下不该死的人。
- **秘密**：她的老师曾给无灯楼供过延迟药效的方子；她隐瞒了这一点，怕牵连师门。
- **武学**：药针“半夏三渡”，麻腕、封穴、止血；药柜、针盒和药味都是她的战场。
- **弧线**：从保护师门名声，到承认医术首先要对活人负责。
- **关键关系**：与施晚晴合作过绣线染药；与陆秋水互相利用；谢三更拿她师门的旧账威胁她。

### 11. 觉岸｜渡厄寺主持

- **身份**：63岁，明照师父。
- **目的**：让明照自己走完亲缘和仪式，不替他选择。
- **秘密**：他曾收到沈红绡寄给寺院的半封信，知道“有人会借冥婚找和尚”，却没告诉明照全部内容。
- **武学**：不主动入局；必要时以“枯木禅”截断一招，表现出与裴九重同一代高手的旧时代重量，但不抢主角战场。
- **弧线**：从以沉默保护弟子，到承认隐瞒也会剥夺弟子的选择。

## 三、新增关键人物

### 12. 施晚晴｜绣灯娘 / 隐藏证人

- **身份**：40岁，山庄绣房管事，曾替沈红绡缝制红盖头和七封信的封套。
- **表面目的**：照管绣房，不让外人碰婚服。
- **真实目的**：救出被谢三更扣在外庄的儿子施小满，同时保护沈红绡留下的最后一枚红针。
- **秘密**：她知道红盖头第七针不是地图，而是“停手”的暗号；她在死亡夜替沈红绡换过一只袖口，却没敢说看见了第二只药碗。
- **武学**：缝影针、红丝绊，近距离以丝线绊腕、封指、夺灯，不适合正面硬拼。
- **关系**：沈红绡把她当半个姐姐；秦半夏曾替她儿子治病；谢三更以儿子做人质；第15章开始从被迫沉默转为主动引路。
- **弧线**：从为救孩子替恶人遮掩，到愿意让孩子知道母亲也会害怕但仍选择作证。

### 13. 俞听潮｜旧水闸匠 / 失踪的师父

- **身份**：56岁，曾为官府修水闸，现被谢三更请来维护庄中暗渠。
- **目的**：找回失踪的徒弟阿顺；他相信徒弟偷走了水闸图，实际阿顺已被无灯楼灭口。
- **秘密**：他当年设计七条暗渠，把其中一条暗渠留作私路；沈红绡发现后没有揭发，反而让他把私路改成逃生线。
- **武学**：铁钩、闸杆、沉肩借力；懂水势胜过懂内力。
- **关系**：柳九娘曾是他的学徒；陶未明父亲曾救过他；谢三更用阿顺的死压迫他；阿七从他手里学会一枚关键绳结。
- **弧线**：从只想找徒弟尸骨，到公开承认自己设计了让罪证离庄的水路。

### 14. 赵无咎｜无灯楼行刑人 / 黑线

- **身份**：27岁，裴九重直属的年轻执行者，常用黑线与短刃。
- **目的**：在第七日收回最后一份证物，并杀掉“看见却不说的人”。
- **秘密**：他幼年曾被沈红绡救过，后来被裴九重收走；他相信沈红绡把自己交给了无灯楼，直到发现她留下的信其实一直在保护他。
- **武学**：黑线绕腕、短刃反刺、借柱换位；专门克制三寸刀的进身距离。
- **关系**：阮孤灯在他的刀路里看见沈红绡旧日教过的救命步；梅照影曾在说书场替他隐去姓名；阿七是他不愿承认的相似者。
- **弧线**：从替强者执行“整理”到在关键处故意留下一条活路；不完全洗白，也不突然变好。

### 15. 顾长亭｜纸鸢信使 / 两边下注的人

- **身份**：32岁，往返江南各城的私信信使，沈红绡曾雇他送过七封信。
- **目的**：拿到谢三更许诺的赎身钱，离开无灯楼控制的债契。
- **秘密**：他没有把第七封信送到收信人手中，而是藏在一间旧戏楼；沈红绡知道后故意没有追究，利用他做了一个“信不在收信人手里”的假线索。
- **武学 / 技艺**：纸鸢索、袖中短尺、翻檐轻功；擅逃不擅久战。
- **关系**：与陆秋水交换过页码；与陶未明有官私信件旧案；谢三更和赵无咎都想抓他；阿七在第12章先救他而不问姓名。
- **弧线**：从两边下注求活，到用最后一封真信换取别人的活路。

### 16. 裴九重｜不见先生 / 最终Boss

- **身份**：58岁，无灯楼主人，江湖上最危险的“听众”。
- **目的**：收回七线账、七封信和所有人的解释权；确认沈红绡是否把藏灯式交给陆七。
- **性格**：温和、有礼、极少直接发怒；把人的选择当作可整理的目录。
- **秘密**：他与沈红绡曾有过一次关于“证据是否属于看见者”的辩论；沈红绡没有赢过他，却把一套不能被单点控制的证词布局留了下来。他允许七日局继续，因为只有所有人被迫行动，七条证物路线才会显形。
- **武学**：不见功；提前改变距离、呼吸、受力和对手的判断。不是无限内力，不靠旁白吹捧，必须在实战中让每个人的优点失去落点。
- **终局规则**：武力上始终未败；他能赢每一场局部交手，却不能同时追回七条已经分散的证词路线。阿七的胜法是让强者的胜利不再等于真相被抹掉。

### 17. 其他功能性人物

- **施小满**：施晚晴的儿子，10岁，被关在外庄；他的安危让施晚晴的沉默具有具体代价，不作为卖惨工具。
- **阿顺**：俞听潮失踪的徒弟，只通过工具、遗留绳结和尸体线索出现，证明水闸线有人灭口。
- **四名护院武师**：孟铁山、罗照壁、韩七斤、邱白面；各自守账、守药、守门、守水，不拥有反派全知视角。第30章后分别受伤、逃散或改供。
- **封水官差**：由陶未明上司派来，只执行封锁水路命令；他们相信自己是在防止更大械斗，不知道无灯楼全盘目标。
