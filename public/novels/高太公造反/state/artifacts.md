# 道具：《高太公造反》

> 依据 `state/outline.md` 与 `state/characters.md` 展开。每个道具：**归属 / 来历 / 能力 / 重构设定 / 书中作用 / 主题与伏笔**。
> 道具与人物一样，一旦设定不得随意更改；新出现的道具必须在此登记（走修订流程）。
> 核心原则：**道具是主题的化身，不是打怪的数值**。金箍棒是血债，钉耙是农具，紧箍咒是收编——每个道具都指向「谁被当猪宰、谁被当牛马、谁握着缰绳」。

---

## 一、命与忘（决定结局的核心）

### 生死簿 + 判官笔

- **归属**：地府十殿共管；判官崔珏执笔。
- **来历**：地府至宝，记录三界（实为人间）一切众生的生死寿数。
- **能力**：写谁死，谁就死；可改、可涂、可删。被涂改的鬼魂当场消失（第7章）。
- **重构设定**：**簿子上的字不是神写的，是自己长出来的——是众生的业**。神只是「誊抄」并「执行」；篡改它的人，篡改的是众生的命。
- **书中作用**：全书核心道具。高太公死期被改、翠兰「寿终正寝」造假、招安条件「翠兰轮回」兑现不了——全在簿子上。第35章夺簿见真相，第38章高太公执笔写下「人间自决」。
- **主题与伏笔**：生死簿 = 谁有权写别人的命。高太公不识字，却成了执笔人——因为能写人间命的，只有人（菩提：神写不了人的命）。F-04（鬼差涂改）/F-11（死期不对）/F-15（招安兑现不了）都收在这里。

### 判官笔

- **归属**：崔珏。
- **能力**：生死簿的配套笔，一笔定生死。
- **重构设定**：崔珏的笔「落过不该落的字」——翠兰死期造假，笔是他落的（他签了字）。这支笔是他的罪，也是他赎罪的工具。
- **书中作用**：第38章，高太公从崔珏手里接过这支笔（或夺过生死簿），写下「人间自决」。**崔珏把笔交给高太公 = 把「写命」的权力还给人间。**
- **主题与伏笔**：一支笔的移交，是全书权力的交接。

### 孟婆汤

- **归属**：孟婆。
- **来历**：奈何桥头，亡魂过桥必饮。
- **能力**：忘记前尘，方能轮回。
- **重构设定**：**汤的原料是亡魂的记忆与执念**——地府的根基是抹除。汤里锁着翠兰的一缕记忆（F-10）。孟婆是「遗忘」的化身，也是被遗忘的人。
- **书中作用**：高太公拒喝，问「我女儿喝了吗」——孟婆说漏嘴「她没喝，她还在等」（第10章）。第27章攻入孟婆领域揭汤的真相。第36章孟婆的结局。
- **主题与伏笔**：遗忘 = 抹平冤情的工具。造反，就是拒绝喝下那碗汤。F-06/F-10/F-17 收在这里。

### 孽镜台（照妖镜/孽镜）

- **归属**：地府第一殿。
- **能力**：照出亡魂生前的善恶。
- **重构设定**：镜子里不是高太公的恶——**照出的是翠兰之死的那一夜**（第8章）。孽镜成了「照冤」的镜子，照出地府不敢认的案。
- **书中作用**：高太公第一次得知翠兰是被害死的（T2）。F-05 埋于此，第37章回收。
- **主题与伏笔**：镜子照不出「谁改了命」，只照得出「命被改了」。照妖镜照妖，照不出天庭的妖。

## 二、兵与器（血债与农具）

### 金箍棒（如意金箍棒）

- **归属**：孙悟空。
- **来历**：大禹治水的定海神针，东海龙宫至宝。
- **能力**：可大可小，重一万三千五百斤，专打妖怪。
- **重构设定**：它本是**量水深的尺子**——大禹治水用它镇海。它管过水，现在是打人的棒子。它打死过白骨精（三次）。**这根棒子上有血债。**
- **书中作用**：白骨精的旗帜——「打死我的那根棒子，现在在谁手里？」（第15章）。悟空用它反过天，如今是斗战胜佛的棒子。第33章悟空的选择，与这根棒子有关。
- **主题与伏笔**：定海神针 = 管水的尺子变成打人的棒子 = 秩序的工具变成镇压的工具。它打过妖，也打过「像妖的人」。F-18（泾河龙王/水）与它遥相呼应。

### 九齿钉耙（上宝沁金钯）

- **归属**：八戒/净坛使者（前身天蓬元帅）。
- **来历**：太上老君亲手锻造，天庭御赐给天蓬元帅的兵器。
- **能力**：九齿钉耙，可筑可筑，威力不俗。
- **重构设定**：**它是一把农具做的兵器**——钉耙本来是刨地的。八戒在高老庄用它耕田耙地（「耕田耙地，不用牛具」），后来它成了杀伐的兵器。它是八戒双重身份的象征：天蓬元帅的兵刃 / 老农家的农具。
- **书中作用**：第39章，八戒赎罪生还，回到高老庄的田里——**钉耙终于又成了刨地的农具**。道具的回归 = 人的回归。
- **主题与伏笔**：F-14（老母猪/猪的命 vs 人的命）的器物版。一把农具被改成兵器，再改回农具——这就是八戒的一生。

### 降妖宝杖

- **归属**：沙僧（卷帘大将）。
- **来历**：梭罗木所制，卷帘大将的仪仗兵器。
- **能力**：降妖。
- **重构设定**：它本是**宫里的仪仗**——不是用来打仗的，是撑门面的。沙僧用它，像他的性格一样：沉默、规矩、不显眼。它从没打死过谁，沙僧也从不炫耀。
- **书中作用**：沙僧开口作证时（第26章），宝杖一直拄在他身边——见证者的杖。
- **主题与伏笔**：仪仗变兵器，规矩变奴役。沙僧的宝杖没有血债，这是他的清白，也是他的沉默。

### 三尖两刃刀

- **归属**：二郎神。
- **能力**：二郎神的兵器。
- **重构设定**：军令的化身——它指哪打哪，不问对错。二郎神的动摇（第22、34章），从握刀的手开始。
- **书中作用**：镇压义军的天兵主将（第22章），混战中的关键选择（第34章）。
- **主题与伏笔**：一把「只问军令」的刀，最终被它的主人放下了。

## 三、控与锁（收编的象征）

### 紧箍咒（金箍 + 定心真言）

- **归属**：唐僧，观音所授。
- **来历**：观音给唐僧的「管教」悟空之物。
- **能力**：念咒则头痛欲裂，锁住悟空。
- **重构设定**：**它是「收编」的具象**——一个造反者被套上箍，从此听话。而唐僧管八戒不用金箍——**八戒的「紧箍咒」是尘缘（翠兰）**：握着翠兰的命，就等于握着八戒的头。这是全书最狠的「看不见的箍」。
- **书中作用**：悟空头上的金箍是明线（他戴着它当斗战胜佛）；八戒的「尘缘之箍」是暗线（F-13），第37章揭穿。第33章悟空与高太公的对话，绕不开这道箍。
- **主题与伏笔**：紧箍咒 = 收编的具象。高太公的造反，本质上是不肯被套上箍——他宁愿死，也不戴。

### 五行山 + 六字真言

- **归属**：如来。
- **来历**：如来压悟空之物，山顶贴六字真言。
- **能力**：压住造反者五百年。
- **重构设定**：**五行山不是山，是「招安前的收编」**——先压服，再招安。悟空从山下出来，就只剩一条路：取经、成佛、听话。
- **书中作用**：悟空对高太公的自嘲——「我反过，被招安了。你猜招安后我每天干什么？」（第30章）。五行山是悟空命运的背景。
- **主题与伏笔**：山压的是肉身，招安压的是心。高太公没有山压他——他死了，反而自由了。

### 金刚琢

- **归属**：太上老君。
- **来历**：老君的宝物，能套走诸般兵器法宝。
- **能力**：收兵器。
- **重构设定**：老君「借刀」的手段之一——他能收走义军的兵器，也能「收走」别人的算计。它是老君「话里有话」的器物版。
- **书中作用**：第32章天庭勾心斗角，老君暗中递刀/收刀。
- **主题与伏笔**：金刚琢套走兵器，老君套走人心。刀是借的，砍了谁的手，那是刀的事。

## 四、权与势（谁握着命脉）

### 蟠桃

- **归属**：王母娘娘，蟠桃园。
- **来历**：天庭至宝，三千年/六千年/九千年一熟。
- **能力**：长生。
- **重构设定**：**长生的经济**——谁的寿数用蟠桃续，谁就不用轮回；蟠桃是天庭统治的底座，王母是「猪圈主」，蟠桃园是「猪圈」。高太公尝了一口：「这桃，不如我地里的甜。」（第31章）
- **书中作用**：第31章天庭之行，第32章王母的账。
- **主题与伏笔**：蟠桃 = 天庭的长生垄断。换了人间后，蟠桃的香火断了——长生的买卖，做不下去了。

### 人参果树 / 人参果

- **归属**：镇元子，万寿山五庄观。
- **来历**：天地灵根，三千年一开花，三千年一结果，再三千年才熟。
- **能力**：闻一闻活三百六十岁，吃一个活四万七千年。
- **重构设定**：**它能养地气，也能断地气**——地仙之祖的根，连着人间的土。它是「换了人间」的手段之一（斩断连接，靠的是人间的土气）。高太公把它当萝卜看：「这果子，不顶饿。」（第18章）
- **书中作用**：第18章镇元子登场；第34章混战末期、第39章换了人间，人参果树是关键。
- **主题与伏笔**：人参果长在地上——地仙的根在人间。人间没了，地仙也没了根；人间自由了，地仙才活。

### 芭蕉扇

- **归属**：铁扇公主（罗刹女），一柄另有太上老君所持（阴阳二扇）。
- **来历**：混沌开辟时的灵宝，一扇熄火，一扇生火。
- **能力**：扇灭火焰山之火（或扇出风火）。
- **重构设定**：**火焰山是悟空大闹天宫留下的疤**——他蹬翻老君的炼丹炉，炉火落成火焰山。芭蕉扇是「收拾烂摊子」的扇子：谁闯的祸，谁来扇。它连着牛魔王/铁扇公主一家的旧账（牛魔王被收编，红孩儿被收走）。
- **书中作用**：牛魔王线的背景道具；混战中火焰山/芭蕉扇可作一处拉锯战场（龙王的水 vs 芭蕉扇的火）。
- **主题与伏笔**：火焰山是「造反的代价」——大圣的闹，烧了人间几百年。换了人间后，这火该不该灭、谁来灭，是留给读者的余味。

### 龙珠 / 定海珠

- **归属**：四海龙王。
- **能力**：龙族的本源之力，行云布雨。
- **重构设定**：龙珠是龙族的「缰绳」所在——天庭捏着龙珠，龙王就得听话。泾河龙王死于「改雨量」（F-18），龙珠是龙族的命，也是龙族的锁。
- **书中作用**：第24章龙王倒戈，第34章「人间的水归人间」。
- **主题与伏笔**：龙珠 = 被捏着的命脉。龙王倒戈，就是把缰绳从自己脖子上解下来。

### 炼丹炉（八卦炉）

- **归属**：太上老君。
- **来历**：老君炼丹之所。
- **能力**：炼金丹、炼法宝；悟空在里面炼出火眼金睛。
- **重构设定**：**老君的炉子炼的不只是丹，是「局」**——他借义军的刀，在炉子里「炼」佛家的败局。炉火落成火焰山（见芭蕉扇）。
- **书中作用**：第32章天庭勾心斗角，老君的暗手。
- **主题与伏笔**：炼丹炉 = 算计的炉子。老君算了一辈子，没算到「换了人间」连他也管不着人间了。

## 五、器与物（小而重的）

### 紫金钵盂

- **归属**：唐僧（唐王所赐）。
- **来历**：取经人的饭钵。
- **能力**：化缘吃饭。
- **重构设定**：**它是最干净的器物，也是最脏的**——迦叶阿难索「人事」，要的就是它（西游正典：无字经书换金钵）。佛门的「人事」贿赂，从一只饭钵开始。
- **书中作用**：第36章高太公上西天，迦叶阿难索人事——高太公掏出一把土：「人事没有，土要不要？我地里的。」（一只饭钵 vs 一把土，两个世界的价值观对撞）
- **主题与伏笔**：饭钵要饭碗，土要命。佛要人事，人要土。

### 琉璃盏

- **归属**：沙僧（前卷帘大将）。
- **来历**：天庭宫中之物。
- **能力**：无（就是一只杯子）。
- **重构设定**：**沙僧打碎一只杯子就被贬下凡**——罪小得荒唐，正是系统的荒唐。琉璃盏是「微不足道的罪」的具象：它碎了，沙僧的一生就碎了。
- **书中作用**：沙僧的身世背景（第26章）。
- **主题与伏笔**：一只杯子毁了一个人——天庭的「规矩」比生死簿还草菅人命。沙僧的沉默，是被一只杯子吓出来的。

### 净瓶 + 杨柳枝

- **归属**：观音。
- **能力**：起死回生、甘露。
- **重构设定**：观音的「慈悲」的具象——她的瓶能救，也能「按」；她救过很多人，也默许了翠兰的死。杨柳枝点一点，是她的手段，也是她的心虚。
- **书中作用**：第36章观音「佛不能知道」。
- **主题与伏笔**：净瓶能救死回生，却救不了「被改的命」——因为改命的人，是她的同门。

## 六、行头与獠牙（穿与戴的）

### 锦襕袈裟

- **归属**：唐僧（观音所授）。
- **来历**：冰蚕丝织就，佛门至宝，观音赐予取经人。
- **能力**：辟水火、免灾殃。
- **重构设定**：**它是「慈悲的门面」**——穿上它，人人当你是圣人；它也是贪婪的磁石（西游正典里，金池长老为它烧了自己的庙）。一件象征圣洁的衣裳，走到哪都招来杀心。唐僧穿着它做最狠的事（抹翠兰），脸上一片慈悲——**袈裟是「慈悲的残忍」的制服**。
- **书中作用**：第37章唐僧黑手全揭时，高太公盯着那件袈裟——「这衣裳，金线绣的，能当被子盖吗？」（老农问圣洁能不能取暖）。
- **主题与伏笔**：圣洁的门面 vs 门面下的血。袈裟越圣洁，他做的事越脏。它招来过黑熊精的贪，也招来高太公的恨。

### 九环锡杖

- **归属**：唐僧（观音所授）。
- **来历**：九环锡杖，取经人的行头。
- **能力**：降妖的名义；更多是「行头」。
- **重构设定**：**它是「不担担子的人」的杖**——取经路上，八戒挑担、沙僧挑担、白龙马驮人，只有唐僧拄着锡杖走路，两手干干净净。九环叮当，每一步都在宣告「我是圣人」。它和锄头是两样东西：**他拄着金杖走路，高太公抡着锄头刨食。**
- **书中作用**：高太公视角的对照意象；第37章对质时，锡杖立在唐僧身后，像他的「道」一样立着。
- **主题与伏笔**：不担担子的人，凭什么指点挑担子的人？锡杖的环声，是全书最响的「体面」，也是全书最空的「道」。

### 虎皮裙

- **归属**：孙悟空。
- **来历**：取经路上悟空打死一只猛虎，剥皮做裙。
- **能力**：无（就是一件裙）。
- **重构设定**：**它是悟空唯一保留的野性**——他反过天，被压了五百年，被套了箍，成了斗战胜佛，但腰上还系着当年打死猛虎的虎皮裙。**他留住了虎皮，丢了老虎。**这条裙是他和「自由」之间最后的联系，也是高太公照见自己的镜子——高太公留住了土，悟空留住了虎皮。
- **书中作用**：第30、33章悟空登场，虎皮裙是细节——他穿着佛的衣裳，系着虎的皮。
- **主题与伏笔**：你被驯化之后，还留着什么？悟空留着虎皮裙，高太公留着土。换了人间后，虎皮裙还在他腰上——这是他自己的选择，也是他唯一没交出去的东西。

### 哮天犬

- **归属**：二郎神。
- **来历**：二郎神的神犬，能咬神仙。
- **能力**：咬人（专咬造反的）。
- **重构设定**：**它是「不问为什么的獠牙」**——狗不咬人，是主人让它咬。哮天犬是二郎神军令的延伸，也是全书最「无辜」的镇压者：它不知道对错，只知道命令。高太公养过猪，他看得懂狗——「狗咬人，是主人的意思，不是狗的意思。」
- **书中作用**：第22章镇压义军时哮天犬登场；第34章二郎神动摇时，哮天犬趴在主人脚边，不知主人为何不动。
- **主题与伏笔**：最底层的执行者，最没有选择。哮天犬是「被当牛马」主题的又一层——连神兽都是缰绳下的工具。它咬人的时候不恨人，它只是奉命。它也是二郎神「军令如山」的活体证明：狗听令，人也听令，听令的人其实也是狗。
