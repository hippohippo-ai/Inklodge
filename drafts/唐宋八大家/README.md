# 唐宋八大家

**题材：** 密谋／文字为刀
**背景：** 北宋汴京（相国寺书市、州桥、汴河、三司、皇城司）
**体制：** 章回体，八回，约一万二千言

## 一句话

"唐宋八大家"不是一个文人的名单，而是八个位子——汴京有八个抄公文的人，以唐宋八家的名字为号，替人改一个字：一字之差，一条命。卖字收钱，白改受罚。沈砚的父亲原是其中"昌黎"一席，三年前死在一份被改回来的判词旁边。三年后，一颗朱点落在沈砚抄的副本上。
