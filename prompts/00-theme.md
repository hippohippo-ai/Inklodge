# 阶段 0：主题确认

【主题】{主题}

## 固定流程（不要跳过任何一步）

1. 读取 `state/theme.txt`，确认主题。
2. 把下面的内容写入 `state/theme.md`：
   - **题材**：玄幻 / 科幻 / 悬疑 / 都市 / 历史 / 言情 / 仙侠 ……
   - **基调**：热血 / 沉重 / 轻快 / 黑暗 / 治愈 ……
   - **视角**：第三人称限知 / 第三人称全知 / 第一人称（写明）
   - **目标规模**：总章节数 + 每章字数（本项目每章目标约 4000 字，正文非空字符 4000–4500）
   - **一句话核心故事（logline）**
   - **结局方向**：HE / BE / 开放式（仅作方向，后续可调整）
3. 完成后把 `state/progress.md` 的「当前阶段」更新为 `01`。

## 规则

- 本阶段只定方向，不展开剧情。
- 主题与基调一旦确认，后续所有阶段都以此为准。
