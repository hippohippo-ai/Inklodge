# 阶段 5：伏笔暗线

【主题】{主题}

## 固定流程

1. 读取：`state/outline.md`、`state/characters.md`、`state/chapters.md`
2. 把下面的内容写入 `state/foreshadowing.md`，**每条伏笔**：
   - **编号**：F-01、F-02……
   - **类型**：明 / 暗
   - **内容**：埋下的是什么信息
   - **埋设章节**
   - **回收 / 揭示章节**
   - **提示方式**：对话 / 道具 / 细节 / 梦境 / 传闻……
   - **状态**：未埋 / 已埋 / 已回收
3. 完成后把 `state/progress.md` 的「当前阶段」更新为 `06`。

## 规则

- 伏笔表是防「挖坑不填」的核心文件。
- 写正文时凡出现新伏笔，必须在阶段 10 同步登记进本表。
- 暗线（读者不知道、角色也不知道的）要单独标注「读者视角」与「角色视角」分别知道什么。
