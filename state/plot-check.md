# 局部剧情复检报告

## 2026-08-28｜第二卷第26—30章与人物执行规则

### 已复检

- 第26章以驿卒军报、城门拥堵、粮车和南逃车队承载潼关失守，不再只用历史消息切片。
- 第27章由老兵、卖水老妇、文人、差役和钩稽使共同构成现场，各自目标不同；军牌改为缺角残字遗物。
- 第28章宁红叶、桑葚、沈念与沈广农建立照护关系，照夜剑纹和父亲旧案具有后续回收点。
- 第29章突围存在互相掩护、孩子拖累、伤势反噬和观察力失控，动作不再按固定招式清单推进。
- 第30章难民营中借车板、躲差役、取水和清创彼此牵制；顾琰保持远观，裴弘度未直接现身。

### 后续审计要求

- 第二卷第31章以后必须让宁红叶、桑葚、沈念持续改变路线、物资和风险判断，不得恢复为主角的道德装饰。
- 半面、严平、段成与退役老斥候必须有独立利益及跨章后果；配角不能只递线索退场。
- 检查第26—30章与第31章之间的军报时效、米盐价格和长安火灾余波，避免事件即时同步。
- 检查对白是否落到钱粮、伤病、路引、家人和具体威胁，禁止多人共享同一套哲理机锋。
- 后续扩写优先采用多方同场、持续同行、协作失败和证物争夺，不以重复观察填充篇幅。
