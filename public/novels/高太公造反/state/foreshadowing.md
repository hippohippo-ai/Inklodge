## 一、高太公之死线

### F-01 报信人的鬼脸（报信人 = 八戒）

- **类型**：暗
- **内容**：高太公死前看见报信人的脸变成一张鬼脸——报信人不是普通捎信的，是取经体系里的人（最终揭示：报信人就是八戒，破戒回来警告，警告却成了催命符）。
- **埋设章节**：第3章（死前的鬼脸）。
- **回收 / 揭示章节**：第28章（八戒：「你死的那个报信人……是我」）。
- **提示方式**：细节（死前所见，一闪而过的鬼脸）。
- **状态**：未埋。
- **读者视角**：不知道报信人是谁，只知道他「不对劲」、脸会变。
- **角色视角**：高太公至死不知是八戒——他含恨而终，这是 T1 的根。
- **执行兜底（用户指定·载体机制）**：八戒破戒下界时神魂后附着西天的追踪与灭口法旨/阴影——问「翠兰埋在哪」触发勾魂夺命，**他不知自己是行凶的刀**（T1）；第28章下跪时，这份「不知情」让悲剧更深。

### F-11 阎罗「你的死期不对」（死期被人改）

- **类型**：明
- **内容**：高太公本该还能再活几年，死期是被人改的——追查「谁改的」贯穿全书。
- **埋设章节**：第9章（阎罗翻页愣住：「你的死期不对」）。
- **回收 / 揭示章节**：第16章（崔珏：「改你死期的人，你认识」）→ 第25章（崔珏坦白，旧账摊开）。
- **提示方式**：对话（阎罗失口）、公文（生死簿上的页）。
- **状态**：未埋。
- **读者视角**：知道死期被人动过，凶手成谜。
- **角色视角**：高太公追查，越查越接近「上头有人」。

### F-15 招安条件「翠兰轮回」兑现不了

- **类型**：暗
- **内容**：太白金星招安的条件是「让翠兰轮回」，但翠兰那页被锁在更高处——招安是假承诺，兑现不了。
- **埋设章节**：第31章（太白金星答应得太爽快，高太公起疑）。
- **回收 / 揭示章节**：第35章（夺簿见真相——页被锁，「寿终正寝」是伪造的）。
- **提示方式**：对话（太白金星不敢看高太公的眼睛）、细节（承诺太顺）。
- **状态**：未埋。
- **读者视角**：隐约觉得招安是骗局。
- **角色视角**：高太公起疑但没证据，直到夺簿。

## 二、翠兰之死线

### F-02 坟被刨过、棺材空（翠兰尸身/魂魄的秘密）

- **类型**：暗
- **内容**：翠兰的坟是新土、被刨过；高太公的棺材空得不像话——**真相：西天取身**——唐僧断尘缘时借地府批文「清理」痕迹：翠兰尸身被取走（她的魂被锁、身被取，坟被刨）、高太公勾魂后尸身同样被处理（空棺=衣冠冢）。
- **埋设章节**：第2章（坟是新土、被刨过）；第4章（棺材空得不像话）。
- **回收 / 揭示章节**：第12章（翠兰魂魄滞留地府，部分揭）；**第35章点破**（夺簿见真相时——她的页是假的，魂被锁、身被取；高太公的空棺同理，勾魂证据被「处理」）；**第38章收束**（箍断，翠兰自由轮回，尸身之谜随真相落地）。
- **提示方式**：细节（新土、空棺）。
- **状态**：未埋。
- **读者视角**：疑云——坟里到底埋了什么。
- **角色视角**：高太公只觉得蹊跷，不敢深想。

### F-03 翠兰坟里说「爹，别来」

- **类型**：暗
- **内容**：魂出窍时，高太公听见翠兰坟里说「爹，别来」——不是告别，是警告：她知道有人要害爹。
- **埋设章节**：第5章（魂出窍，坟里的声音）。
- **回收 / 揭示章节**：第12章（翠兰：「害我的人还在上面，爹，你别查了」）。
- **提示方式**：梦境/声响（魂出窍时听见）。
- **状态**：未埋。
- **读者视角**：翠兰在警告爹别卷进要命的真相。
- **角色视角**：高太公不懂为何「别来」，只当女儿舍不得。

### F-05 孽镜照出翠兰之死那一夜

- **类型**：暗
- **内容**：孽镜照出的不是高太公的善恶，而是翠兰之死的那一夜——翠兰不是病死，是被害（T2）。
- **埋设章节**：第8章（孽镜台）。
- **回收 / 揭示章节**：第37章（被害真相全揭——唐僧借地府伪造「寿终正寝」）。
- **提示方式**：道具（孽镜，照出不敢认的案）。
- **状态**：未埋。
- **读者视角**：知道翠兰是被害，不知道凶手。
- **角色视角**：高太公知道被害，追查凶手。

### F-10 汤里锁着一缕翠兰的记忆

- **类型**：暗
- **内容**：孟婆汤的原料是亡魂记忆；汤里锁着翠兰的一缕记忆——她不是没喝过，是记忆被藏进汤里。
- **埋设章节**：第27章（攻入孟婆领域，汤的真相）。
- **回收 / 揭示章节**：第37章（八戒交出这缕记忆，作证）。
- **提示方式**：道具/细节（汤里浮出的碎片）。
- **状态**：未埋。
- **读者视角**：翠兰的记忆在汤里，是罪证也是遗物。
- **角色视角**：高太公隐约察觉，直到八戒交出。

## 三、地府·簿子真相线

### F-04 鬼差涂改生死簿，鬼魂消失

- **类型**：明
- **内容**：鬼差当众涂改生死簿，被涂改的鬼魂当场消失——簿子可改、可删，连魂都能被「改没」。
- **埋设章节**：第7章（鬼门关，亲眼所见）。
- **回收 / 揭示章节**：第35章（簿子真相——字不是神写的，是众生的业；篡改它的人篡改的是众生的命）。
- **提示方式**：事件/细节（当场消失）。
- **状态**：未埋。
- **读者视角**：知道簿子可改，埋下「存在可被删」。
- **角色视角**：高太公亲见，开始怀疑地府的规矩本身。

### F-12 地藏王「我等到你了」

> 四件套组件之一（兜底#6）：地藏王是「业力归还人间」的执行者。

- **类型**：暗
- **内容**：地藏王「地狱不空誓不成佛」，不是不在，是被困在生死簿里/即生死簿——「我等到你了」等的是一个敢破局的人。
- **埋设章节**：第30章（地藏王/谛听的影子）。
- **回收 / 揭示章节**：第35章（谁写的簿子——地藏王即簿子/被锁在簿子里）。
- **提示方式**：对话/传闻（谛听转述）。
- **状态**：未埋。
- **读者视角**：地藏王在等一个破局者。
- **角色视角**：高太公不知自己是被等的人。

## 四、义军·双层内鬼线

### F-07 内鬼泄密（两层：一缕执念 + 妖派通敌）

- **类型**：暗
- **内容**：密谋总被泄露，泄密有两层——①一缕执念附身最忠心的鬼卒（马面倒卖孟婆汤残渣，地府「遗忘」的残渣，不是人）；②妖派牛魔王与天庭私下交易（太白金星二次招安：按死义军换「妖界复辟」）。
- **埋设章节**：第19章（内鬼疑云，谛听登场）。
- **回收 / 揭示章节**：第23章（揪出执念——假内鬼，真松一口气）；第34章（牛魔王通敌暴露——真叛徒，义军惨败）。
- **提示方式**：事件（密谋泄密）、对话（谛听）、细节（执念附身）。
- **状态**：未埋。
- **读者视角**：知道有内鬼，不知是谁——执念是意外，牛魔王是暗流。
- **角色视角**：义军以为执念是全部，牛魔王在暗处笑。

### F-21 牛魔王「出卖过老兄弟」的旧账

- **类型**：暗
- **内容**：牛魔王当年被天庭收编时出卖过几个老兄弟（他不敢提的旧账）——历史会在混战中重演：他为了「妖界复辟」，二次把义军卖给天庭。
- **埋设章节**：第14章（联合牛魔王，旧账的传闻/细节）。
- **回收 / 揭示章节**：第34章（通敌暴露——历史重演，被天庭再卖一次）。
- **提示方式**：细节/传闻（妖派对牛魔王旧事的只言片语）。
- **状态**：未埋。
- **读者视角**：牛魔王有前科，是隐患。
- **角色视角**：高太公只知传闻，不知他会再卖一次。
- **执行兜底（用户指定·不洗白）**：第39章牛魔王的回头是绝望后的玉石俱焚（发现连做狗都不配，替义军挡枪/断后），不是「重归于好」；高太公与白骨精不原谅他、只利用他的蛮力破局——「叛徒虽醒，裂痕永在」。

## 五、取经·唐僧黑手线

### F-13 取经路上唐僧「不对劲」

- **类型**：暗
- **内容**：唐僧的「慈悲的残忍」——①从不问家事（取经路上从没问过八戒的老婆孩子）；②知道得太多（第一次见面就知道高老庄、翠兰的名字，可八戒从没跟他说全过）；③慈悲是挑人的（普度只给有用的人）；④女儿国一段（使命就是他的妻子，把「事」当「人」来爱）；⑤尘缘是八戒的紧箍咒（握着翠兰的命=握着八戒的头）；⑥「尘缘既断，何须回头」（第二天起八戒再也收不到高老庄的信）。
- **埋设章节**：第26章（沙僧口述）、第28章（八戒口述）。
- **回收 / 揭示章节**：第37章（唐僧黑手全揭）。
- **提示方式**：对话/细节/回忆（沙僧作证、八戒口述、白龙马的沉默）。
- **状态**：未埋。
- **读者视角**：唐僧不对劲，但不知全貌。
- **角色视角**：沙僧/八戒知道，高太公逐块拼图。
- **执行兜底（用户指定·执刀人）**：唐僧是「规则与大义上的执刀人」，非法力黑手——借佛门印信/金蝉子宿慧与地府做账目交割（崔珏认的是取经工程批文），观音幕后隐性背书（F-17）；正文必须写明，不能让他凭空调动地府。

### F-17 观音「佛不能知道」

- **类型**：明
- **内容**：取经的代价观音知情——唐僧抹翠兰，她默许了，因为取经「更重」。「有些事，不是佛不知道，是佛不能知道。」
- **埋设章节**：第36章（上西天，观音）。
- **回收 / 揭示章节**：第37章（唐僧全揭，观音的态度坐实）。
- **提示方式**：对话（观音留余地）。
- **状态**：未埋。
- **读者视角**：观音默许了翠兰的死。
- **角色视角**：高太公从观音的态度确认唐僧。
- **执行兜底（用户指定·背书）**：观音的隐性背书是唐僧这个执刀人能动地府的口子——她不开这个口子，唐僧就动不了；第36章她放水，口子才真正关上。

### F-20 沙僧的沉默（他什么都知道，只是不说）

- **类型**：明（对读者）暗（对高太公）
- **内容**：沙僧取经路上什么都知道（唐僧的所作所为、八戒的尘缘被锁、翠兰的死因），但被一只琉璃盏吓出来的沉默让他闭嘴——沉默者的证词最重。
- **埋设章节**：第26章（沙僧登场，「我看见了，只是不敢说」）。
- **回收 / 揭示章节**：第37章（作证，卸下沉默的罪）。
- **提示方式**：对话/细节（话极短，一次说破一句）。
- **状态**：未埋。
- **读者视角**：沙僧知道一切，等着开口。
- **角色视角**：高太公从沙僧的沉默里拼图，知道他说的是真的。

## 六、天庭旧案线

### F-08 六耳「我是被删掉的那一页」

- **类型**：明（六耳自述）内容暗（天庭旧案）
- **内容**：六耳猕猴是被抹去的存在——「被删掉的那一页」，天庭旧案的受害者；他的被抹除证明「存在可以被删」。
- **埋设章节**：第29章（六耳登场）。
- **回收 / 揭示章节**：第32章（天庭旧案）、第35章（生死簿真相——被删掉的人）。
- **提示方式**：对话（六耳自述）、模仿（声音串台）。
- **状态**：未埋。
- **读者视角**：存在可被删，与生死簿可改接上。
- **角色视角**：高太公第一次听说「被删掉」，联想到翠兰那页。

### F-16 天蓬元帅坠落另有隐情（嫦娥知道）

- **类型**：暗
- **内容**：当年不是天蓬调戏嫦娥——是有人设局（夺天蓬的兵权/取经的引子），嫦娥是被安排的「诱饵」，她一直知道一直没说。
- **埋设章节**：第26章（天蓬坠落旧案初现）。
- **回收 / 揭示章节**：第32章（嫦娥开口，天庭旧案全揭）。
- **提示方式**：对话/回忆（嫦娥「有人教我喊的」）。
- **状态**：未埋。
- **读者视角**：天蓬坠落不是调戏那么简单。
- **角色视角**：嫦娥知道不说，直到混战才开口。

### F-18 泾河龙王之死（西游记开端）——龙族的旧冤

> 四件套组件之一（兜底#6）：龙王「断雨断香火」的根——人间的水归人间，天庭的香火供奉随之断。

- **类型**：暗
- **内容**：泾河龙王当年只是改了雨量却被斩首——因为有人要借他的头开刀（开启取经的引子）。龙族知道这是个局，一直在等。
- **埋设章节**：第24章（龙王入局，旧冤揭开）。
- **回收 / 揭示章节**：第34章（龙王倒戈的根——人间的水归人间）。
- **提示方式**：传闻/细节（龙族旧案）。
- **状态**：未埋。
- **读者视角**：龙族被天庭捏着缰绳，有旧冤。
- **角色视角**：高太公把龙王当管水渠的，后来才懂龙族的恨。

## 七、招安·悟空线

### F-09 悟空「招安后我每天干什么」

- **类型**：明
- **内容**：悟空反过天、被压五百年、被套箍、成了斗战胜佛——「被招安后每天干什么」是看家护院。他劝高太公别重蹈覆辙，又忍不住希望他成功。
- **埋设章节**：第30章（悟空登场劝诫）。
- **回收 / 揭示章节**：第33章（悟空让路/递刀/祝福——他没反成的，高太公反成了）。
- **提示方式**：对话（自嘲里带苍凉）。
- **状态**：未埋。
- **读者视角**：招安是陷阱，看门狗的命运。
- **角色视角**：高太公被警告，反而更清醒。

### F-19 菩提祖师「等一个凡人」

- **类型**：明
