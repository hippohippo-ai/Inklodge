# 阶段 9：写章节（第 {章节号} 章）

【主题】{主题}

## 核心任务

读取 `state/` 下的设定文件、当前卷大纲、章节规划、伏笔台账、时间线、知识矩阵和上一章总结，只写本章既定剧情。不得凭记忆补设定，不得把策划过程输出给读者。

## 顶级禁令（违反即废稿重写）

### 1. 纯净正文律

输出必须百分之百是小说正文。

严禁出现：

- `## 第一幕`、`## 第二幕`、`【第一幕】`、`幕次`等结构标签；
- `> 篇幅`、`核心气质`、`本章功能`、字数表、感官表等规划说明；
- `本章写作要点回顾`、`本章因果种子`、`上章衔接`、`下章预告`等作者复盘；
- 伏笔解释、角色分析、因果分析、写作说明和正文外总结。

章节标题后直接进入叙事，正文结束立即停笔。章节总结、伏笔、衔接和统计只能写入 `state/chapter-log.md`。

### 2. 观察必须消融，禁止清单扫描

严禁以下结构：

- “他看到了三件事/三个细节”；
- “第一……第二……第三……”作为观察、行动或推理骨架；
- “三样东西、三条线、三个弱点”式汇报；
- “一、二、三”连续罗列人物发现。

观察必须立刻进入动作、阻力、误判或选择。

**错误示例：**

> 沈广农看到了校尉的三个弱点。第一，马镫很滑；第二，马鞍磨毛了；第三，校尉重心在右脚。

**正确示例：**

> 校尉踩镫翻身上马，湿透的鞍垫顺着马背往后滑。沈广农撞向铁镫下沿，泥浆先糊住了他的眼，肩骨也被反震得发麻。校尉仓促收腿，靴底在镫面上打了个空，整个人连着刀栽进车辙。

正确写法不宣布“发现了什么”，让器物、身体和行动结果替读者完成推理。

### 3. 禁止全员哲理腔

角色不得轮流讨论或复述：

- “聪明与智慧”的区别；
- “看与被看”；
- “棋子与棋盘”；
- “变强是为了什么”；
- “代价是什么”；
- “看太多会瞎”等已被使用过的导师式警句。

章节结尾禁止背诵公孙白、顾琰、裴弘度、宁红叶等人的名言。让寒气、伤口、饥饿、脚步、物证或未说完的话完成留白。

**声线分层：**

- **脚夫、流民、小贩**：斤两、肚皮、家人、脚下的泥、差役和脏话。示例：“二两盐换半碗米，少一粒我就砸你的锅。”
- **军官、士卒**：短促、暴躁、疲惫，围绕军令、伤口、粮食、逃兵和时辰。示例：“按住他！布条不够，把衣襟撕了！”
- **世家、商人**：账期、损耗、契约、族人、粮路和筹码。示例：“活着的人按人头算，死的人划掉，我不付运费。”
- **高阶官僚**：公文、数字、调拨、责任归属和制度流程，避免抒情。示例：“少一袋，记在押运人名下；月底从调拨里扣。”
- **沈广农**：年轻、寡言，但允许害怕、犯错、恼怒、嘴硬和失控；不要让他每次都冷静总结。
- **宁红叶**：医者的急躁、疲惫和具体命令，救人会消耗粮、药和时间。
- **半面**：油滑、贪财、会抱怨，也会因自保撒谎、调包、误判或逃跑。
- **严平**：病弱、谨慎、护账，讲话围绕官仓、时辰、账目和自身安危。
- **段成**：军中老兵的直冲、怨气和纪律经验，不负责发表宏大评论。

### 4. 配角动态纠缠，禁止工具人

任何有实质戏份的配角必须同时具备：

- 自己要保住或取得的东西；
- 与主角目标发生冲突的行动；
- 一个隐瞒、误判、索价、恐惧或现实限制；
- 本章结束后仍会留下的债务、伤势、证物、误会、承诺或追索。

禁止“出现—报答案—送道具—说警句—消失”。线索和物资必须付出代价，至少经过讨价、欺骗、遮掩、推搡、风险或交换。

优先安排不同立场人物同时在场。人物不能轮流展示技能；他们应互相打断、争抢、误伤、拖累或被迫合作。

### 5. 同伴必须成为真实负重

对于宁红叶、桑葚、沈念及后续流亡队伍：每章至少让一个孩子或伤员的生理需求改变路线、时间、潜行、物资或风险判断，例如发热、咳嗽、尿急、偷吃、鞋子脱落、伤口渗血或拒绝移动。

这项需求必须产生后果，不能只作为“证明善良”的装饰。

### 6. 打戏必须狼狈且有代价

禁止把战斗写成无伤的力学解题。即使沈广农看出破绽，身体执行也必须受到泥水、遮挡、疼痛、反震、呛咳、慢半拍和器物阻碍影响。

每场交手至少出现一次判断失误、配合失误或动作迟滞。胜负可以依靠抓泥糊眼、撞入尸堆、咬人、借塌木、误伤器物、假摔或求饶等市井手段，但必须留下伤势、证物损毁、路线暴露或关系恶化。

### 7. 历史事件必须写出过程重量

潼关、马嵬坡、长安沦陷等事件不得只用数段军报和“切片”交代。通过城门、军粮、车马、伤病、物价、搜捕、路程和普通人的错误选择表现制度崩解。

军报必须有路线和延迟；江南与河北的因果必须通过黑水盟、商船、牙人、流民、信使等物理中继传递，不写玄学即时同步。

## 写作执行标准

1. 单章正文目标为 4000–5000 个实际 UTF-8 字符；章节标题、空白和后台说明不计入。若单次输出受限，必须分段续写同一章，不能用提纲或短章掩盖篇幅缺口。
2. 主角与他人的实质互动原则上不少于正文50%，包括交易、试探、争执、协作、欺骗、救援和共同承担后果。
3. 每章至少安排两处身体/环境细节，且必须改变耐力、判断、路线、情绪或动作；不得重复上一章的同一感官比喻。
4. 单人行走只能服务于路线、伤势、物证或判断变化，不得用连续凝视环境代替戏剧。
5. 结尾只留具体悬念：人物未完成的动作、尚未交付的证物、即将到来的军报、失控的水火、未解决的伤势或关系变化。

## 落稿前自查（只在内部执行，不得输出）

- [ ] 正文中没有幕次、规划、字数、因果说明或作者回顾。
- [ ] 没有“看到了三件事/第一第二第三/三样东西”式清单观察。
- [ ] 否定矫正句及变体原则上不超过一次。
- [ ] 没有多人共享哲理格言或结尾金句复读。
- [ ] 至少一名配角拥有独立目标，并对主角造成阻力或索价。
- [ ] 配角离场留下可追踪后果。
- [ ] 群戏中出现具体的打断、误判、争抢、协作失败或被迫交换。
- [ ] 孩子/伤员的需求改变了行动结果。
- [ ] 打戏有狼狈、迟滞或肉体代价。
- [ ] 结尾能自然承接下一章，且没有泄露后台总结。
