# 阶段 8：漏洞检查（动笔前）

【主题】{主题}

## 固定流程

1. 读取全部设定文件：`state/outline.md`、`state/characters.md`、`state/conflicts.md`、`state/chapters.md`、`state/foreshadowing.md`、`state/timeline.md`、`state/knowledge.md`
2. 逐项核对以下维度，把结果写入 `state/plot-check.md`：
   - **时间矛盾**：时间线是否有冲突、人物是否分身
   - **人物动机矛盾**：行动是否符合其「目的」与「性格」
   - **伏笔缺失**：该埋的没埋、该回收的没安排
   - **知识越界**：人物知道了他不该知道的事（对照 knowledge.md）
   - **章节衔接**：章与章之间是否有断档
   - **矛盾未爆发**：conflicts.md 的矛盾是否都有落点
3. 输出**问题清单**：问题 / 严重度（高 / 中 / 低）/ 修正方案。
4. **修正**：回到对应阶段文件更新，再重新检查，直到没有严重问题。
5. 完成后把 `state/progress.md` 的「当前阶段」更新为 `09`。

## 规则

- 本阶段通过前，**禁止进入写正文阶段**。
- 这是一次性全盘检查；之后每写完一章，在阶段 10 只做局部检查。
