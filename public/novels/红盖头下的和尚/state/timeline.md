# 时间线｜《红盖头下的和尚》·重建版

## 一、时间基准

- 沈红绡死亡发生在当前线前三个月；官方结论为自尽。
- 当前故事集中发生在七日局，但第35–40章延伸到离庄与证词送达。
- 太湖水寨二十名好手只属于第一章开篇传说，不进入时间线。

## 四、终局延伸

| 日程 | 事件 | 结果 |
|---|---|---|
| 第7日 | 众人返回或遥望留春山庄，谢三更启动冥婚仪式，七件物证重新排序 | 叙事从逃亡转为主动组织证词 |
| 第8日 | 阮孤灯旧约、明照红盖头、柳九娘第七封信和谢三更灭证同时推进 | 谢三更成为公开执行者，裴九重失去山庄封闭优势 |
| 第9日 | 裴九重在空喜堂压制全员，账房证物随水道分流 | 武力差距确立，证物进入七路传播 |
| 第10–11日 | 秦半夏、施晚晴、陆秋水和顾长亭补齐各自证词 | 沈红绡最后药性保留两种解释，谢三更罪责闭合 |
| 第12日 | 陶未明带证词册回官府，封水官差和无灯楼同时追击 | 官府版本与民间版本同时出现，裴九重转为截断传播 |
| 第13–14日 | 七路证词送往官府、寺院、船队、戏楼和民间说书场 | 裴九重能赢局部，却不能同时追回七路 |
| 第15–18日 | 众人承担伤势、失船、失官和债契后果，赵无咎消失 | 江湖后果开始形成，主线不靠一场胜负收束 |
| 第19–22日 | 阿七写下陆七，裴九重带未完成黑印离开 | 主谜案闭合，最后一杯药的解释保持余味 |

## 五、不可改动的时间边界

- 第24章前，不公开阿七与沈红绡的完整关系和“陆七”姓名。
- 第31章前，不直接让人物说出裴九重姓名；只能通过环境、命令层级和武学痕迹暗示。
- 第32章前，不完整解释七线账、七针地图和反制谱。
- 第40章前，不确定沈红绡最后一杯药究竟是主动选择还是被迫服下。
